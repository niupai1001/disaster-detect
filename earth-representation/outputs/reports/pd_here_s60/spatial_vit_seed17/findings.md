# S60 空间 ViT 30轮消融

将原生60米 Patch 的可见像元拼接后线性投影到128维，加QA、可见性和二维位置编码。编码器使用一层4头全局空间 Pre-LN ViT 与末端 LayerNorm。移除光谱 Token 分支及局部融合，全部可见波段仍进入空间 Patch 投影。沿用两层 MAE Decoder 和共享原生输出头。参数量由1,099,462降至690,886。

单个新实验从 seed17 初始化，保留模块逐张量复制 Dual-Axis 的初始化值。与上一轮独立完成的 S60 Dual-Axis 运行比较。修正S2 700 TRAIN／300开发 VAL，固定480米窗口和原生目标，batch16／尾批12，单卡FP32、相同遮盖和 paired MSE。两组均为30 epoch／1320更新，使用last。数据、窗口、目标像元、遮盖源码及训练配置哈希已核对。
