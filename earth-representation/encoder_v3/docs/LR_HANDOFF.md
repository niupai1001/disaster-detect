## 两项已确认修订，必须替代 v1.1 旧条目

**1. 首版无独立高维 skip。** 不建立逐像元、逐通道或 micro-cell 高维 Decoder 旁路。原生动态卷积和 micro-cell 特征仍可作为计算中间态；以跨通道融合后的 summary 为主要表示。原文融合后的 `R(C)` 局部 latent 保留，它们不是逐通道 skip。独立 skip 未来可另定冻结消融协议，本轮不实现、不运行、不自行设置启用开关；也不擅自增加原始标量到 Decoder 的旁路。

**2. A 完全隐藏区域在 Decoder 侧预测。** Encoder 只编码可见观测，目标区域不新增可学习空白内容 Token；Decoder 从可见 summary 与全局 context 读取上下文，并显式使用目标相对位置、支持尺寸和目标通道条件。静态 `Q_decoder(s,c)` 仍负责读取传感器 KV，逐像元几何进入空间读出路径，不混成一种 Query。目标没有可见内容 Token 或没有直接面积重叠，不构成从 A 损失删去合法目标的理由。

不得借这两项确认更改 P32、KV 数、卷积公式、Sub-Patch 尺度、R(C)、主干层数或 A/B1 权重，也不得将其解释为真实训练授权。

## 首先交付一份接口提案，同时完成确定部分

核查已有实现、数据和规格后，集中提交 `interface_proposal.md`，不要把未定部分默认为自己的习惯实现。最少包含：

| 编号 | 需具体化的内容 |
| --- | --- |
| I1 | 标准化变换、输出和监督域、逐通道损失与层次归约、旧 NMSE 衔接及指标还原；标准化域 MSE 目前只是讨论候选 |
| I2 | 有空间排列信息的 LocalEmbed，以及未给定的 Fourier/小投影/连续 latent Query 细节；无独立高维 skip |
| I3 | 既定主干预算内的位置编码、粗聚合、空窗口、全局回注和分块前后向等价方案 |
| I4 | A 上下文读出及通用 Decoder 的检索/聚合、目标相对坐标参考系与尺度归一化、目标支持及通道条件接入 |
| I5 | 真实载荷身份和完整通道目录、full\_geometry 取值集合、完整 observation/cache 与原始产品整幅的范围核对 |

每项给出最小推荐方案、理由、张量与 mask、资源影响和直接测试。已明确且不依赖待审选择的 Registry、SensorMemory、卷积、纯几何组件和独立测试可以推进；未定义小投影也不要擅自补成冻结配置。依赖未确认接口的正式集成暂停，提案和确认状态必须如实记录。

## 接口确认后完成 D0–D8 / E1

除原计划测试外，重点覆盖：无独立 skip；完整隐藏 Sub-Patch 仍获得预测和监督；同通道不同目标像元的几何实际进入网络；固定真值、冻结统计和 mask 后，仅投毒隐藏输入副本的隔离测试；对应地理位置的通道置换、batch 和分块前后向等价；验证后 live state 写入 checkpoint 并可恢复。

真实数据只能执行无优化器更新的前后向，记录参数 hash、step 调用计数、实际覆盖、Token 数、耗时、内存及失败范围。不能将随机初始化结果称为学习效果，也不能把小景反向通过称为大景训练已验收。已有规范允许的 CPU 合成优化器单步测试与真实数据更新分开计数，不能借合成测试授权运行真实更新。

报告接口确认状态与 PASS/FAIL/BLOCKED，E1 完成后停止。E2 有界真实更新、E3 正式训练均须另获授权；不得复用已停止的历史预算、自动尝试真实训练、删旧检查点或自填批准。
