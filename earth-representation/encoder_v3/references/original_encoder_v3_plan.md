# 0. 研究目标与边界

## 0.1 核心研究目标

训练一个共享的光学遥感 Encoder，使不同卫星、不同波段集合、不同 SRF 和不同 GSD 的真实观测能够进入同一套网络，得到具有共同地表信息、同时允许保留观测差异的潜在表示。

研究假设为：

- 真实地表经过不同传感器观测，形成不同的反射率影像产品。
- Encoder 根据观测数据及其可获取的物理条件，学习不同观测之间可共享的光谱—空间信息。
- 不同观测得到的潜在表示应具有可利用的共同地表信息，但不要求数值完全相同，也不要求不同传感器的信息差异全部消失。
- 训练辅助 Decoder 从 Encoder 的 Z、Token 空间支持和目标波段 SRF 条件中读取信息，预测目标网格上的原始反射率像元。
- 最终下游任务直接使用 Encoder 表示；预训练 Decoder 不属于下游必需结构。

本研究不是灾害专用表征。灾害分割、变化检测和其他地物任务属于后续下游评价。

## 0.2 本阶段数据范围

| 数据来源 | 在本阶段中的角色 | 使用要求 |
|---|---|---|
| Sentinel-2 | 光学多光谱观测 | 使用可核验的反射率产品、原生波段网格和真实 SRF |
| Landsat 8/9 | 光学多光谱观测 | 使用可核验的反射率产品、原生波段网格和真实 SRF |
| EnMAP | 光学高光谱观测 | 作为普通训练观测进入 Encoder，不作为 S2/Landsat 的专属教师或桥梁 |
| WorldView 等高分辨率光学数据 | 后续可扩展来源 | 数据、反射率标定和 SRF 可核验后再纳入正式训练 |
| SAR | 本阶段范围之外 | 不进入本版网络与训练 |

EnMAP 不承担把 S2 与 Landsat 转换到共同光谱空间的桥梁职责。它作为一种独立光学观测参与训练；是否有足够可用数据，依据实际数据清单判断。

HLS 是经过协调处理的派生产品，不作为一种独立卫星传感器，也不作为真实 S2/Landsat 观测的替代标签。若用于辅助数据检查或单独基准，必须保留其产品来源和协调处理属性，不得将 HLS 结果当成独立传感器观测来证明跨传感器统一。

## 0.3 输入与网络不得使用的语义捷径

模型不把卫星名称、产品名称或人为 Band ID 当作学习式语义嵌入。模型使用的是可解释的观测条件：

- 真实反射率；
- SRF 响应曲线；
- 波长及带宽等可从 SRF 获得的描述；
- 横纵 GSD；
- 原生空间网格与地理位置；
- 有效像元状态。

采集时间、产品处理级别、数据来源等信息用于数据审计、配对筛选和结果解释。**采集时间不作为 Encoder 的输入条件**，以保持本研究定义的时间无关观测编码目标。

不要求所有输入拥有相同波段数量、相同 SRF 采样点数量、相同 GSD、相同影像尺寸或相同 Token 数量。

## 0.4 明确不纳入本版的设计

以下内容不属于 V3 已批准结构：

- 固定数量的空间统计量；
- 固定数量的波段或固定波段顺序语义；
- 将所有输入强制重采样到同一 GSD 后再编码；
- 固定数量的 Encoder Query 或人工锚点集合；
- 固定 Token 总预算；
- 固定最大空间支持范围；
- 未经论证的 GSD 幂律公式或固定 GSD 档位；
- 默认八个卷积基；
- 未经验证的固定抗混叠滤波；
- 为了降低损失而绕过共享潜在表示的局部特征旁路；
- 未定义观测依据的 PINN 或额外物理损失；
- 将 EnMAP 设为其他卫星的唯一监督教师。

如实施中认为必须增加其中任何一项，先提交设计变更及其对研究假设的影响，未经确认不得进入正式代码和训练。

# 1. 总体架构

## 1.1 固定数据流

```text
各来源原生光学反射率观测
        │
        ├── 每条波段的 SRF / 波长 / 带宽 / GSD
        │                 │
        │          连续物理条件编码
        │                 │
        │          共享 Hypernetwork
        │                 │
        │          生成条件化投影参数
        │
        ▼
每条波段在自身原生网格上执行动态卷积
        │
        ▼
每条波段独立执行 GSD 条件化的可学习局部 Merge
        │
        ▼
形成数量可变、空间支持可追踪的 Sub-patch
        │
        ▼
每个 Sub-patch 形成 128 维 Token
        │
        ▼
不同波段 Token 合并为可变长度序列
        │
        ▼
共享空间—光谱 Transformer
        │
        ▼
统一潜在表示 Z：[N, 128]
        │
        ├── 训练辅助 Decoder：空间索引读取 Z + 目标 SRF 条件 + 共享像元 MLP → 反射率
        │
        └── 下游任务头：直接读取 Z
```

## 1.2 已确定的架构约束

| 模块 | 已确定要求 |
|---|---|
| 输入 | 各波段原生反射率及真实物理条件 |
| 条件编码 | 连续数值波长/SRF 编码，GSD 条件参与 |
| Hypernetwork | 跨卫星、跨波段共享，不建立卫星专用 Hypernetwork |
| 初始特征 | 条件化动态卷积 |
| 空间处理 | 每条波段独立进行 GSD 条件化的可学习局部 Merge |
| Sub-patch | 保留局部特征及真实空间支持 |
| Token 宽度 | 固定 128 维 |
| Token 数量 | 随实际输入与 Merge 结果变化 |
| 主干 | 一套共享空间—光谱 Self-Attention Transformer |
| Encoder 输出 | 可变长度 `[N,128]` |
| Decoder | 训练辅助模块，可从下游模型中卸载 |
| 下游 | 直接使用 Encoder 的 Z |

# 2. 数据输入与观测记录

## 2.1 单波段输入对象

每条波段必须保留自己的原生网格，不在 Encoder 输入阶段统一重采样。

```python
@dataclass
class BandObservation:
    reflectance: Tensor           # [H, W]，真实反射率
    valid_mask: BoolTensor        # [H, W]，QA/有效性
    srf_wavelength_nm: Tensor     # [M]，真实 SRF 采样波长
    srf_response: Tensor          # [M]，相对响应
    gsd_x_m: float
    gsd_y_m: float
    crs: str
    affine: Affine
    acquisition_time: datetime    # 审计和配对筛选，不输入 Encoder
    product_level: str            # 审计字段
    reflectance_scale: float      # 产品标定/缩放记录
    source_record_id: str         # 数据追溯字段
    band_record_id: str           # 数据追溯字段，不作为语义嵌入
```

一个观测可以包含不同数量的 `BandObservation`。不同波段可以拥有不同的 H、W、GSD、SRF 采样点数和空间网格。

## 2.2 数据质量检查

数据进入训练清单前必须完成：

1. 确认反射率产品级别、缩放系数、单位和 QA 规则。
2. 确认每条波段对应的 SRF 来源及适用传感器/产品。
3. SRF 波长统一使用 nm；采样波长有序，响应值合法，响应积分面积有效。
4. 记录 GSD 的横纵值，不将非整数 GSD 四舍五入成预设档位。
5. 保存 CRS、Affine、实际空间覆盖和有效像元比例。
6. 记录采集时间、产品处理级别和数据来源，以便审计跨源配对。
7. 检查不同观测的空间重叠、时间差和明显地表变化风险。

SRF 缺失或来源不可靠时，不得伪造 SRF，也不得用卫星名称或 Band ID 代替。该观测暂不进入依赖 SRF 的正式训练路径，列入数据缺口报告，等待真实物理资料或经确认的处理方案。

## 2.3 跨源观测配对清单

跨源训练与跨源 JEPA 需要真实的空间重叠观测。配对清单至少记录：

- 输入观测 ID 和目标观测 ID；
- 各自的采集时间；
- 两者地理重叠范围；
- 两者有效像元覆盖；
- 目标与输入的 GSD、SRF 和波段集合；
- 时间差及地表变化风险；
- 配对是否通过训练使用条件。

配对的采集时间不要求被输入 Encoder。时间信息只用于判断两次观测能否作为同一地表状态的近似多视角样本。存在明显地表变化、云/阴影差异或空间覆盖不可靠的区域，不得作为跨源一致性目标。

不预设一个未经数据审计的统一时间间隔阈值；阈值须根据数据来源、时间差分布和地表变化检查在数据配置中冻结。

# 3. SRF 连续编码与 Hypernetwork

## 3.1 SRF 编码方式

每条波段的 SRF 由一组真实采样点组成：

- 波长 `λ_i`；
- 相对响应 `r_i`。

编码过程：

1. 统一波长单位为 nm。
2. 将真实波长数值输入共享的可学习波长编码器。
3. 波长编码器对每个采样点产生特征。
4. 根据 SRF 响应值及相邻采样点的实际波长间隔，对特征进行加权数值积分。
5. 按 SRF 总响应面积归一化，得到该波段的 SRF 条件向量。
6. 将 SRF 条件向量与 GSD 条件共同提供给共享 Hypernetwork。

示意：

```text
(λ1,r1), (λ2,r2), ... (λM,rM)
                │
                ▼
       共享波长编码器
                │
                ▼
        每个采样点的特征
                │
                ▼
   按 SRF 响应与波长间隔加权积分
                │
                ▼
          SRF 条件向量
                │
                ├── GSDx
                └── GSDy
                │
                ▼
       共享 Hypernetwork
```

SRF 采样点数量 M 不固定。不得先把所有 SRF 强制插值为固定数量的波段，也不得把 SRF 简化成仅有中心波长的类别标签。

中心波长和带宽可由 SRF 计算并作为辅助描述；它们不能替代完整 SRF 曲线。

## 3.2 Hypernetwork 的职责

本版 Hypernetwork 的明确职责是：根据每条输入波段的 SRF 和 GSD 等物理条件，生成该波段原生动态卷积所需的参数。

```text
输入波段 SRF + GSD
        │
        ▼
共享物理条件编码
        │
        ▼
输入侧 Hypernetwork
        │
        ▼
该波段动态卷积参数
```

要求：

- 所有卫星、所有输入波段共享同一个物理条件编码网络和输入侧 Hypernetwork。
- 不创建 S2、Landsat、EnMAP 各自独立的 Hypernetwork。
- 不默认设置八个卷积基。
- Hypernetwork 不直接变换反射率影像；它只生成动态卷积使用的参数。
- **反射率 Decoder 不调用 Hypernetwork，也不生成自己的动态卷积核或目标读出权重。** Decoder 将目标 SRF 条件作为普通输入特征，由共享 Decoder 参数完成条件化读取。
- Decoder 可以复用本节的 SRF 条件编码结果，但这不等于调用 Hypernetwork。

输入动态卷积的参数生成机制与 Decoder 的目标条件读出属于不同功能。当前没有证据要求二者必须由同一个 Hypernetwork 生成参数，因此不把输入/输出参数生成共享写成 Decoder 的强制结构。

## 3.3 条件编码验收

- 同一条 SRF 以不同采样密度表达时，编码结果在数值积分误差范围内保持一致。
- 不同带宽、不同响应形状的 SRF 能够形成可区分的条件表示。
- 非整数 GSD 以真实数值进入条件编码。
- 输入端与目标端调用同一个共享 Hypernetwork 参数实例。
- 条件编码和动态参数生成具备梯度。
- 不读取卫星名称、产品名或固定 Band ID 作为学习条件。

# 4. 原生动态卷积

## 4.1 运算对象

每条波段独立执行动态卷积：

```text
BandObservation.reflectance [H,W]
              │
              ├── SRF/GSD → Hypernetwork → 卷积权重
              │
              ▼
         动态卷积
              │
              ▼
     局部特征图 [H1,W1,C_local]
```

卷积权重由物理条件决定；同一波段的原生像元使用该波段生成的卷积参数。

## 4.2 实现要求

- 使用真实反射率，不先将不同传感器重采样到同一空间分辨率。
- 每条波段在自身原生网格上计算。
- 不同波段共享动态卷积生成机制和卷积计算定义。
- 有效性掩码必须随卷积传播；无效值不能被当成真实反射率。
- 对超大影像允许分块计算。分块必须读取卷积与后续局部 Merge 所需的真实重叠邻域，输出核心区域，避免块边界伪影。
- 不增加固定十维统计量或人工光谱特征。

卷积核大小、步长和局部特征通道数尚未由研究讨论最终确定，列为配置冻结项。Agent 可以完成接口、形状测试和候选实现报告，不得自行把某个候选写成最终架构。

# 5. GSD 条件化的可学习局部 Merge

## 5.1 模块职责

每条波段的动态卷积特征图独立进入局部 Merge。Merge 在该波段自身空间网格上学习邻近局部特征的组合，形成 Sub-patch。

```text
波段 A：局部特征图 ──> GSD 条件化 Merge ──> N_A 个 Sub-patch
波段 B：局部特征图 ──> GSD 条件化 Merge ──> N_B 个 Sub-patch
波段 C：局部特征图 ──> GSD 条件化 Merge ──> N_C 个 Sub-patch
```

不同波段不要求得到相同数量或相同位置的 Sub-patch。

## 5.2 Merge 的具体操作要求

每个 Merge 操作必须明确：

1. 从当前波段特征图读取哪些相邻局部位置。
2. 这些局部位置各自的真实地理覆盖范围。
3. 如何依据有效掩码排除无效特征。
4. 使用什么可学习参数组合局部特征。
5. Merge 后的特征通道数、空间位置及物理支持如何更新。
6. 如何将 GSD 条件传递到局部处理过程。

Merge 是空间局部特征聚合，不是先提取固定统计量再做 MLP。局部特征应通过可学习的特征组合形成新的 Sub-patch。

## 5.3 GSD 自适应要求

- 使用真实连续 GSD 数值，不将 GSD 映射到固定卫星类别。
- 每条波段独立进行尺度处理。
- GSD 影响局部 Merge 的处理方式和空间聚合程度。
- 允许 0.37 m、1.21 m 等非整数 GSD。
- 不规定所有波段相同的 Merge 次数。
- 不规定固定 Token 总预算、每波段 Token 预算或最大物理支持范围。
- 不创建人工锚点集合。
- 不要求不同波段的 Sub-patch 一一对应。

**Merge 的离散操作级数如何随连续 GSD 变化，是当前尚未冻结的架构细节。** 不使用未经验证的幂律公式，也不由 Agent 自行创建 GSD 档位。实施者须先提交具体的 GSD 条件化 Merge 方案，说明其如何处理任意非整数 GSD、局部窗口如何变化、输出空间支持如何计算；经确认后再实现正式版本。

## 5.4 Sub-patch 必须携带的信息

每个 Sub-patch 至少保留：

- 可学习局部特征；
- 所属原始波段的物理条件；
- 实际地理覆盖范围；
- 聚合后的空间支持；
- 源 GSD；
- 有效性状态。

这些是特征的来源和空间定位信息，不是额外的人工统计量。

## 5.5 通道要求

- 最终 Token 宽度固定为 128。
- 中间局部特征通道宽度尚未确定。
- 最后一级 Merge 可以直接输出 128 维。
- 若 Merge 输出尚非 128 维，则通过共享投影映射到 128 维。
- 不设置无意义的“先降回较小通道，再立即升回 128”的重复转换。

# 6. Token 形成与共享 Transformer

## 6.1 Token 形成

每个有效 Sub-patch 对应一个 Token。

```text
Sub-patch 1 ──> 128 维 Token
Sub-patch 2 ──> 128 维 Token
Sub-patch 3 ──> 128 维 Token
...
Sub-patch N ──> 128 维 Token
```

不同波段的 Token 合并为同一个可变长度序列：

```text
N = N_band_1 + N_band_2 + ... + N_band_C

Encoder 输入：[N,128]
Encoder 输出：[N,128]
```

N 随输入波段数量、原生影像尺寸和各波段 Merge 结果变化。模型参数不随 N 创建新的全连接层。

## 6.2 Token 元数据

每个 Token 保留：

- 地理位置；
- 实际空间覆盖范围；
- 源 GSD；
- Sub-patch 聚合尺度；
- SRF 条件；
- 有效性状态。

这些信息用于空间关系建模与 Token 定位。Decoder 只读取 Token 的地理覆盖范围、中心位置和有效性，不读取 Merge 层级、父子分组或内部计算记录。卫星名称和 Band ID 只用于审计，不进入语义嵌入。

## 6.3 Transformer

使用一套共享空间—光谱 Transformer，对全部可见 Token 进行 Self-Attention。

它需要学习：

- 同一波段不同空间位置的关系；
- 不同波段之间的光谱关系；
- 不同 GSD Token 之间的空间关系；
- 不同观测来源之间可共享的地表信息。

不同波段的 Sub-patch 不要求先对齐到固定空间网格。空间关系使用真实地理位置与空间支持建立。

Transformer 的具体稀疏计算方式、层数、Heads 和 FFN 宽度须在工程预检前冻结。稀疏化不得静默删除某些波段或固定数量的 Token；若计算成本要求改变邻域组织，必须报告实际被保留和未参与交互的 Token 关系。

## 6.4 Encoder 输出

```python
@dataclass
class EncoderRepresentation:
    tokens: Tensor             # [N,128]
    footprints: Tensor         # 每个 Token 的真实空间支持
    positions: Tensor          # 地理位置
    gsd_xy: Tensor             # 来源 GSD
    support_xy: Tensor         # 聚合后的空间支持
    srf_condition: Tensor      # 对应波段的物理条件
    valid: BoolTensor
```

Encoder 不输出固定长度的全局向量替代全部 Token。下游可以根据任务需要设计自己的解码器或任务头。

# 7. A/B 共用的解耦式反射率 Decoder

## 7.1 Decoder 的唯一目标

Decoder 的目标是：**从 Encoder 输出的潜在 Token 中读取信息，预测指定目标波段、指定目标空间网格上的原始反射率像元。**

Decoder 不负责恢复 Sub-patch、Token 或 Merge 中间特征，也不负责逆向执行 Encoder 的卷积和 Merge。

A、B1、B2 共用同一个反射率 Decoder。三项任务改变的是可见输入、目标波段和目标像元集合，不改变 Decoder 的主体结构。

Decoder 的任务定义：

| 任务 | Encoder 可见输入 | Decoder 预测目标 | 监督范围 |
|---|---|---|---|
| A：空间遮盖恢复 | 空间遮盖后得到的可见 Token | 原观测中被遮盖区域的全部目标波段反射率 | 仅被遮盖且有效的像元 |
| B1：同源波段遮盖恢复 | 随机隐藏一个或多个完整波段后的可见 Token | 同一观测中被隐藏波段的完整原生网格反射率 | 仅被隐藏且有效的波段像元 |
| B2：跨传感器观测恢复 | 来源传感器的可见 Token | 配对目标传感器在其原生网格上的真实反射率 | 目标观测中有效且空间重叠的像元 |

A 和 B1 属于 MAE 式掩码重建目标；B2 是基于真实配对观测的跨传感器重建目标，不称为经典 MAE。

## 7.2 Decoder 与 Encoder 的接口

Decoder 只接收以下信息：

**Encoder 提供：**

- `Z`：可变数量的 128 维 Token，形状为 `[N,128]`；
- 每个 Token 的真实地理空间覆盖范围；
- 每个 Token 的空间中心；
- Token 有效性标记。

**目标观测提供：**

- 目标像元的地理空间覆盖范围；
- 目标像元中心；
- 目标波段的 SRF 条件编码；
- 目标像元有效性标记。

目标 SRF 条件编码复用第 3.1 节已有的连续 SRF 编码器。A/B1 的目标 SRF 来自被遮盖的原始波段元数据；B2 的目标 SRF 来自目标传感器的真实波段元数据。

使用共享标量反射率输出头时，必须让 Decoder 知道当前要预测哪一种光谱响应。因此目标 SRF 是必要的目标条件，但不需要新的 Decoder Hypernetwork，也不生成动态卷积核。

目标 GSD 不再作为一份独立的学习式条件向量输入 Decoder。目标像元的实际地理覆盖范围已经表达了其空间支持大小；源 Token 的空间覆盖范围表达了 Encoder 特征的支持大小。

**Decoder 不接收：**

- Encoder 的 Merge 层级；
- Merge 父子树或内部分组记录；
- 动态卷积中间特征；
- 原始输入反射率旁路；
- 卫星名称、产品名称或人工 Band ID；
- Encoder 的内部模块配置。

因此，只要新的 Encoder 仍输出 `Z` 和每个 Token 的地理空间覆盖范围，Decoder 不需要因 Encoder 内部卷积或 Merge 结构变化而修改。

## 7.3 像元级预测的具体操作

Decoder 采用**空间索引读取 + 几何加权聚合 + 共享 MLP**。不使用 Cross-Attention，不建立学习式 Query，不执行 Unmerge。

对每一个目标像元，按以下步骤执行：

1. 根据目标影像的 CRS、地理变换参数和行列号，得到目标像元的地理覆盖范围及中心坐标。
2. 使用空间索引，从 Encoder Token 中检索与目标像元空间相关的有效 Token。
3. 对每个候选 Token，计算目标像元中心相对于该 Token 空间中心的横向、纵向偏移，并按 Token 的空间覆盖宽高归一化。
4. 根据实际空间重叠面积或空间距离计算确定性的几何权重，对候选 Token 特征进行加权聚合。
5. 将聚合后的 128 维特征、归一化相对位置和目标 SRF 编码输入共享 MLP。
6. MLP 输出一个目标波段、一个目标像元的反射率。

```text
Encoder Z：[N,128]             目标像元网格
Token 空间覆盖范围              目标像元中心/覆盖范围
        │                              │
        └──────────┬───────────────────┘
                   ▼
             空间索引检索
                   │
                   ▼
       候选 Token + 相对位置 + 几何权重
                   │
                   ▼
           几何加权特征聚合
                   │
                   ▼
     [128维聚合特征, 相对位置, 目标SRF编码]
                   │
                   ▼
             共享轻量 MLP
                   │
                   ▼
             一个像元的反射率
```

A、B1、B2 的候选 Token 检索规则：

- **A：**目标空间区域已从 Encoder 输入中遮盖，因此不能读取目标位置的 Token。使用遮盖区域边界外可见的空间邻接 Token；若目标位置处于影像边缘，则使用该位置可获得的有效邻接 Token。候选集合由真实空间邻接关系确定，不设固定物理半径、不设固定 Token 数量。
- **B1：**从未被隐藏的其他波段 Token 中，检索与目标波段像元空间覆盖范围重叠的 Token。不同波段 GSD 和原生网格不同，使用真实地理覆盖范围匹配，不使用数组索引直接对齐。
- **B2：**从来源传感器的 Token 中，检索与目标传感器像元空间覆盖范围重叠的 Token。目标像元比来源 Token 更细时，可以由同一来源 Token 为多个目标像元提供特征；目标像元比来源 Token 更粗时，可以聚合多个重叠 Token。

若目标像元没有任何合格的可见 Token 支持，则该像元不参与本次损失，并记录为无有效支持像元。不得用目标反射率或其他未经批准的数据旁路填补。

A 的可见 Token 已经过 Encoder Transformer 的上下文交互，因此邻接 Token 不仅包含自身局部信息，也包含 Encoder 从其他可见 Token 学到的上下文信息。

### 共享 MLP

首版采用两层共享 MLP：

```text
输入：[128维聚合特征 + 2维归一化相对位置 + D_srf维目标SRF编码]
      │
      ▼
Linear → GELU
      │
      ▼
Linear → 1
      │
      ▼
目标像元反射率
```

MLP 参数在 A、B1、B2、所有卫星和所有波段之间共享。输出为单个反射率标量，不按卫星名称或 Band ID 建立独立输出头。

具体隐藏宽度列为实现配置项，在小规模预检中冻结；不得因此增加 Transformer Decoder 或 Hypernetwork。

## 7.4 A、B1、B2 如何使用同一个 Decoder

**A：空间遮盖恢复**

- 目标波段来自原始观测中被遮盖的波段。
- 目标 SRF 编码来自这些波段的真实 SRF。
- 目标像元来自被遮盖空间区域的原生像元网格。
- Decoder 从遮盖区域边界外的可见 Token 读取上下文。
- 输出被遮盖区域中各波段的像元反射率。
- 只在被遮盖且有效的目标像元上计算损失。

**B1：同源波段遮盖恢复**

- 目标波段是随机隐藏的完整波段。
- 目标 SRF 编码来自被隐藏波段的真实 SRF。
- 目标像元来自被隐藏波段的原生网格。
- Decoder 从剩余可见波段的空间重叠 Token 读取信息。
- 输出被隐藏波段的完整原生网格反射率。
- 只在被隐藏且有效的目标像元上计算损失。

**B2：跨传感器观测恢复**

- 目标波段来自真实配对的目标传感器观测。
- 目标 SRF 编码来自目标传感器的真实 SRF。
- 目标像元来自目标传感器的原生网格。
- Decoder 从来源传感器的空间重叠 Token 读取信息。
- 输出目标传感器真实观测网格上的反射率。
- 只在目标观测有效且空间配对合格的像元上计算损失。

## 7.5 输出网格与 GSD

训练监督使用真实目标观测的原生像元网格：

- A：被遮盖输入观测的原生网格；
- B1：被隐藏波段的原生网格；
- B2：配对目标传感器的原生网格。

推理时可以由调用方指定请求输出网格。目标像元覆盖范围由请求网格直接计算，Decoder 使用相同的空间索引和 MLP 接口。

请求输出网格不同于真实传感器原生网格时，输出是模型在指定空间支持上的条件预测，不自动等于该传感器的真实观测，也不证明模型恢复了目标传感器未采样到的空间细节。

例如，S2 输入后请求 Landsat 条件下的 10 m 网格，不得把插值后的 Landsat 10 m 影像当作真实 10 m 监督标签。B2 的直接反射率监督仍使用 Landsat 真实原生网格。

## 7.6 损失与数据隔离

- A 只在空间遮盖区域内的真实有效像元上计算反射率损失。
- B1 只在被隐藏波段的真实有效像元上计算反射率损失。
- B2 只在真实配对目标观测的有效空间重叠像元上计算反射率损失。
- 各目标波段先独立计算误差，再按冻结的样本/波段聚合规则组合，避免高分辨率来源仅因像元数量多而支配总损失。
- Decoder 不增加未经确认的物理损失，也不通过额外平滑项掩盖恢复误差。
- 目标像元真实反射率只用于监督，不进入 Encoder、空间检索特征、MLP 输入或几何权重计算。

## 7.7 Decoder 的明确非目标

首版不包含：

- Decoder Hypernetwork；
- 动态输出卷积核；
- 目标传感器专属 Decoder；
- 每个卫星独立的输出头；
- Cross-Attention 或多层 Transformer Decoder；
- 学习式目标 Query；
- 固定数量的 Latent Query、人工 Anchor 或固定数量的候选 Token；
- 固定物理半径的空间检索；
- Merge 层级、父子树或 Unmerge；
- 原始影像或 Encoder 中间特征旁路；
- 未经验证的物理约束损失。

Decoder 的职责限定为：空间索引读取 Encoder Token、几何加权聚合、共享 MLP 输出反射率。若该结构不能完成任务，先检查 Encoder 信息保留、掩码泄漏、空间支持匹配和训练目标；不得直接扩展 Decoder 复杂度来掩盖问题。

# 8. A/B 预训练任务

A/B 是联合训练的两种互补目标。两者始终属于同一 Encoder 预训练过程，使用同一套共享参数；课程学习通过损失权重调整两者的训练侧重点。

## 8.1 A：空间遮盖像元恢复（MAE 式目标）

### 训练目标

隐藏一部分空间 Sub-patch 对应的地理区域，让 Encoder 只能使用可见空间 Token，恢复被遮盖区域中各目标波段的原始像元反射率。A 采用 MAE 式掩码重建目标，但不要求使用原始 MAE 的多层 Transformer Decoder。

### 遮盖单位与执行顺序

A 的遮盖单位是 **Sub-patch 对应的空间支持区域**。遮盖区域按 Token 的真实地理覆盖范围确定；遮盖必须在该区域的反射率值进入动态卷积和 Merge 之前生效，避免局部卷积感受野造成目标泄漏。

执行顺序：

1. 根据原生 GSD 和局部 Merge 规则确定 Sub-patch 的空间划分及真实覆盖范围。
2. 在空间 Sub-patch 层面随机选择需要遮盖的区域。
3. 将这些空间区域映射到所有参与本次 A 任务的波段原生网格。
4. 遮盖区域内的真实反射率只进入独立 Target，不进入 Student 的动态卷积、Merge、Token 或 Transformer 数值路径。
5. 对卷积和 Merge 感受野可能跨越遮盖边界的情况，必须进行掩码传播。任何可见 Token 的输入感受野若读取了隐藏目标值，该 Token 不得作为可见 Student Token；实现可以采用掩码感知局部计算，但不得发生目标泄漏。
6. 只把可见 Token 送入 Student Encoder。
7. Decoder 根据 Z、隐藏像元的空间覆盖范围及目标波段 SRF 编码，检索遮盖区域边界外的可见 Token，经几何加权聚合和共享 MLP，预测隐藏区域内各目标波段的原始像元反射率。
8. 使用隐藏区域内真实、有效的反射率计算 A 损失。

### A 的空间一致性

本次 A 遮盖区域在参与任务的波段之间按地理位置对应，使模型不能通过另一条未遮盖波段直接读取相同位置的隐藏目标。

各波段的像元网格可以不同。遮盖依据地理覆盖范围映射，不使用不同数组中相同的像素索引冒充同一地理位置。

### A 的待冻结参数

空间遮盖比例、遮盖区域形状/尺度、每次任务的遮盖数量和目标像元采样方式需要在预检后冻结。不得在正式训练中隐藏默认值或临时改变。

## 8.2 B：随机波段遮盖恢复（B1 为 MAE 式目标）

### 训练目标

给定随机保留的可见波段集合，恢复被隐藏波段在其真实原生空间支持上的反射率。

### 随机采样规则

- 每次逻辑优化更新重新采样隐藏波段集合。
- 既有单波段遮盖，也有多波段组合遮盖。
- 被隐藏波段不固定为某一个 Band。
- 不要求每次隐藏相同数量的波段。
- 采样必须保证至少有一个可见波段。
- 隐藏目标波段的真实反射率不得进入 Student Encoder。
- 隐藏目标波段的 SRF 编码和原生空间网格元数据只用于构造 Decoder 的目标；隐藏波段的反射率不得进入 Student Encoder。
- B1 必须在隐藏波段的反射率进入动态卷积及任何跨波段特征聚合之前执行遮盖。不得先进行光谱交互，再仅删除最终融合 Token，否则会发生目标信息泄漏。
- 目标 GSD 不作为独立 Decoder 条件向量；目标像元真实空间覆盖范围用于空间匹配。
- 各波段被选为隐藏目标的次数应被统计，避免某些波段长期没有训练曝光。
- 训练组合随机变化；固定验证组合在训练前确定，训练期间不参与随机采样。
- 断点恢复必须复现相同逻辑更新的隐藏集合。

不把 G5 的“最多隐藏三个波段”固化为 V3 限制。多波段数量根据样本实际波段数及已冻结的采样分布决定，只保留至少一个可见波段这一必要条件。

### B 的两个监督场景

**B1：同一观测内的缺失波段恢复**

输入某一观测的部分可见波段，恢复该观测中被隐藏的一个或多个真实波段。B1 属于 MAE 式的波段级掩码重建：隐藏波段的反射率不进入 Encoder，Decoder 仅在被隐藏波段的有效原生像元上计算损失。

**B2：跨传感器目标观测恢复**

输入一种传感器的观测，使用目标传感器的 SRF 条件和真实目标像元空间覆盖范围，预测空间重叠目标观测中的一个或多个目标波段。B2 是真实配对观测的跨传感器重建，不属于同源 MAE 掩码任务。

B2 使用真实可获取的跨源观测配对。输入与目标可以具有不同波段数、GSD、网格和采集时间。训练配对必须经过时间差、空间重叠及地表变化风险检查。

S2、Landsat 和可用 EnMAP 均作为普通输入/目标来源参与；不指定 EnMAP 为唯一教师，不通过 HLS 构造虚假的原生传感器真值。

如果某类跨源配对数据尚未获得，必须如实报告该类 B2 训练尚未执行。不得将 B1 的同源波段恢复结果描述成已经完成跨卫星观测恢复。

## 8.3 A/B 联合更新

每次逻辑优化更新：

1. 按训练清单抽取一个或多个真实光学观测。
2. 为 B 生成随机单波段或多波段隐藏集合。
3. 构造 B1 或有真实配对时构造 B2 的可见输入和隐藏目标。
4. 构造 A 的空间遮盖任务，确保隐藏区域的目标值不进入 Student 输入。
5. A、B 分别执行 Encoder 前向；共享 Decoder 根据目标像元空间支持检索可见 Token，并执行几何加权聚合与像元级 MLP 预测。
6. 分别计算 A、B1、B2 损失。
7. 根据当前课程权重组合损失。
8. 进行一次共享 Encoder 的优化更新。
9. 记录本次实际观测成员、输入来源、隐藏集合、目标集合、各项损失和梯度信息。

A/B 不拆成两个独立的完整训练阶段。两项任务在联合训练中始终保留有效训练权重。

## 8.4 损失计算与不同数据量平衡

- 只在真实有效目标像元上计算反射率损失。
- 目标反射率采用一致的物理单位和训练集统计量进行误差标准化。
- 先计算单个目标波段的有效像元损失，再按目标波段、观测成员和来源进行分层聚合。
- 不允许高分辨率影像仅凭像元数量更多，就在总损失中自动占据更大权重。
- B1、B2 分别统计；B2 缺席时不得把它的损失记为零。
- 同时记录标准化误差和物理单位 MAE、RMSE、Bias。
- 训练与验证目标像元索引、遮盖集合和样本成员必须可追溯。

## 8.5 A/B 课程权重

课程方向已确定：

- 训练前期 A 空间恢复权重较高，B 波段恢复权重较低。
- 随训练推进，A 权重逐步降低，B 权重逐步提高。
- A、B 在整个课程中均参与训练，不将某一任务完全关闭。
- B1 与 B2 分开记录；有跨源配对时，B2 必须有独立的曝光和验证记录。

具体起始权重、终止权重、课程长度和变化曲线尚未由实验确认，列为训练配置冻结项。不得直接复制 G5 的固定 B 权重，也不得把未经验证的 `1.0 → 0.25`、`0.25 → 1.0` 和固定步数写成最终事实。

# 9. JEPA 辅助潜在预测

## 9.1 JEPA 在本项目中的作用

JEPA 用于辅助 Encoder 学习不同观测之间可共享的潜在信息。它不替代 A/B 真实反射率恢复，也不成为最终下游模型的必需模块。

本项目优先研究**跨传感器多视角 JEPA**：

- Student 接收一种光学观测；
- EMA Teacher 接收同一地理区域的另一种有效光学观测；
- 两者使用同一套 Encoder 架构和共享参数体系；
- Predictor 根据 Student 潜在表示及目标观测条件，预测 Teacher 对应空间支持的潜在特征。

不指定某一传感器为固定教师。不同来源可以交换 Student/Teacher 角色。EnMAP 不承担其他传感器的专属监督职责。

## 9.2 跨源配对

跨源 JEPA 使用真实空间重叠观测。配对筛选遵守第 2.3 节的数据审计要求。

- 采集时间只用于配对质量检查，不作为 Encoder 输入。
- 有明显地表变化风险的区域不用于跨源潜在一致性监督。
- 两个来源保持各自原生网格和真实 GSD。
- 不把一方重采样到另一方网格后，再将同一数组位置视为天然对应 Token。

## 9.3 不同 Token 网格的目标对应

Student 与 Teacher 的 Token 数量、位置和空间支持可以不同。

目标对应通过真实地理空间支持建立：

1. 读取 Student 目标 Token 的地理覆盖范围。
2. 找到 Teacher 中与该空间范围真实重叠的有效 Token。
3. 按实际重叠空间支持组织 Teacher 潜在目标。
4. 目标条件包含目标观测的 SRF/GSD，使 Predictor 知道需要预测哪一种观测条件下的潜在表达。
5. 无有效空间重叠或配对质量不合格的位置不参与 JEPA 损失。

不得使用 Token 数组索引强行配对，不创建固定人工锚点集合。

## 9.4 JEPA Predictor：与反射率 Decoder 分开

JEPA 不调用第 7 节的反射率 Decoder。JEPA 的目标是预测 Teacher 的潜在 Token，而不是输出反射率，因此使用独立、轻量的 Predictor。

```text
Student Encoder：来源观测 A
          │
          ▼
        Z_A
          │
          ├───────────────┐
                          ▼
目标 Teacher Token 的位置/空间支持/SRF/GSD
                          │
                          ▼
                    目标 Query
                          │
                          ▼
              Predictor Cross-Attention
                 Q=目标 Query，K/V=Z_A
                          │
                          ▼
                    轻量 FFN
                          │
                          ▼
                 预测潜在特征 [Q,128]
                          │
                          ▼
                与 EMA Teacher 的 Z_B 比较

EMA Teacher Encoder：来源观测 B → Z_B
                         stop-gradient
```

具体要求：

- EMA Teacher 是 Student Encoder 参数的 EMA 副本，不接收反向传播。
- Predictor 根据 Student 的 Z_A 和 Teacher 目标 Token 的空间支持、目标 SRF/GSD 条件，预测目标位置的 128 维潜在特征。
- Predictor 不读取目标反射率像元值。
- Predictor 输出与被选中的 Teacher 目标 Token 特征比较。
- 目标 Token 的空间对应遵循第 9.3 节的真实地理空间支持关系。
- Predictor 使用独立于反射率 Decoder 的 Cross-Attention、FFN 和输出投影参数。
- 可以复用 SRF 条件编码与位置编码；不共享反射率 Decoder 的输出层。
- Predictor 不使用 Hypernetwork，不生成卷积核或反射率读出权重。

首版 Predictor 采用一个 Cross-Attention 层和轻量 FFN，输出宽度为 128。它的结构目的仅是把 Student 的可见潜在信息映射到目标观测的 Token 支持上，不额外增加潜在状态库、聚类中心或多层复杂解码器。

梯度流向：

- Teacher：stop-gradient；
- Student Encoder：接收 JEPA 损失梯度；
- Predictor：接收 JEPA 损失梯度；
- 反射率 Decoder：不接收 JEPA 损失梯度。

## 9.5 JEPA 启动与权重

JEPA 在 A/B 联合训练已通过稳定性检查后接入。开启 JEPA 后 A/B 继续训练，A/B 课程权重保持在其已确定的课程终点；JEPA 作为辅助损失逐步加入。

JEPA 的起始条件、EMA 系数、预测器结构、潜在损失权重和加入速度均须通过小规模对照试验确定。不得在正式训练中突然加入一个未经验证的大权重。

## 9.6 JEPA 验收

使用相同训练成员、数据配对、随机种子、A/B 课程和训练预算，对比：

- A+B；
- A+B+跨源 JEPA。

分别检查 A、B1、B2、JEPA 潜在预测、冻结 Encoder 表征及下游可用性。

JEPA 只有在跨源表征评价带来可重复收益，且 A/B 真实反射率任务没有持续退化时，才保留为正式训练组成。

# 10. 训练计划与执行策略

## 10.1 训练前置阶段：数据与模型预检

正式训练前完成：

1. 冻结训练/验证/测试数据清单。
2. 检查 S2、Landsat、EnMAP 的实际可用产品、SRF、GSD、反射率标定和 QA。
3. 构建真实跨源空间重叠配对清单。
4. 完成 Hypernetwork 输入/输出共享方式的设计冻结。
5. 完成 GSD 自适应 Merge 具体规则的设计冻结。
6. 完成 Token 组装、空间关系和 Transformer 计算方式的设计冻结。
7. 完成 Decoder 目标条件与输出网格接口。
8. 完成 A/B 隔离、随机采样、固定验证和断点恢复测试。
9. 完成学习率调度器单元测试。
10. 运行小批量固定任务拟合检查，确认 A、B 的目标确实能产生有效梯度和可解释的损失变化。

任一架构关键项仍未冻结时，只允许接口开发和单元测试，不启动完整训练。

## 10.2 A/B 联合训练阶段

训练任务在同一共享 Encoder 上联合执行：

- A：随机空间 Sub-patch Token 遮盖恢复；
- B1：随机隐藏一个或多个同源波段；
- B2：有真实跨源配对时，输入一种来源、恢复另一来源的目标波段。

训练前期 A 权重高、B 权重低；训练推进后 A 权重降低、B 权重提高。课程参数在正式训练前冻结。

每个逻辑更新记录：
- 观测成员与来源；
- A 遮盖区域；
- B 隐藏波段集合；
- B1/B2 任务类型；
- 目标波段和目标网格；
- 各项独立损失；
- 各项权重；
- 梯度范数；
- 优化器学习率；
- Token 数量、有效目标数和运行成本。

## 10.3 如何判断 A/B 稳定

稳定、收敛和平台期必须分开判断。

**训练数值稳定：**
- Loss、梯度和模型参数均为有限值；
- 没有梯度爆炸或持续异常裁剪；
- 训练更新和检查点恢复可复现；
- A/B 的有效目标和数据曝光符合采样记录。

**任务级稳定：**
- A、B1、B2 使用固定验证成员、固定遮盖和固定目标索引；
- 每项任务分别报告验证曲线，不只看总损失；
- 各任务在连续验证窗口内没有超出验证噪声范围的反复大幅波动；
- 没有某项任务持续恶化而被其他任务的改善掩盖；
- 预测方差没有塌缩为近似常数输出；
- 逐波段 Bias、MAE、RMSE 与空间误差图没有显示明显退化。

**优化关系稳定：**
- 在固定诊断批次上分别计算 A、B1、B2 对共享 Encoder 的梯度范数；
- 记录任务梯度方向关系；
- 若某两项任务长期出现明显梯度冲突，并伴随其中一项验证持续恶化，暂停课程推进并诊断；
- 单次梯度方向冲突不直接判定训练失败。

稳定窗口长度、验证噪声阈值和梯度诊断频率须由预检确定并在训练前冻结。不得把某个固定验证次数当成无条件充分证明。

**稳定不等于收敛。** 各项任务仍在稳定改善时，可以继续训练；不要求 Loss 完全不再下降。

## 10.4 平台期、震荡与发散的处理

| 状态 | 判断依据 | 处理 |
|---|---|---|
| 稳定改善 | 固定验证持续改善，任务间无持续退化 | 继续当前课程 |
| 平台期 | 固定验证改善低于由验证噪声确定的有效阈值，持续达到配置规定的观察窗口 | 触发学习率调整 |
| 震荡 | 固定验证反复大幅上/下跳动，超出验证不确定性；或任务间出现持续冲突和退化 | 保存检查点，固定输入复测，按任务/梯度/数据顺序诊断 |
| 发散 | Loss、梯度或参数出现 NaN/Inf | 立即停止当前更新，保存故障状态并定位首次异常 |
| 过拟合 | 训练损失持续改善而固定验证持续恶化 | 停止盲目增加步数，检查数据划分与模型泛化 |
| 人工终止 | 用户主动结束运行 | 记录为人工终止，不称为收敛或算法早停 |

震荡诊断顺序：

1. 用同一检查点、同一验证成员、同一遮盖和目标索引重复验证。
2. 确认验证模式关闭随机增强、Dropout 等训练随机性。
3. 分解 A、B1、B2 以及逐来源、逐波段曲线。
4. 检查任务梯度范数、梯度方向和裁剪频率。
5. 检查异常更新对应的波段数量、有效覆盖、SRF/GSD、目标覆盖和观测成员。
6. 确认问题来自优化过程后，再调整学习率或任务权重。
7. 调整后使用同一固定验证面板复核。
8. 若问题仍持续，停止本次运行并形成诊断报告，不以增加训练步数代替诊断。

## 10.5 学习率与调度器

G5 的训练出现后期震荡，且学习率没有触发变化。G5 的最终记录不足以确认未触发的具体原因，因此 V3 必须把调度器行为作为独立验收对象。

要求：

- 使用固定验证指标驱动学习率调整。
- 固定验证指标不得随着 A/B 课程权重变化而改变定义。
- 改善阈值根据固定验证重复评估的波动确定。
- 平台观察窗口、衰减因子、最低学习率和 Warmup 长度必须在预检后冻结。
- 每次调度记录当前指标、历史最佳指标、改善量、阈值、连续平台次数、调整前 LR、调整后 LR。
- 一旦满足预先冻结的调度条件，必须检查优化器参数组中的实际 LR 是否变化。
- 若条件已满足但实际 LR 未改变，标记为调度器错误并停止继续训练，不能静默运行。
- 断点恢复后，调度器最佳值、平台计数和 LR 必须与中断前状态一致。

优化器可使用 G5 的 AdamW 作为首轮参考。初始 LR、weight decay、梯度裁剪、Warmup 和批量组织通过小规模预检确定，不直接把 G5 数值当作 V3 已验证配置。

## 10.6 验证面板

训练前固定并持续复用：

| 面板 | 目的 |
|---|---|
| A-spatial | 空间 Token 遮盖恢复 |
| B1-single | 同源单波段缺失恢复 |
| B1-multi | 同源多波段组合缺失恢复 |
| B2-cross-source | 输入一种传感器、预测另一种传感器 |
| Unseen-band-combination | 训练中未出现的波段组合 |
| Cross-resolution | 不同输入 GSD 下的目标条件恢复 |
| Frozen representation | 冻结 Z 后的特征可用性 |

每个面板保存固定成员、遮盖、目标索引、目标网格和数据处理版本。验证不得在训练过程中临时换样本后继续拼接成同一条曲线。

## 10.7 检查点与恢复

完整检查点至少保存：

- Encoder 全部参数；
- SRF 编码器和共享 Hypernetwork；
- 动态卷积与 Merge 参数；
- Transformer 参数；
- 训练 Decoder；
- JEPA Predictor 与 EMA Teacher（启用后）；
- 优化器与调度器状态；
- 随机数状态；
- 当前逻辑更新计数；
- A/B 课程进度；
- 当前最佳验证指标；
- 固定数据清单 ID；
- 配置文件与代码提交标识。

恢复后，下一次逻辑更新的观测成员、遮盖集合、目标像元采样、课程权重和学习率状态必须与未中断运行一致。

# 11. 评价与研究结论

## 11.1 反射率恢复评价

对 A、B1、B2 分别报告：

- 标准化 NMSE；
- 物理单位 MAE；
- RMSE；
- Bias；
- 预测方差与目标方差；
- 空间误差分布；
- 逐来源、逐波段、逐 GSD 结果。

同时与项目中已经使用过的空间插值和 Ridge 光谱回归基线进行同条件比较。比较必须使用相同的有效目标、空间支持和训练/验证划分。

## 11.2 跨传感器评价

必须分别检查：

- S2 输入 → Landsat 目标；
- Landsat 输入 → S2 目标；
- 可用 EnMAP 输入/目标参与的跨源方向；
- 不同 GSD 的输入与目标组合；
- 不同波段集合和未见波段组合。

评价时区分目标传感器原生观测网格与请求输出网格。不能把插值网格上的预测误差解释成目标传感器原生分辨率的真实恢复能力。

## 11.3 Encoder 表征评价

冻结 Encoder，卸载训练 Decoder，检查 Z 是否保留了可供下游利用的信息。

至少包括：

- 冻结特征探针；
- 不同来源输入的特征可用性；
- 不同波段缺失情况下的特征稳定性；
- 不同 GSD 下的空间信息保留；
- 在已有数据和任务条件下接入灾害分割等下游任务。

反射率恢复表现不能单独证明下游语义表征有效。下游评价必须独立报告。

| A 任务 | 空间遮盖比例、区域形状/尺度、遮盖数量、感受野泄漏处理实现 |
| B 任务 | 单/多波段采样分布、组合曝光平衡策略、B1/B2 采样比例 |
| A/B 课程 | 起始权重、终止权重、课程长度、权重变化曲线 |
| 优化 | 初始 LR、Warmup、weight decay、梯度裁剪、有效 batch 组织 |
| 稳定性 | 固定验证间隔、稳定观察窗口、验证不确定性阈值、平台期判断规则 |
| JEPA Predictor | Cross-Attention heads、FFN 宽度、EMA 系数、潜在损失权重、加入速度、配对目标组织 |
| 运行 | 检查点间隔、计算资源上限、总预算与停止条件 |

配置文件必须区分：

- `confirmed`：已达成共识的设计；
- `candidate`：已有候选但尚未冻结；
- `required_before_training`：正式训练前必须确认的项目。

如果 `required_before_training` 字段缺失，训练入口应中止并输出待确认清单。

# 14. 最终验收标准

V3 的成功不能仅定义为 A/B 重建损失下降。

必须分别给出以下结论：

1. **输入适配能力**：不同波段数、不同 SRF、不同 GSD 和不同原生网格能否进入同一共享 Encoder。
2. **信息保留能力**：Z 是否能支持真实空间遮盖恢复和缺失波段恢复。
3. **跨传感器能力**：输入一种传感器，是否能利用目标 SRF/GSD 条件预测另一种传感器的真实观测表达。
4. **潜在表示能力**：跨源 JEPA 是否使不同观测的潜在信息更具可预测性和可迁移性，同时保留目标观测差异。
5. **Encoder 独立价值**：卸载 Decoder 后，冻结 Z 是否仍能支持下游特征探针和实际下游任务。
6. **训练可靠性**：A、B1、B2 的任务级稳定性、学习率调度、震荡诊断和检查点恢复是否有完整证据。

最终结论必须区分：

- 同源波段恢复成功；
- 跨源目标恢复成功；
- 潜在表示跨源关系改善；
- 冻结特征具备下游可用性。

这些结论不能相互替代。

## 执行总原则

本版模型的固定主链路为：

**真实光学观测与 SRF/GSD 条件 → 共享 Hypernetwork → 每波段原生动态卷积 → GSD 条件化可学习局部 Merge → 可变数量的 128 维 Sub-patch Token → 共享空间—光谱 Transformer → 统一潜在表示 Z。**

训练采用：

**A：空间 Token 遮盖恢复；B1：随机同源单/多波段遮盖恢复；B2：真实跨传感器观测恢复；JEPA：跨源潜在预测辅助目标，使用独立 Predictor，不调用反射率 Decoder。**

A/B 通过共享的空间索引读取、几何加权聚合和像元级 MLP Decoder，从 Z 恢复被遮盖或目标观测的原始反射率；Decoder 不依赖 Encoder 的 Merge 层级或内部特征。JEPA 使用独立 Predictor 预测 Teacher 潜在 Token。最终下游直接使用 Z。

未确定的 Merge 级数机制、Hypernetwork 输入/输出参数生成共享方式和其他数值参数，必须在对应阶段明确并冻结。不得把工程默认值、未经验证的假设或临时实现写成已经达成的研究设计。
