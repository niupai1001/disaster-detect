# V3-FR 实现与效果验收

## 实现验收

本轮使用历史 Run `83f833a1ef5e4515825c1457b6e4278d` 的真实冻结发布。176 个文件逐字节核对，best/last 的参数与绑定一致，seed 17 随机初始化重新计算并匹配。原始冻结配置与此前去敏的 GitHub 副本分别处理。本地原始源码的 Git HEAD 为 `f623efa`，设计引用的远端开发提交为 `d330714`，实际基线由发布清单和权重共同绑定。[身份与源码](../baseline_identity.json)

完整验证重新执行，383 条观测的 A/B1 MSE 为 0.34913589 / 0.39939317，高纹理梯度 MSE 为 0.14973579 / 0.06137363。766 条任务观测、3,133 条目标波段与冻结掩码一致。真实固定样本分别扰动隐藏目标与 QA 无效值，共 20 次检查通过。隐藏目标只改变监督损失，QA 无效值不改变损失。32 条和 18 条真实批次均完成单卡、双卡、历史 CUDA 图的梯度与 AdamW 更新对照。[复算](../s1_baseline/baseline_replay.json) · [原执行器](../s1_baseline/executor_reference.json)

新入口先清理不可见值，再用 1/2/4 倍率按原生行优先顺序打包。初始 32 维内容的前 16 维可准确读回数值槽。两块浅层 ResNet 各使用两个 stride 1 的 3×3 掩码卷积和逐位置通道 LayerNorm。FiLM 按波段和块生成参数。几何融合读出每个原生相位的特征，按真实交叠汇聚到每个 40 米父格的四个 20 米槽。四个 8 维槽按明确顺序重排成 32 维输入。现有 Transformer 保留三阶段 32/64/96 维与 8/4/2 压缩，位置适配只加到 Q/K。[张量接口](../representation_trace.csv)

D0 对照在固定历史权重下比较预测、损失和参数梯度。最大预测差 4.77×10⁻⁷，最大梯度差 1.19×10⁻⁷。D1 单独替换共享细场末端展开，并保持 top-down、目标线性读出和原生面积投影。固定 S2 样本的 B1 兼容支路有贡献，L8 样本为零。候选预测通过隐藏值、QA 与目标查询子集检查。完整最大场景通过 A/B1 前后向。最大 S2 场景含 34,491,294 原生值，实测峰值约 5.66 GiB。新候选通过 32/18 条单卡与双卡一步更新、参数注册和保存恢复后的下一步对照。[兼容与查询](../s4_decoder_execution/decoder_terminal_gate.json) · [支路](../s4_decoder_execution/legacy_detail_gate.json) · [容量](../s4_decoder_execution/capacity.json) · [恢复](../s4_decoder_execution/resume_gate.json)

历史黑块的浮点证据显示至少两类现象。复算上轮 B1 消融图的中位配对样本 B04 后，两组均有 100% 预测落在显示下界以下，方差仍约为真值的 26.36 倍和 25.86 倍，属于显示饱和伴随辐射偏移。最差配对样本 B02 关闭支路后的方差比为 0.051，只有 3.6% 预测落在下界外。历史 30 轮权重在固定 L8 A SR_B1 样本上约 97% 落在上界以上，方差约为真值的 5%。[上轮图复算](../s1_baseline/previous_display_audit.json) · [历史显示审计](../s1_baseline/display_audit.json) · [原始浮点与掩码的本机位置](artifact_manifest.json)

## 效果验收

[完整模型架构、追溯 ID 与图集](../visualizations/README.md) · [命名对照](../experiment_display_names.json)

S5 四组各 400 次更新。每次覆盖两条固定 TRAIN 拟合样本，seed 17，原生像元 MSE，B1 兼容支路关闭。两组 Oracle 使用独立且相同的 Latent 初值，真值只进入损失。四组保存初始、最佳、末态权重与预测。最佳权重均成功重放。

| 实验模型 | 最佳步 | S2 MSE | L8 MSE | S2 有符号梯度 MSE | L8 有符号梯度 MSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| Patch Latent 动态卷积 + D0 全可见拟合（AE-L） | 370 | 0.06550 | 0.06957 | 0.04042 | 0.07753 |
| FiLM 浅层 ResNet + D1 子像素解码全可见拟合（AE-F） | 400 | 0.05222 | 0.04581 | 0.03972 | 0.04888 |
| 自由 Latent + D0 连续插值解码拟合（OR-D0） | 400 | 0.07532 | 0.06901 | 0.03773 | 0.05196 |
| 自由 Latent + D1 子像素解码拟合（OR-D1） | 400 | 0.08060 | 0.06860 | 0.04331 | 0.04876 |

FiLM 浅层 ResNet + D1 子像素解码全可见拟合在两条样本均达到预登记的零预测参照门槛。它比较整个新共享主路径。D1 在自由 Latent 对照没有跨两条样本的一致收益。冻结岭回归读出确认多个接口可读，但固定八维子集对原生相位、粗格读出和不同阶段表达的覆盖有限。S2/L8 的前后变化方向不完全一致，单探针结果不能定位全部瓶颈。[拟合门禁](../s5_capacity_fit/fit_gate.json) · [拟合图](../visualizations/figures/s5_fit.png) · [岭回归](../s5_capacity_fit/ridge_probe.csv)

S6 采用相同 seed 17、数据顺序、目标和可见掩码协议，六组按登记顺序比较。第 0 步初次评价发现 NumPy float64 统计在纹理分位数临界像元上与冻结 Torch float32 选择不同。该尝试没有执行优化器更新。复查保留旧记录，使用原始 float32 选择和归约，继续同一试验设计。运行结果见阶段目录和 Viewer。

前端组合切换前复核了共同参数。N0 原构造方式会改变后续相位与融合头的随机数消费顺序。修订使 N0 与 N1 的共同权重逐元素相同，同时保留完整候选 C 的已验收初值。B0、BP 不实例化新融合模块，继续使用原执行身份，准确源码另存。[修订记录](../source_revision.json) · [B0/BP 源码](../source_revision_b0_bp/)

只改 Q/K 位置的 BP 与 B0 各完成 233 步，逐条训练目标、可见掩码及像元数一致。A MSE 由 0.651275 变为 0.651450，B1 由 0.696296 变为 0.696220。B1 共享主路径高纹理梯度 MSE 由 0.13221378 变为 0.13221144，幅度未达到 5% 质量筛选门槛。位置可区分性通过实现检查，当前质量数据不支持单独晋级位置候选。

## S6 终点与 S7 决策

每组 seed 17、233 次更新，A/B1 各 7,442 个真实视图。训练目标、可见掩码与目标像元逐条匹配。验证在 0、42、116、233 步完成，同一固定 VAL 与历史协议一致。下表中的 B1 主路径指标以兼容支路相加前的预测计算。

S6 各组使用原三阶段压缩全局 Transformer，B1 总输出为共享主路径输出加上历史 B1 细节支路贡献。A 的支路贡献为零。

六组短程比较没有候选同时满足 MSE 不劣与共享主路径纹理门槛，S7 多种子确认未触发。

在有序打包与空间槽位融合基础上加入两块浅层 ResNet（FiLM 关闭）后，B1 像元 MSE 下降 0.56%，A 上升 0.68%，两项分组区间均跨零。启用 FiLM 调制后，B1 MSE 下降 0.035%，共享主路径纹理变化小于 0.001%。FiLM 浅层 ResNet 的解码末端由 D0 连续插值换为 D1 子像素展开后，总体 A/B1 MSE 上升 1.75% / 1.65%，S2 两项均退化，L8 两项均改善。B1 主路径纹理误差上升 4.05%。从同一 FiLM 浅层 ResNet + D1 子像素解码权重读取，叠加历史支路把 B1 高纹理梯度 MSE 从 0.13801 降到 0.07293。固定 S2 的 B1 B03 样本中，D1 主路径有周期性网格，40 米半格相位的边界残差比从 1.007 升到 1.070。该相位发现只针对固定面板。Patch Latent 动态卷积 + Q/K 物理位置 + D1 是可选交互对照，本轮未触发。
