# Merge B 实施与严格审阅

已按用户选择实施B；曲线仍为候选。正式训练和真实参数更新均未启动。

实现：participation_layout.py负责连续GSD→r→s=1/(1−r)、原生中心唯一归属及完整相邻组选取；participation_encoder.py复用动态卷积、投影、共享局部网络与完整全局注意力；adaptive_streaming.py沿用逐波段/任务分层监督。没有加入可学习窗口、内容门控、固定2×2树、新损失或新训练组。旧主模块与迁移备份哈希一致，旧检查点未隐式加载。

覆盖、QA有效代表区域、实际可见区域、局部卷积感受野、全局输入支持分别保存。选组只读取几何与可见性，隐藏反射率变为NaN不改变输出。一个有效可见位置只属于一个输出组；未选位置仍经共享局部网络输出Token，不丢原生位置。缓存/恢复配置绑定曲线和选择种子，错配拒绝。

几何散列为确定性空间分散次序，不保证小区域严格等距。有限边界和QA孔洞的参与偏差原样报告；完整组不为凑比例而拆分。若要分块生成Merge计划，必须沿用同一个完整观测选组结果，不能在各子块重新选择后宣称等价。

98项工程测试全部通过，无跳过（participation_engineering_tests.json）。新B覆盖A/B1完整目标分块一致性、隐藏值隔离、梯度、检查点配置错配拒绝；A/B+JEPA有效批量8的CPU/GPU集成与合成更新/EMA/恢复检查通过。合成优化器测试不计真实预检预算，不能替代真实更新等价验收。

高分辨率容量使用单个生成波段、显式未冻结曲线，FP32 Encoder完整前后向；不是已准入高分辨率真实观测，不包括Decoder或有效批量8。60/120m仅为诊断视场，不决定Merge窗口：

1.21m保留完整ceil尺寸，实际视场为60.5/121m，没有重采样到60/120m。0.5m、120m案例参与率75%，选中组16位置；1.21m、121m案例实际65.67%，选中组2–9位置。

单卡局部网络合批64→1024的生成高分辨率案例约2.49倍加速，latent最大差2.384e-6；不能把latent误当反射率预测判定。随后在一个已审TRAIN真实B1观测、全部32768监督像元和29116 Token上，64→1024完整Encoder/Decoder前后向为5.944→2.511秒（2.37倍），峰值2.100→2.119GiB。初次读取0.038秒、计划0.905秒、传输0.127秒另记；不是有效批量8更新步耗时。

实测预测最大绝对差4.172e-7、任务损失差1.361e-8、最大逐波段NMSE差1.576e-8、梯度相对差3.513e-7，均低于现有对应FP32限制。未放宽数值容差。未做真实GPU参数更新及恢复等价，1024继续是执行候选，默认仍64。

参数变动边界：工程测试的Hill函数r=.80922489545/[1+(sqrt(gx*gy)/4.01095302622)^1.21926828157]并未冻结。它通过三个示意点，极细GSD参与率趋近80.92%；函数族、系数和非方形等效GSD需用户确认。没有采用旧指数公式。

结论边界：当前完成的是已选B机制及工程集成，未完成真正的递归多级空间机制、视场与遮盖关系评审、B2准入或整体验收。真实更新累计214次，剩余186次不使用。来源哈希、容量运行时源快照及逐量对照见participation_merge_implementation_evidence.json与各原始报告。
