## 0. 执行任务与边界

### 0.1 任务

在保留“原生观测 → 物理描述器/条件编码 → 通道融合 → 多尺度空间主干 → 目标条件重建”总体路线的前提下，回答四个问题：

1. A空间遮挡重建与B1整波段隐藏重建是否存在负迁移？冲突发生在哪些模块？
2. 块状伪影主要来自执行/几何错误、Transformer前的融合，还是Decoder空间展开？
3. 动态卷积是否已经丢失可用的空间信息，还是后续聚合或读出未正确利用这些信息？
4. 在不增加独立原生高维旁路、不继续更换Transformer的前提下，哪些局部修改和训练策略值得进入正式实验？

本计划中的“B”均指当前B1，不包括其他未启用任务。任何因果结论必须有对应对照，不能直接沿用报告中的解释。

### 0.2 执行权限

将本计划交Agent执行时，默认范围为P0—P5的检查、测试及本计划预算内的独立工程实验；各阶段须满足前置门禁。允许创建诊断入口、候选开关、新配置与新输出目录。

不执行以下操作：

- 不恢复、续训、覆盖或删除历史正式Run、检查点、冻结代码及原始数据。
- 不自动启动新的长期/完整预算正式训练；P6只提交晋级建议。
- 不新增独立的逐原生像元、逐通道高维Skip/KNN库；不增加新的原始影像直达Decoder旁路。
- 不继续替换Transformer主干，不默认引入JEPA、额外预训练任务或外部预训练权重。
- 不通过增大模型、改变数据划分、改变监督或修改可见性，同时修复多个问题。
- 不把工程诊断、全可见自编码、自由Latent拟合记为正式A/B1结果。
- 不把“短程未改善”写成“已经证明无效”，不超预算无限重试。

既有B1细节分支必须核对并保留为基线事实。关闭它只能作为显式单因素对照，不能静默改变基线。

## 1. 总体执行顺序

| 阶段 | 核心工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 | 冻结基线、任务定义、数据和预算；核对真实计算链 | 能绑定代码/配置/权重/数据/掩码；明确缺失项 |

| P2 | 全可见重建、自由Latent和分阶段读出探针 | 能提出有证据支持的瓶颈位置；允许结论“不确定” |

| P5 | 固定架构比较联合训练与B1预热课程 | 任务暴露、优化步数和评价协议受控 |

## 2. 全局实验契约

### 2.1 基线身份

每个Run至少记录：

`experiment_id, parent_id, git_commit, dirty_diff_hash, source_snapshot_hash, config_hash, checkpoint_hash, dataset_manifest_hash, train_member_hash, val_member_hash, mask_protocol_hash, seed, environment, precision, optimizer, scheduler, trainable_modules, changed_factor`。

工作树未提交修改不可丢失：保存补丁和源码快照。每个候选与哪条基线比较，必须在启动前写明。

### 2.2 数据与目标

- 保持现有TRAIN/VAL分组边界；不得从VAL选择训练样本或拟合归一化、线性基线。
- P2优先从TRAIN固定选择16个天然较小/中等规模观测，覆盖现有主要传感器、原生GSD及高/低纹理条件；另设不参与拟合的只读检查样本。
- P2选择数量不足时使用全部合格样本并报告，不复制样本伪造规模；大场景容量另测，不用截断场景冒充原观测。
- P3—P5优先沿用原完整TRAIN。确需子集时，预先冻结同一个分层256 TRAIN/64 VAL诊断集合；全部比较组都使用它，不与完整数据Run直接归因比较。
- 子集划分只能使用已知元数据和预定义统计规则，不按候选模型的验证误差筛选。
- 每次正式比较使用同一组验证观测、波段、QA、目标位置、可见位置和归一化；保存逐观测目标/可见掩码哈希。
- 训练掩码以`seed + observation_id + task + exposure_index`确定。不能依赖“A/B先调用谁”的全局RNG推进。
- 若实际VAL不包含某传感器，只报告该传感器的工程或TRAIN诊断，不宣称其验证泛化提升。

### 2.3 训练配置

短程模型比较沿用基线优化器、精度、裁剪、有效Batch及学习率曲线的相应前缀；不要把原长程scheduler压缩成短程周期。改动这些设置须建立单独实验。

P2允许工程专用的小Batch配置，组内一致；不将其吞吐与正式Run直接比较。

P3—P5从同一初始化身份开始。结构相同则初始参数哈希一致；结构不同则匹配共有参数并报告新增/替换部分的初始化。不能只说“seed相同”就声称初始化完全一致。

阶段训练中不重置优化器、scheduler或模型参数，除非这是单独登记的实验因素。旧正式Run不得用作未经说明的续训起点。

### 2.4 单因素约束

每个实验的`changed_factor`必须能用一句话说明。任务顺序、A遮挡难度、融合结构、Decoder、梯度损失和细节分支分别是不同因素。

修复已确认Bug之后，旧有实验不能与新代码直接形成结构归因。先建立修复后的基线，保留修复前结果和差异。

## 3. P0：核对计算链与复现基线

### P0.1 代码追踪

定位实际训练入口、任务包装器、动态核生成、卷积、几何映射、块内融合、主干、Decoder、损失、可视化与完整VAL实现。不得预设报告中提到的源码目录一定存在。

生成`representation_trace.csv`，按模块记录：

- 输入/输出形状及各轴含义：空间、通道、Query、特征宽度。
- 原生GSD、采样间距、卷积感受野、实际空间支持；不要将四者混为一项。
- 是否下采样；是否跨空间聚合；是否跨观测通道聚合。
- 相对位置、全局坐标、目标描述器在哪里进入。
- QA、可见掩码、覆盖量和归一化分母的来源。
- 一个输出Token对应多个空间位置时，这些位置的信息以什么形式保留。
- Decoder如何区分同一块内的不同目标位置，如何读取相邻块。

重点确认光谱融合是`[空间位置, 通道, d] → [空间位置, d']`，还是把空间和通道一起汇成少量Token。若输出多个Query，确认它们代表空间槽位、光谱槽位还是无固定含义的Latent。

### P0.2 核对A/B1契约与实际损失

分别记录A/B1：隐藏规则、目标集合、可见上下文、可用旁路、像元损失、辅助损失、样本/波段/像元归一化及有效权重。

禁止把“配置A/B等权”直接当成“两个任务对共享参数贡献相同”。应展开到实际标量loss及其分母；若有多卡，核对梯度聚合和全局样本数。

### P0.3 只读复现

用冻结检查点先复现少量指定样本，再复现现有完整VAL。保存逐观测、逐任务、逐波段指标，不只保存均值。

容差必须在运行前登记，区分确定性算子误差与实际重复执行噪声。纯FP32算子对照建议起始使用`atol=1e-6, rtol=1e-5`，实际GPU路径另记录重复执行基线；不能为通过检查事后放宽容差。

**交付：** `baseline_identity.json`、`baseline_reproduction.json`、`representation_trace.csv`、`task_contract.json`、`experiment_registry.csv`。

## 4. P1：先排除实现错误

### P1.1 可见性与泄漏

固定可见输入、描述器、坐标、QA和掩码，只修改隐藏目标的数值。预测应保持不变，损失可以改变。

核查隐藏值不能通过动态核条件、局部对比度、插值基线、归一化统计或缓存进入预测。B1目标描述器可按既有契约进入Decoder，但隐藏波段的数值不能进入Encoder或细节分支。辅助梯度监督读取目标属于loss计算，不得倒流为前向输入。

### P1.2 执行chunk一致性

固定完整输入、权重与逻辑感受野，只改变计算chunk、查询分块或等价执行Batch组织。预测及必要的参数梯度应在预先登记容差内一致。

不得把“改变真实裁剪范围/上下文”误作等价chunk实验。若伪影随纯执行chunk边界变化，优先修复缓存、padding、halo、索引或梯度归并，不先修改网络。

### P1.3 几何与覆盖算子

独立测试常数场、水平/垂直斜坡、不同位置的脉冲、正反阶跃、棋盘格和细线。合成样本保留合法几何与明确的QA/可见支持。

- 对定义为归一化面积平均的算子，有效支持内常数应保持；不要求任意带偏置/激活的完整网络满足同一断言。
- 用解析或高精度参考核对像元中心、面积、边界、负坐标、不同GSD及当前支持的旋转/跨CRS情形。
- 分别改变QA覆盖和可见覆盖，检查分母、空支持及部分支持处理。
- 对卷积记录输出采样间距和特征支持，不能将stride=4产生的特征一律当成原生像元足迹。
- 高频合成图用于检查表示能力和相位响应，不把超出输入可辨识尺度的恢复设为真实任务要求。

### P1.4 可视化与相位

在相同色阶下输出：原生真值、合法可见输入、原始预测、目标掩码、目标区域误差、梯度误差。另存显示拼接图，但不以“可见真值+预测”的拼接结果代替原始预测评价。

灰色目标占位块、无预测位置和真实预测块状伪影必须分开。允许诊断接口对全部合法位置发起读出，但不得因此改变输入可见性；原接口不支持时明确记录。

增加按实际格网原点/步长确定的相位诊断。仅改变数组表示、同时保持物理场和逻辑算子等价的测试可设一致性门禁；改变模型地理分区原点或真实输入平移，只作为相位敏感性对照，不能要求严格相等。

**门禁：** 任一泄漏、等价执行不一致或确定性几何错误未解决，停止P3—P5训练。保存失败样本与最小复现测试。

## 5. P2：信息保留与空间读出能力诊断

### P2-A：全可见主路径自编码（VISIBLE-AE）

在固定16个TRAIN工程样本上，让合法QA内的观测全部可见，并在同一支持上重建。只使用共享主路径，关闭既有任务特有细节旁路；这项关闭必须在诊断配置中显式标记。

不新增任何直达目标的旁路。使用当前前端、融合、主干及Decoder；最多200次更新。报告初始/最终像元、梯度和块状诊断，并保存固定样本输出。

本实验仅回答“信息已经给到模型时，主路径能否拟合局部结构”，不提供自监督泛化证据。

### P2-B：Decoder自由Latent拟合（DECODER-ORACLE）

在相同工程样本上，用逐样本可学习张量替代Encoder输出，形状、空间拓扑、宽度和几何接口与实际Latent一致；联合拟合这些Latent和当前共享Decoder，最多200次更新。

不得增加Latent空间位置数、逐像元真值输入或新旁路。目标只用于loss；本实验允许拟合TRAIN目标，但不进入正式成绩。

- 拟合良好：说明该规模Latent和Decoder至少存在可表达该样本的参数，不证明Encoder能学到它。
- 拟合失败：只能标记Decoder/Latent表达或优化可疑，不能凭200步失败证明表达能力不足。
- 与VISIBLE-AE共同解释，不能单看其中一项就宣布根因。

### P2-C：分阶段受控读出探针

根据上述结果，优先选择“光谱融合前”和“融合后”两个检查点；必要时以卷积后或主干后替换其中一个，不自动扩成无限探针矩阵。

固定被检查的Encoder权重，给选定阶段接独立探针，仅训练探针，每个最多200步。探针输出同一原生目标，采用统一读出范式、近似容量匹配并报告真实参数量。不得访问该阶段之后的特征、隐藏真值或额外原生Skip。

使用同一可见性和目标协议做前后比较。全可见探针与掩码探针分别标记，不交叉比较。

**证据规则：** 前一阶段可读、后一阶段在合理探针下显著退化，支持在二者之间排查；探针成功证明有可读信息，探针失败不单独证明信息已消失。

**预算：** P2默认最多4个拟合Run，总计不超过800次工程更新。仍不确定则报告，不自动扩展。

## 6. P3：A/B1是否相互干扰

### P3.1 固定同一个架构

在P0/P1冻结、经P2诊断的当前同一基线版本上建立；此时不先采用新的结构候选：

| ID | 训练任务 | 起点与默认预算 |
| --- | --- | --- |
| T-JOINT | 原联合A+B1 | 相同随机初始化，233更新 |
| T-A | A-only | 相同随机初始化，233更新 |
| T-B | B1-only | 相同随机初始化，233更新 |

只有已有工程Run的身份、初始化、数据、掩码和配置全部相同，才可复用其前缀；不得用不同架构的历史A-only/B1-only结果代替。

默认单任务用自身完整任务loss训练，联合组沿用真实基线权重；A/B1各自原有监督和支路不变。零权重任务不得参与前向、改变归一化或更新任务状态。

共同训练观测顺序固定。T-A看到的A视图应与T-JOINT中的A视图一致；T-B同理。每个节点保存实际任务视图数、目标像元数、更新次数、FLOPs估计/测量、峰值显存和墙钟时间。

233只是工程更新预算。只有真正遍历完整原TRAIN且计数吻合时才可以称为原数据的一轮；使用子集时不得称原Epoch。

### P3.2 两种公平性分开报告

**主要比较：每任务暴露匹配。** T-A与T-JOINT的A观测暴露相同，T-B同理；联合组计算量通常更大，不能隐去。

**辅助比较：等资源前缀。** 用已有日志报告相同更新/任务视图或实际计算预算下的曲线；这些预算不是同一概念，必须注明是哪一种。

单任务loss系数为1、联合任务系数较小时，单任务更好不直接证明梯度冲突。若联合组出现稳定退化，追加受影响任务的“与联合组贡献系数匹配”单任务控制，最多两个、每个233步，并记录梯度尺度与优化器行为；不能把缩放loss等同于对Adam严格缩放学习率。

### P3.3 梯度诊断

使用固定TRAIN诊断微批，在初始化及预先登记的训练节点分别计算A和B1对以下参数组的梯度：动态核生成器、卷积参数、融合层、各主干stage、Decoder共享部分。任务专属参数单列，不与共享梯度混合。

记录：

`norm_A, norm_B, cosine(A,B), norm(weighted_A), norm(weighted_B), norm(weighted_sum)`。

分解B1像元项和B1辅助梯度项；既有细节分支的参数梯度单列。梯度诊断不调用optimizer.step，不改变BN/运行统计、RNG、EMA或训练游标。

- 梯度余弦持续为负只是冲突线索，需与任务性能和层位置相互印证。
- 幅度失衡与方向冲突分别解释。
- 无梯度/零梯度不填成0余弦，应标为不可定义并说明原因。

### P3.4 结论分类

1. **T-A仍有同类严重块效应：** 优先保留结构/信息问题解释，不能靠课程替代定位。
2. **T-A显著改善、联合A退化：** 在排除loss尺度和预算差异后，支持联合负迁移；结合层级梯度定位。
3. **B1旁路贡献很大：** B1好不能自动证明共享Encoder好；单列主路径成绩。
4. **两者单训/联训均正常，但A遮挡内部差：** 加做按到可见支持的物理距离分层，检查任务可辨识性与遮挡难度。
5. **证据不足：** 输出`INCONCLUSIVE`，不得宣布任务天然不兼容。

默认不引入PCGrad/GradNorm/独立双Encoder。若证据指向Decoder冲突，优先提出少量任务专属读出层的后续候选；若仅幅度失衡，再提出归一化/重加权候选。

## 7. P4：局部技术候选，一次只改一个因素

根据P1/P2及P3任务对照证据，从下表选择最多两个候选。候选均以同一基线为父项，先分别比较；不在本轮把两个修改合并后当作单因素实验。

| 候选 | 唯一改动 | 必须保持不变 | 适用证据 |
| --- | --- | --- | --- |
| F-STATIC | 动态卷积替换为同核大小/步长/输出宽度的静态卷积 | 几何映射、融合、主干、Decoder、损失 | 卷积阶段已经疑似压平空间响应 |
| F-SPATIAL | 光谱融合保留空间槽位/相对位置组织 | 卷积、主干接口、Decoder及任务 | 融合前后探针明显分化 |
| D-EXPAND | 替换空间展开/目标条件读出机制 | Encoder、输入权限、Latent来源及任务 | 自由Latent或冻结特征读出提示Decoder可疑 |
| B-DETAIL-OFF | 仅关闭已有B1细节分支 | 全部共享主路径、B1梯度监督及其他设置 | B1成绩可能主要依赖任务特有捷径 |

### F-STATIC执行细则

记录参数量差异和初始化差异，不能将结果解释成纯“动态性”之外所有因素已数学等价。先进行固定输入下的滤波器响应/通道相似性诊断。不要同时改变stride；stride修改需要后续独立实验。

### F-SPATIAL执行细则

目标是“先区分空间位置，再在适当空间支持上融合观测通道”，不恢复庞大的逐像元逐通道高维库。

空间槽位或空间基底由实际几何推导。保留相对位置/实际交叠支持；不同槽位必须有可验证的空间意义或位置响应。单纯增加多个无空间约束Query不算完成。

优先保持主干输入接口和总表示宽度可比。若无法不改变Token数/宽度，则明确这是表示预算变化，记录Token、参数、显存与计算增量；不得宣称纯位置编码收益。必要时提出容量匹配对照，但超出本轮候选数时只登记后续任务。

### D-EXPAND执行细则

在“位置展开的输出基底”与“邻域特征+相对坐标+目标描述器的连续读出”中选一个实现，不同时叠加两个方案。保持目标原生足迹的读出/积分语义，不把像元中心点采样静默替代面积支持。

位置输入只提供输出自由度，不能宣称补回Encoder已经丢失的观测信息。禁止额外读取原始影像绕过Encoder。

### 短程比较

每个候选最多233次更新；共同基线也需有同协议前缀，最多233步。使用相同训练任务、初始化共有部分、数据序列与掩码。P4阶段不同时改变A/B1训练顺序或损失。

P4最多3个Run/699次更新。通过必要诊断的候选执行完整原VAL；可疑候选可提前终止并记录实际成本。

只有证据足以支持时才选用候选进入P5。否则继续使用原基线，不为了“必须改模型”而选择验证均值偶然更好的版本。

## 8. P5：阶段训练与课程比较

本阶段固定P4结束时选定的同一架构、任务损失及支路。不能一边改融合/Decoder，一边验证课程效果。若P4采用了新结构，C-JOINT必须在该新结构上建立；P3旧结构的任务干扰证据只能归属于旧结构，不能直接转移为新结构的结论。

### P5.1 先统一微批执行基线

为了避免“交替训练多了一倍optimizer.step”的混淆，统一为任务微批执行器：

- 每次optimizer更新累计相同目标数量的观测视图，例如两个任务微批。
- JOINT基线每组为A微批+B1微批。
- 课程可出现B1+B1或A+A，但总A/B1微批清单、每任务观测暴露和总optimizer更新数与JOINT相同，仅改变排列与混合时机。
- 微批损失依据原任务归一化和实际样本数加权；尾批不得简单按名义Batch平均。
- 保持与基线相同的总loss标度；重构前后先用固定输入比对loss、梯度和一次optimizer更新。不能假定均分两次backward必然等价。
- Batch相关状态、随机层及多卡行为造成不等价时，保留原执行器，建立明确的新执行基线并报告差异，不能冒称数值等价优化。

### P5.2 默认仅比较两组

| ID | 顺序 | 预算 |
| --- | --- | --- |
| C-JOINT | 从头按固定A/B1联合顺序训练 | 466 optimizer更新 |
| C-BWARM | B1预热 → 逐步加入A → 后段保留B1 | 同样466 optimizer更新 |

若同一初始化和执行身份可完整延长T-JOINT工程Run，可复用其前缀；不得续训历史正式Run。学习率曲线相同，不在阶段切换时重置。

**C-BWARM默认任务配额设计：**

- 前约10%更新：B1预热。
- 随后约20%更新：逐步引入A，A微批比例由0上升至50%。
- 剩余约70%更新：按剩余A/B1配额完成训练，持续保留B1。连续近似下后段A/B1约为64%/36%；实际整数调度必须精确补齐两种任务总配额。
- 启动前生成并冻结`task_schedule.json`；断言与C-JOINT总A/B1暴露、成员、掩码及optimizer更新数一致。不可训练后再调整配额解释结果。

这是预注册的候选课程，不是已知最优比例。B1预热是否有利需由结果判断。

### P5.3 本轮不同时改变A遮挡难度

C-JOINT与C-BWARM使用相同A掩码协议。若二者已完成而证据仍指向A遮挡难度，可登记独立`C-MASK`：保持任务顺序不变，仅按预定规则从较小连续遮挡区域过渡到正式协议。

`C-MASK`不属于默认执行预算，先报告再申请。验证始终使用固定正式掩码；比较时另报各阶段实际隐藏比例、连通遮挡尺度和目标像元数量，不能把更容易的目标当成同难度提升。

交替训练、梯度手术、任务专属头不与C-BWARM打包。需要进一步比较时分别登记，不能一次全部启用。

## 9. 统一评价与块效应验收

### 9.1 指标与统计单元

所有主要结果按任务、传感器、波段/GSD及观测分别保存。总体均值沿用已冻结的原评价分母，同时补充中位数、P90和逐观测配对差值。

必须包括：

1. 目标原生像元误差：既有MSE，以及需要时的MAE/偏差。
2. 相邻目标像元梯度误差：明确只有哪些像元对可用、每观测有效对数；A/B1不因有效对分布不同直接比高低。
3. 梯度幅度比与梯度方向/相关性：识别过平滑及无依据锐化；不能只奖励梯度变大。
4. 固定物理尺度、不同相位的边界残差诊断：同时保留分子、分母、比值及分布。比值约1不等于恢复正确。
5. A按到最近合法可见支持的物理距离分层；B1按可见波段支持和目标GSD分层。
6. 真实计算成本：实际训练视图、更新、GPU峰值、冷/热执行成本与墙钟；不把训练更新耗时说成端到端耗时。

频域/多尺度残差可作为补充，但只在支持明确的连续有效区域计算，或使用一致且说明清楚的掩码处理。不得对填零的A目标拼图直接FFT后把掩码频谱归因于模型。

### 9.2 辅助基线

至少提供只用TRAIN统计的均值基线。可再提供A的合法可见同波段空间插值、B1的合法可见波段线性预测；它们必须使用相同QA、几何和输入权限，不从VAL拟合，也不读取隐藏值。

某样本不满足插值/线性基线前提时标记N/A并报告覆盖数，不静默丢样本。可报告相对各自任务基线的改善，但不将其当成A/B1同难度的证明。

### 9.3 图集

固定代表样本之外，按预注册规则补充改善最大、退化最大及中位数附近的案例，明确选择规则。不同模型对同一观测共用色阶和目标掩码。

禁止只展示“挑出来好看”的图；A/B1同一观测应避免被当成两个独立场景统计。

### 9.4 统计和结论强度

比较采用逐观测配对差值；存在同事件/同场景重复观测时优先按组汇总或分组bootstrap，记录组数和方法。小样本不足以支持稳定区间时直接说明。

单种子短程结果只用于筛选。正向候选还须兼顾主要传感器/波段退化、纹理指标与成本；平均MSE下降不能独自覆盖明显块效应。

不要在看过结果后设置通过阈值。P0冻结`acceptance_policy.json`：如尚无领域阈值，可只用预注册的比较方向、重复性和不劣约束筛选，不虚构“提升某百分比就解决”的标准。所有具体百分比若作为工程阈值，必须标为本次约定，而非科学定律。

## 10. 预算、停止条件与恢复

### 10.1 默认预算上限

| 项目 | 默认上限 | 备注 |
| --- | ---: | --- |
| P2表示/读出诊断 | 4 Run × 200更新 | 总计≤800；不是正式A/B训练 |
| P3核心任务对照 | 3 Run × 233更新 | 可复用完全一致的工程前缀 |
| P3系数匹配控制 | 最多2 Run × 233更新 | 仅出现相应混杂证据时执行 |
| P4基线及局部候选 | 3 Run × 233更新 | 一条基线、最多两个单因素候选 |
| P5联合/课程 | 2 Run × 466更新 | 可复用满足全部契约的工程前缀 |

不复用且全部条件实验触发时，上述最多3596次optimizer更新；不同任务每次更新计算量不同，此数字不等于统一FLOPs预算。只读VAL、前后向诊断、失败执行与重放成本另计。

这是执行上限，不是必须消耗完的配额。对真实数据吞吐/容量不能预先保证；P0/P1发现资源不满足时报告并缩减未执行范围，不静默改变模型语义。

### 10.2 立即停止条件

数据泄漏、身份不匹配、非有限数值、掩码变化、样本遗漏、未授权架构变动或基线无法复现，停止受影响阶段并输出最小复现证据。

性能变慢只影响是否继续实验，不允许通过减少原生目标、丢弃困难波段或裁剪大场景来伪造加速。容量失败记录为失败，不自动降精度或改变GSD。

合法工程Run如需恢复，必须恢复模型、优化器、scheduler、RNG、数据游标与微批/课程游标；保留失败成本及重放计数。不得重复执行后仍声称观测暴露完全匹配。

## 12. Agent最终汇报格式

按以下结构汇报，不用泛泛的“全部完成/效果提升”替代证据：

1. **实际基线与执行范围：** 代码、Run、配置身份；哪些阶段完成、未执行或阻塞。
2. **确定问题：** 逐项给出文件/函数位置、复现条件和证据路径。
3. **结果对照：** 每个候选唯一改动、A/B1各自指标、块状/纹理诊断及计算成本。
4. **因果判断：** 分开写“已证明”“证据支持”“尚不确定”，不得把假设写成Bug。
5. **实施结果：** 新增/修改文件、测试通过/失败、历史运行是否保持不变。
6. **下一步决定：** 推荐保留的一个优先候选或明确无候选；待确认的正式训练范围。

**最终原则：先证明信息在哪里变得不可读、或任务在哪里相互干扰，再决定改哪一层；不得用更大模型、更长训练或新旁路掩盖尚未定位的问题。**
