# V3 A/B1 训练解耦与空间细节诊断

## 实际基线

基线是 Run `83f833a1ef5e4515825c1457b6e4278d` 的冻结 Patch Latent 三阶段全图压缩注意力发布。176 个冻结文件逐一通过哈希核对，配置、训练和验证成员、归一化统计、物理目录与检查点身份一致。第 30 轮 best 和 last 的模型参数一致。当前工作树与发布文件逐字节相同，当前 Git HEAD 与运行时代码的差异另有补丁。附件中的 Git 提交在本机对象库中不可解析，运行身份由冻结发布及检查点提供。

指定的 S2 和 L8 样本先通过复算，随后按历史评价入口复算完整 383 VAL 两次。A/B1 MSE 为 0.34913590 / 0.39939317，高纹理梯度 MSE 为 0.14973579 / 0.06137363。历史汇总 MSE 差约 5.73×10⁻⁹。逐观测和逐波段字段均通过预登记的绝对与相对容差。训练 7,442 条，验证只有 S2 335 条和 L8 48 条。

## P1 正确性

已证明，在选定的 S2 和 L8 样本上，对 A 与 B1 的隐藏或 QA 无效像元作数值扰动会改变损失，预测保持在预登记容差内。纯执行分块及 CUDA 图与 eager 的参数梯度通过对照。分块比较的最大绝对预测差为 4.77×10⁻⁷，参数梯度差为 1.04×10⁻⁷。面积映射与独立矩形交叠参考吻合，涵盖 10/20/30 米、负坐标、错位、零支持、斜坡、脉冲、阶跃、棋盘和细线。冻结输入类型拒绝旋转、跨 CRS 的联合几何。现有 CPU 回归第一次遇到 Windows autograd 访问异常，单例复测通过，限制为两线程后 40 项回归通过。真实 GPU 检查没有观察到相应预测或梯度故障。

本阶段的结论限于已测样本、几何范围和执行路径。可视化分别保留原生真值、可见输入、原始预测、目标掩码、误差、梯度误差与显示拼接图。

基线成员哈希与既有原生光学划分审计吻合，后者在 7,395 TRAIN 和 383 VAL 之间没有发现跨角色共享身份或地理窗口交叠。另对 47 条 EnMAP TRAIN 和 383 VAL 复查了元数据，精确交叠和待确认跨投影候选均为零。TRAIN 和 VAL 的观测 ID 无交集。

## P2 信息保留

四组各 64 次有效工程更新。16 个拟合样本和 8 个只读样本均来自冻结 TRAIN，覆盖 S2、L8、L9、EnMAP。共享路径全可见拟合从历史最佳参数出发。探针使用同容量读出，比较同一个全可见原生目标波段。修正后的自由 Latent 每个尺度的宽度、位置和支持与真实输出一致，初值独立于目标数值，使用两线程 CPU。其初版用全可见编码初始化，违反目标数值只进入损失的要求，64 次更新保留为失败成本，结果排除。

两组探针各有 10,337 个可训练参数。P2 保存了固定样本的起点、终点数值及训练记录，未保存可重新绘图的末态权重或预测张量，因此 P2 不单独提供像元级图或相位残差；P1 与 P3–P5 的图和相位数据分别用于正确性和任务对照。

| 诊断 | 拟合样本 MSE，初始 → 末态 | 拟合样本梯度 MSE，初始 → 末态 | 只读 TRAIN 末态 MSE |
| --- | ---: | ---: | ---: |
| 全可见共享路径 | 0.2469 → 0.4200 | 0.06815 → 0.06824 | 0.3256 |
| 自由 Latent + Decoder | 1.0700 → 1.0782 | 0.07084 → 0.07073 | — |
| 融合前冻结探针 | 1.1962 → 0.7900 | 0.10217 → 0.11404 | 0.2833 |
| 融合后冻结探针 | 1.1767 → 1.0415 | 0.10192 → 0.10417 | 0.3469 |

证据支持融合前的同波段特征在所测读出下保留了可读像元信息。融合后探针在 MSE 上较差，但拟合样本上的梯度 MSE 更低。随机自由 Latent 的 64 步结果未显示明显拟合收益，表达容量与优化难度仍难区分。尚不确定动态卷积、融合、主干或 Decoder 各自造成了多少纹理损失。部分近零真值梯度使振幅比不稳定，阶段结论依据 MSE 与梯度 MSE。

实际动态卷积为 7×7、步长 4，10/20/30 米输入的特征中心间距分别为 40/80/120 米。融合在每个 40 米格内跨通道汇聚，四个 Query 无显式子格位置；之后主干在 40/80/160 米尺度处理，Decoder 再生成 10 米共享场并映回原生足迹。探针的前后差只覆盖融合接口，未独立干预动态卷积或主干。两样本面积采样对照量化了几何汇聚误差，不能把端到端伪影归给 Decoder。

## P3 同架构任务对照

核心三组各执行 233 次 AdamW 更新，随机初始参数与历史运行一致。每个启用的任务都有 7,442 条相同训练观测。A 的目标像元合计 488,584,490，B1 合计 325,962,170。对应训练目标掩码逐条一致，完整 VAL 的可见与目标掩码和历史基线一致。

| 233 步 | A MSE | B1 MSE | A 高纹理梯度 MSE | B1 高纹理梯度 MSE | 端到端秒 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 联合 | 0.65128 | 0.69630 | 0.151809 | 0.067197 | 590.3 |
| A-only | 0.61622 | 0.98231 | 0.151731 | 0.067264 | 547.7 |
| B1-only | 0.92157 | 0.69828 | 0.151578 | 0.066809 | 390.7 |
| A-only，系数 0.5 | 0.61622 | 0.98230 | 0.151730 | 0.067264 | 516.9 |

A-only 相对联合的 A 逐观测配对均值下降 0.03505，中位数仅下降 0.00031，383 条中 201 条改善。高纹理梯度误差变化很小。B1-only 的 B1 在第 42 步一度好于联合，第 116 和 233 步均略差。联合的共享层梯度余弦在第 42 步存在局部负值，第 116 步只剩一条诊断观测为负，第 233 步全部诊断观测为正。这支持阶段性、样本相关的梯度分歧，尚不能定位持续冲突层。

匹配联合的 A 系数后，第 116 和第 233 步的 A MSE 仍分别为 0.62758 和 0.61622。这支持当前短程联合设置对 A 有不利影响，且观测暴露、更新次数和单任务标量系数无法解释此差异。单种子、同四个训练诊断样本限制了可推广性。B1 未触发系数控制。各组端到端耗时包括数据、验证和执行准备，运行时系统缓存和资源占用可能不同。逐更新耗时和前向 MAC 估算下界分别保存在成本表。

系数匹配的 A 结果有传感器差异：S2 的 A MSE 下降 0.04110，L8 上升 0.00717。按发布的隔离组、采集键和源产品合并重复观测后，383 条 VAL 属于 280 组。组重采样 5,000 次给出配对平均差的 95% 区间：A-only 系数匹配组全 VAL 为 [−0.07864, −0.00532]，B1-only 的 B1 为 [−0.01549, +0.01818]。区间描述当前两模型在这批观测组间的差异，不包含种子变异。

辅助等资源读法：联合第 116 步累计 7,424 个总任务视图，A-only 第 233 步为 7,442 个，A MSE 分别为 0.67405 和 0.61622。两组在该处每任务暴露和更新数不同；它只是相近总任务视图的资源参照。联合的前向计算下界为 2.565×10¹² MAC，A-only 为 1.299×10¹²；耗时不包括在配对效应的归因内。

## P4 局部候选

固定历史最佳权重和 B1 可见输入，仅关闭现有原生细节分支。完整 383 VAL 的 B1 平均 MSE 上升 0.02750，中位数上升 0.00109。703 个目标波段的预测改变，分布在 335 个 S2 观测。263 条因保留支路而改善、72 条退化，48 条 L8 未改变。这量化了支路对这个检查点的贡献。

另在两个预先指定的验证样本上，以全 QA 真值做 40 米面积汇聚再映回原生足迹。S2、L8 的波段平均 MSE 为 0.01629 和 0.00613。这个对照包含目标真值，只用于量化采样操作造成的误差。它没有估计可见输入所允许的实际重建上限。

随后从与 P3 相同的随机初始化训练 233 步，只关闭现有 B1 细节分支；保留 B1 梯度监督及全部共享主路径。训练视图、目标掩码、验证掩码与 T-JOINT 一致。

S2 的 B1 MSE 上升 0.03691，高纹理梯度 MSE 上升 0.07433；L8 的 B1 MSE 下降 0.00239。L8 在固定权重干预中不变，训练对照中的变化反映共享参数学习轨迹。关闭支路不满足分传感器的预定不劣筛选，P5 保留原架构及支路。P2 的像元与纹理证据未指向同一结论，本轮没有继续引入第二个结构候选。

## P5 课程

联合微批执行器对照原执行器通过：32 条整批和 18 条尾批分别检验 eager 和原有 CUDA 图形状，四组的目标计数、标量损失、参数梯度、AdamW 动量和更新后参数全部通过。四组最大的损失、梯度和更新后参数绝对差分别约为 6.06×10⁻⁹、1.49×10⁻⁸、5.81×10⁻⁷。

两组均使用同一随机初始化、AdamW 与原 6,990 步学习率前缀，每步累计两个等长任务微批，用实际观测视图数归约。课程三个阶段的 A/B1 微批配额为 0/94、46/140、420/232，两处 18 条尾批保持 A/B1 配对。终点的实际日志通过核验：每组各 466 步，A、B1 各 14,884 个视图，目标像元分别为 977,063,950、640,988,432。实际顺序与各自冻结清单逐步一致；两组按任务、观测 ID 和暴露编号匹配的每张训练目标掩码一致，VAL 目标与可见掩码均与历史基线一致。

联合组的 466 步全为 A+B1；课程组为 94 步 A+A、278 步 A+B1、94 步 B1+B1。任务内观测清单不变，重新分配的是每步的任务搭配和时序；没有改变 A 遮挡难度，没有在阶段切换重置优化器。第 47/140/233 步仅对齐更新次数与总视图，A/B1 各自的累计暴露不同。

## 结论强度

- **已证明：** 冻结源码、配置、权重及数据能复现历史 Run；所测隐藏值、几何和执行等价性检查通过；课程对照的实际暴露、更新和评价一致。关闭既有 B1 细节分支会改变所测历史权重的 S2 预测，且该干预下 B1 总体误差上升。
- **证据支持：** 联合训练在当前短程设置中牺牲了 S2 的 A 像元精度，匹配 A 的联合系数后结果仍在；L8 方向不同。既有 B1 分支有助于 S2 的高纹理重建。该预热课程未通过终点筛选。
- **尚不确定：** 哪个共享层造成任务干扰，动态卷积、融合、主干和 Decoder 各自造成多少细节损失，以及重建结果对滑坡下游的收益。既有分组区间不覆盖模型种子或正式训练预算。

## 空间指标与交付

本次新增的诊断、评估和 Viewer 同步入口均位于本实验目录；训练读取冻结发布，没有覆盖历史 Run、改动项目源码或启动长期正式训练。最初的 T-A 工程进程中断，没有可用断点，独立保留了失败目录；正式对照的 T-A 从相同初始参数重新起跑，未拼接两次尝试的暴露。旧尝试的更新数因日志未落盘只能给出下界。

40、80、160、320 米按同一物理原点与半格相位分层，分别保存边界和内部相邻目标残差的均值、有效像元对数及比值。T-JOINT 的 S2/A 40 米比值中位数为 1.0028（原相位）和 0.9917（半格）；接近 1 只说明该统计下没有普遍的边界残差增幅。S2/A 按距合法同波段可见像元的距离分层，0–40 米目标像元加权 MSE 约 0.49，160 米外约 1.25。分层没有随机改变遮挡距离，因而反映关联。B1 按目标 GSD 和同格可见波段数分层；组间受不同场景和目标波段影响。

TRAIN 均值基线在标准化空间预测零；每个波段使用同一合法目标掩码评价，VAL 未参与拟合。梯度统计只使用两个端点都属于目标的相邻像元对。历史评价按原逐波段、逐观测等权归约；额外的距离分层采用目标像元权重并明确标记。L9、EnMAP 的探针结果仅属于 TRAIN 工程诊断。未执行可选的 A 插值或 B1 线性对照。

在 Training Viewer 的 `earth-representation/training-runs` 源中，打开「Encoder V3 · A/B1 与空间细节诊断」看正式掩码对照，打开「Encoder V3 · 空间表征探针」看只使用 TRAIN 的 P2。历史基线保留原 Viewer Run ID；所有诊断均有新 ID。Viewer 指标从实际日志发布；初始化无效的 Oracle 初版已在名称中标记排除。

课程组请使用更新步作为 Viewer 横轴；进度字段按 233 步为一单位，单任务实际累计暴露见报告和更新明细。
