# Encoder V3-H-R 修订设计

V3-H-R 用原生像元逐通道建立 Fine 表征，再通过 Middle 双路径和 Regional／Global 汇总上下文。首阶段任务为 A 空间 MAE 和光学 B1 整波段隐藏重建。工程基线用于验证计算图、几何、泄漏及容量。用户已为首个1 Epoch正式逐像元A+B1 Run确认同一模型容量；其他候选仍须另行冻结。

## 张量及信息权限

单观测独立执行。下表以工程基线为例。原生网格保持各通道自己的坐标和像元，不对值重采样。

| 级别 | 数据与形状 | 读入与参数共享 |
|---|---|---|
| Descriptor | 有效通道 `d[c,32]` | 共享 MLP。观测类型、量纲、极化为类别；GSD、光学波长／带宽、SAR 频率／入射角按字段附适用位和有效位。元数据来源和通道名不作为网络输入 |
| 动态卷积 | 每通道核 `[32,1,3,3]`，原生输出 `[N_c,32]` | 共享基础核、8个卷积基及系数生成器。每可见通道每前向生成一次核；以1像元 halo 执行单层步长1卷积 |
| Fine | 打包 `[T,32]`，带通道偏移、原生像元索引 | 依次读取同通道3×3、真实交叠的其他可见通道，随后共享 FFN。两种读法分别共享各自 Q/K/V，通道间不复制参数。Descriptor 条件化跨通道读取 |
| Middle 保留路径 | `[K,2,64]`，每个 `K=(m,c)` 有可见覆盖 | 共享2 Query 读取本单元该通道所有交叠 Fine；同通道相邻单元读、同单元异通道读及 FFN 均保留通道身份 |
| Middle 联合路径 | `[M,4,64]` | 每单元4共享 Joint Query 读取该单元的全部保留 Latents |
| Regional | `[R,4,64]` | 每区域4共享 Query 读取所属 Middle Joint Latents；保留整数地理 ID 和有覆盖子单元 |
| Global | `[8,64]` | 只读 Regional，再对8个 Global Latents 执行 Self-Attention 和 FFN |
| Decoder | 每目标像元 `[64] → 标量` | 用共享目标 Descriptor、原生中心和投影面积构造 Query；第一次读取可见 Fine 和 Middle 保留路径，第二次读取所在 Regional 与 Global；共享点式 MLP 输出 |

编码的唯一跨尺度方向是 Fine→Middle→Regional→Global。Decoder 只接收编码结果、目标几何、目标通道元数据。隐藏像元在卷积之前剔除，监督值由任务包装器在预测后计算损失。完全隐藏的通道不产生 Fine 或 Middle 保留特征，且它的属性不参与可见通道选择。Decoder 与编码主干可独立构造，预训练后可丢弃。

Decoder 局部读取使用目标通道的原生3×3上下文以及与目标像元有正面积交叠的其他可见通道；Middle 部分读取与目标像元实际交叠的单元。跨通道候选从可见通道构造，按光学谱序取端点后逐层二分，和 SAR 极化组、缺失属性组轮转。每个 Query 在有可见交叠的候选中最多取8个其他通道，保留这些通道的所有交叠像元。通道上限不是边上限。空读残差增量为零。

## 支持几何与边界

使用 [Equal Earth 等面积投影](https://proj.org/en/stable/operations/projections/eqearth.html) EPSG:8857。Middle ID 为 `floor((x,y)/L)`，Regional ID 为 `floor_divide(Middle ID, S)`。在负坐标同样使用向下取整。每个 Regional 区域定义含完整 `S×S` 个 Middle 格，单个观测只实例化有可见覆盖的格。覆盖由原生支持与格子交叠记录组成，重叠通道覆盖不能相加解释为联合面积。

同网格用像元索引恒等对应，同一投影下使用原生平面正面积交叠，轴对齐网格走矩形快路径，旋转网格走原生平行四边形求交。不同投影的网格以 Equal Earth 支持多边形及空间索引求交。跨日期变更线拆分支持。投影边逐步加密并记录相邻两级最大相对面积差，工程阈值为 `1e-5`。这是数值近似收敛条件，不是交叠拓扑误差的全局上界。

按唯一网格和网格对维护缓存。持久缓存按完整仿射、CRS、尺寸、步长、实现和依赖版本绑定，可在独立目录跨进程复用。对 QA 或掩码的变化只过滤边。卷积感受野、原生像元支持和当前可见覆盖分别处理。

## 成本与候选范围

令 `T` 为可见原生 Token 数，`E` 为某次读取的有向配对数，`d` 为该读取投影宽度。注意力矩阵乘及值加权约 `4Ed` FLOPs。投影按实际 Q/K/V 及输出行数乘输入／输出宽度计算，FFN 按实际 Token 数计量。A/B1 的可见 Token 和 Decoder 目标数分别统计。

- Fine 局部最多约 `9T` 对。同网格时跨通道最多 `kT` 对，异分辨率需实际计数。
- Fine→Middle 为像元与 Middle 单元的正面积关联数乘空间 Query 数，跨界像元可服务多个单元。
- Middle 通道项为 `sum_m q² C_m(C_m−1)`，只发生在每个 Middle 单元内。Joint 项为 `sum_m J q C_m`。
- Regional 配对数为 `q_r J M`。Global 为 `G R q_r + G²`，没有 Regional 两两矩阵。
- Decoder 单独计算两次读取。Middle 目标读取在高光谱 A 视图可能比 Fine 的跨通道注意力更贵。

| 候选维度 | 已确认比较范围 | 计算影响 |
|---|---|---|
| Fine 宽度 | 32／64／96 | 线性层平方项为基线1／4／9倍；配对项和单份激活为1／2／3倍 |
| Middle、Coarse 宽度 | 64／96／128 | 同 Token 时投影平方项为1／2.25／4倍 |
| 每通道 Query、Joint、Regional、Global | 2／4／8，4／8／16，4／8／16，8／16／32 | 分别提高压缩容量；Middle 通道项随每通道 Query 数平方增长，Global 自注意力最多1024对 |
| Fine 跨通道上限 | 8／16／32 | 224通道同网格 EnMAP 最大原生容量433,664，满可见时约346.9／693.9／1387.7万有向对 |
| Middle 步长、Regional 每边格数 | 128／256／512米，4／8格 | 内部格数量近似按步长平方反比，必须报告小场景仅覆盖一个 Regional 的比例 |
| 每级块数 | 1／2／3 | 相同几何和宽度下，重复块的计算量近似线性增加 |

已知最大 S2 样本为34,491,294个原生值。在全可见的上限估算下，FP32 单份 Fine 激活分别约4.11／8.22／12.33 GiB，实际还包含投影、Decoder 和梯度。执行按卷积行块和有向 Query 块分块。大投影可存于 CPU，按需要搬运当前 Query 块的唯一 K/V。Decoder 按目标块完成两次读取，只保留共享 K/V 和输出标量，反向重算每块并将梯度归并至共享缓冲区。此策略改变驻留内存与传输量，不改变配对数和预测范围。

原生清单的 Equal Earth 足迹包围盒普查覆盖7,442 TRAIN和383 VAL。512米与1,024米 Regional 候选中，未发现整个原生包围盒落在单格的样本。4,096米候选中，EnMAP TRAIN 有21/47、S2 TRAIN 有1,787/5,349、S2 VAL 有117/335的完整包围盒落在单格。该普查每条网格外边取17点，使用掩码前近似包围盒，不能代替可见区域计数。短场景在更粗 Regional 下可能缺少跨区域信号。

## 等价执行修订

Decoder 共享同一Latent键集的目标Query通过分桶矩阵计算，原生稀疏局部与Middle分组读取以log-normalizer恢复同一联合softmax。短上下文使用索引路径。各像元的Query与全部已选上下文均保留。当单个Middle单元的保留Latents多于64时，Decoder采用`decoder_query_chunk=32768`；短上下文沿用`query_chunk=4096`。这是经真实样本选择的执行策略，不按传感器名称分支，也不改变模型Query数量或逻辑配对数。目标Descriptor的条件投影按块内唯一通道复用，原生位置与面积仍逐像元投影。

效率复审和降低Attention配对数的后续候选见实施文档链接。总FLOPs需包含分桶padding，不能只报告有效配对乘加。执行桶容量向上对齐16行，避免2的幂对齐引入较多无效乘加。

## 经授权的独立共享粗尺度候选

`SharedCoarseDecoder` 使用独立配置 `config_v3_h_revised_shared_coarse_candidate.json`，默认Decoder仍为逐像元两次读取版本。本候选是用户允许的结构消融，不是已采纳的新默认。

每个目标通道按完整Regional支持集合分组。支持集合来自固定几何、跨边界时保留全部父分区，几何签名不依赖QA、随机掩码或值，并进入版本化持久缓存。当前目标像元只决定参与哪些组及组内原生地理特征均值。组Query由目标Descriptor与这些地理特征构造；每组读取对应可见Regional与全部Global一次，产生64维残差。每个像元仍执行原局部Fine/Middle读取，再加上所属组的粗尺度残差，接原共享MLP。没有目标像元间Self-Attention，也没有Encoder反向更新。

与基线不同，粗尺度Attention的Query不再由该像元局部读取结果条件化，而由目标通道及该支持组的地理条件决定。这是需要质量消融的表达能力变化，不能声称数学等价。训练目标、隐藏权限、原生位置输入、所有可见编码上下文来源、模型宽度、参数数量和优化器状态量均保留。

设目标数为N，非空支持/目标通道组合数为U，粗尺度上下文长度为K：粗尺度配对与Q/输出投影从O(NKd)、O(Nd²)变为O(UKd)、O(Ud²)，逐像元残差读取为O(Nd)。局部Decoder、输出MLP和Encoder成本不因此消失。每次视图增加长度N的int32组索引；其构建、冷/热几何缓存、实际U和显存另计。

## 新旧映射

| 旧 V3-H | V3-H-R |
|---|---|
| 物理 Memory 条件化卷积 | 共享类型化 Descriptor MLP 与共享动态卷积基 |
| 从原生特征并行聚合三尺度，入口融合通道 | Fine 逐可见原生像元保留通道，Middle 再压缩 |
| 独立三尺度主干、双向交互 | 逐级向上读取，Middle 双路径 |
| Coarse 全量 Self-Attention | Regional 地理池化，固定 Global Latents |
| 层次／残差 Decoder | 两次稀疏 Cross-Attention 与原生标量 MLP |
| 旧构造包含 JEPA/EMA/Predictor | 独立 A/B1 包装器与 Encoder/Decoder |
| 旧场景坐标用于 A 掩码 | A 保留原契约，模型分区独立使用全球地理 ID |
