## 2. 实现

| 文件 | 内容 |
|---|---|
| `src/augment/spatial_degradation.py` | 高斯低通 + area 降采样 + 双线性回采样；`generic_resize` 为无低通对照 |
| `src/augment/band_dropout.py` | 按 keep_min 保底随机丢波段，返回 mask |
| `src/augment/reflectance_perturb.py` | 每波段有界 gain/offset（默认 ±5% / ±0.02） |
| `src/augment/augmentation_log.py` | 逐视图参数 + seed 记录 |
| `src/ssl/train_dino.py` | `aug.mode` 选择增强；`aug.log_params` 打开参数日志 |

五种档位（`configs/experiments_e1.yaml`）：

| ID | 模式 | 含义 |
|---|---|---|
| E1-0 | `standard` | 裁剪/翻转/旋转，无辐射或退化增强 |
| E1-1 | `generic` | 无低通的普通缩放（模糊对照） |
| E1-2 | `physical` | 先低通再重采样 |
| E1-3 | `physical_band` | E1-2 + 波段子采样 |
| E1-4 | `physical_band_radiometry` | E1-3 + 有界辐射扰动 |

物理语义：
- 低通 → 采样：模拟“同一地表被更粗的仪器观测”，顺序与物理一致；普通缩放先降采样再插值，缺少低通，正是要对照的差别。
- 波段子采样用 mask 而不是置零参与均值：被丢的波段不进入 `masked mean`，避免把人为的 0 当反射率。
- 辐射扰动只作用于反射率，不触碰 QA/valid mask，测试里有断言。

参数日志样例（`outputs/dino/auglog_aug.jsonl`）：

## 3. 实验设置

- 数据：300 个 patch（S2 96 / Landsat 94 / HLS 110），278 个 npz 落地。
- 模型：`configs/model_cnn.yaml`（11.7M 参数），DINO，out_dim 64。
- 预算：每组 150 步，batch 8，lr 1e-3，seed 0。
- 每组结果：`outputs/e1/E1-*.jsonl`、`outputs/e1/E1-*.pt`、`outputs/e1/e1_summary.json`。

## 4. 结果

| ID | 首步 loss | 末步 loss | 后 5 次均值 | 降幅 |
|---|---|---|---|---|
| E1-0 | 9.726 | 4.1579 | 4.1478 | 5.568 |
| E1-1 | 9.890 | 4.1597 | 4.1505 | 5.731 |
| E1-2 | 9.900 | 4.1586 | 4.1495 | 5.741 |
| E1-3 | 9.987 | 4.1579 | 4.1480 | 5.829 |
| E1-4 | 9.870 | 4.1597 | 4.1508 | 5.710 |

关键观察：
1. **末态全部等于 ln(64) = 4.159**（均匀分布的交叉熵），即五组的预测都塌成了均匀分布。
2. 组间差异 0.001–0.003，小于单组内的波动，**不能作为增强效果的证据**。
3. 所谓“降幅 5.6–5.8”是首步高 loss（随机 teacher 锐化）回落造成的假象，不是学到东西。

结论：**E1 的对照在本预算下不可判定**。任何“物理增强更好/更差”的说法都缺乏证据，报告中不予主张。

## 5. 失败与风险

1. **塌缩到均匀**。150 步内学生被拉到均匀分布，说明当前数据量/步数/batch 下 DINO 目标无法维持非平凡解。这与 Phase 2 的结论一致（300 步时 loss 也未持续下降）。
2. **只有单一随机种子**，未做计划要求的 3 个种子。
3. **强度匹配不严格**：`generic` 与 `physical` 共用 factor 抽样，但低通 sigma 与缩放的等效程度没有量化（未计算 MTF），因此“强度相当”目前只是设计意图，不是已证事实。
4. **没有下游证据**：计划要求跨区域线性 probe/下游初测，本轮未做；仅凭 DINO loss 既不能支持也不能否定 H1。
5. **提示**：数据侧在本轮从 120 扩到 300 个 patch，但仍比 DINO 常规规模小两个数量级。

## 6. 下一阶段建议

在进入 Phase 4（选择性尺度一致性）之前，建议先解决“基线学不动”这一前置：

1. 数据扩到 ≥2000 patch，或改用更小的输入与更强的正则，让 batch 能开到 32–64。
2. 训练 ≥10k 步，并记录每 500 步的特征统计（logits std、原型使用率）来监测塌缩，而不是只看 loss。
3. 加一个冻结特征线性 probe（产品/区域分类作代理），作为“特征是否可用”的最低证据。
4. 只有在基线能稳定学到非平凡表征后，E1 的对照才有意义；否则 Phase 4 的尺度一致性对照会重复同样的问题。

E1 的代码与流程已验证可复现（同一命令、同一 seed 得到同一 loss 轨迹），问题在数据与预算，不在实现。

## 7. Round 2 追加：E1 的结论没有被推翻，但也不再可复用于新代码

E1 的五组数据来自修复前的训练循环（逐样本前向、未跨产品混批）。此后训练侧改了四处：

1. 原型层排除 weight decay；
2. head 输入加 LayerNorm；
3. 批次跨产品混合（补齐 10 波段 + mask）；
4. 整批一次前向（8 倍加速）。

因此 E1 的绝对数值**不能**与新代码直接对比，E1 也**没有重跑**——在基线仍塌缩到均匀解之前重跑只会得到同样无信息的五组数字。这属于有意不做，不是遗漏。

当前可复现的是：同一命令 + 同一 seed 得到同一 loss 轨迹（outputs/e1/E1-0.jsonl 与 1_summary.json 一致），增强参数逐视图落盘（outputs/dino/auglog_aug.jsonl），增强模块有 5 个单元测试。

## 8. Round 5：E1 在官方基线上跑完，用探针比较

训练用官方 DINO（`vendor/dino` 的 DINOLoss/DINOHead/MultiCropWrapper），五组各 2000 步、2048 patch、batch 32、seed 0。因为不同增强改变了信息量，DINO loss 不可横比，改用冻结特征线性探针（1600 patch、区域分类、80/20 随机划分、3 个划分平均）。

| 组 | 增强 | 末值 loss | 探针准确率 |
|---|---|---|---|
| E1-0 | 标准（裁剪/翻转） | 2.68 | 0.651 |
| E1-1 | 普通缩放（无低通） | 2.49 | 0.682 |
| E1-2 | 低通 + 物理采样 | 2.62 | **0.685** |
| E1-3 | + 波段子采样 | 4.25 | 0.619 |
| E1-4 | + 有界辐射扰动 | 4.20 | 0.645 |
| off3k | 3000 步标准（更长训练） | 1.84 | **0.714** |

解读（严格按证据）：

1. 物理采样 E1-2（0.685）略高于普通缩放 E1-1（0.682），但差值 0.003 **远小于探针划分波动**，单 seed 下不能支持 H1。
2. 波段子采样明显掉点（0.619）——信息被删掉，符合预期，不能当作“增强有害”的证据。
3. 训练更久的 off3k（0.714）高于所有 2000 步的组，说明当前瓶颈是训练量而不是增强种类。

结论：**H1 未获支持**。补种子之前先看量级：E1-2 与 E1-1 只差 0.003，而更长的 3000 步标准训练（off3k, 0.714）比所有 2000 步组都高 0.03 以上。也就是说，增强种类之间的差距小于训练量的差距，做种子也只是在噪声里加精度，不会改变“没有哪种增强超过更长训练”的结论。经用户确认，种子实验停止，不再继续。
