# Phase 5 Report — 跨卫星验证（三源对齐数据）

生成时间：2026-10-31
数据：S2 patch（`landslide-seg/data/sen12`）+ 对齐的 Landsat C2 L2 / HLS S30（`earth-representation/data/sen12_*`，各 6309）

## 1. 先修了两个会让结论完全错误的 bug

| bug | 现象 | 修复 |
|---|---|---|
| patch 是 15 个时相的时间栈 | 加载器读 `read(1)`，永远拿到 2018-09-06（第 0 时相），而 manifest 记录的是事件后日期（如 2019-03-20） | 按 manifest 的 `post_index` 取对应时相（`src/data/manifest_index.py`） |
| patch 数组**转置存储** | 与同日 STAC 窗口的 NDVI 相关只有 0.10；转置后 0.959 | 加载时 `.T`（`src/data/triples.py`） |

修完后配对才成立：同一地点的 S2–Landsat NDVI 相关 **0.350**、S2–HLS **0.275**，随机配对的 −0.027。在此之前的所有跨卫星数字都不可用。

## 2. 跨卫星检索结果（修正后，1200 个样本）

| 模型 | 方向 | R@1 | R@10 | 中位排名（随机=600） | 同地余弦 vs 随机 |
|---|---|---|---|---|---|
| off3k（仅 S2 训练） | S2→Landsat | 0.000 | 0.009 | 643 | 0.535 vs 0.557 |
| | S2→HLS | 0.002 | 0.003 | 476 | 0.541 vs 0.473 |
| | Landsat→HLS | 0.000 | 0.005 | 642 | 0.427 vs 0.469 |
| mixed2k（三源混合训练） | S2→Landsat | 0.000 | 0.030 | 676 | 0.204 vs 0.235 |
| | S2→HLS | 0.003 | 0.019 | 449 | 0.622 vs 0.560 |
| | Landsat→HLS | 0.000 | 0.003 | 711 | 0.176 vs 0.244 |

## 3. 结论

**没有观察到跨卫星位置可检索性。** 两个模型的召回率都在随机水平，中位排名与随机（600）无差别；同地配对的余弦相似度也不高于随机配对。三源混合训练（mixed2k）没有改善这一点。

这意味着：当前的可变波段编码器虽然能前向处理三种传感器输入（P2 验收项），但**没有学到跨传感器共享的地表表征**——计划的核心前提在本训练预算下未获支持。

## 4. 限制（为什么不能直接下"方法无效"的结论）

1. 训练量小：两个模型都只有 2000 步、约 1200 个 patch；DINO 在 ImageNet 上是 100+ epoch。
2. 配对本身有噪声：同地 NDVI 相关只有 0.35，说明两景仍存在时间差（±30 天）与传感器差异。
3. 检索是零样本跨传感器，模型没有显式的跨传感器对齐目标；DINO 目标只要求同一图像的多视图一致。
4. 只有两个 checkpoint，没有多 seed。

## 5. 下一步建议

若要检验"跨卫星通用表征"，按性价比排序：

1. **加跨传感器正样本**：把同一地点的 S2/HLS/Landsat 作为同一实例的不同视图，DINO 的视图对就能直接约束跨传感器一致性——这是最小的改动，也最贴合问题。
2. 训练量提到 ≥5000 步，数据从 1200 提到 5000+ 三元组。
3. 用检索指标作为训练中的验证指标，而不是只看 loss。
