# 统一条件观测模型

本包是统一光谱—空间编码器与目标条件预测器的稳定入口。旧CNN-DINO、USE及其数据、权重和报告保留。旧版训练因气溶胶质量掩码缺失与目标位置描述不完整已停止；修正版数据、代码和训练独立位于`outputs/repair_v2/`。修正版同源Transformer已完成15000步，真实双向跨源组与同源继续训练对照已从其固定第10000步权重接续；同容量CNN及随机编码器对照仍按原队列推进。

修正版沿用原地点、原始采集与地域分组，不重划数据；训练S2/Landsat为162/154份，验证49/47份，测试36/31份。单源维持每波段至少50%有效覆盖，严格跨源配对还需全部17波段共同有效比例达到80%。通过的配对为训练5组、验证2组、测试1组，独立采集覆盖有限，只支持探索性结果。气溶胶策略统一作用于所有Landsat成员：排除填充，以及高气溶胶且检索无效或插值的像元；没有按模型分数选择样本。反射率和原生网格未改写，训练统计已重拟合。改变有效掩码后的分数不能直接当作模型收益。

修正版通过FP32原生100步、第50步磁盘恢复，以及双向跨源4步、第2步恢复；TVLP均为0错误、0警告。BF16实际损失相对差0.183%、梯度相对差0.520%，随后采用。工程检查只证明数值、采样、恢复和日志路径可运行，100步局部验证尚未显示稳定收益。证据见[验收](outputs/repair_v2/acceptance/acceptance.json)、[数据](outputs/phase0/release_local_v2/release.json)与[配对](outputs/phase0/cross_local_v2/release.json)。

末1000步Transformer实际损失的标准差/均值为0.499，CNN为0.371。两者梯度范数95分位分别0.0323和0.0125，均远低于裁剪阈值3，触发比例均为0。因此没有证据把震荡归因于梯度爆炸或裁剪过强；Adam的归一化更新仍可能对任务切换敏感。Landsat按目标分组的条件平均损失相差约5倍。Transformer末态17条波段的RMSE均高于Ridge，约为其1.09—8.03倍，说明差距不只来自一个异常波段。上述观察不能证明只调学习率即可弥补差距。

Ridge不是不可超越的理论上限。当前它在每个目标网格直接读取其余可见波段、按可用集合解条件回归，且每目标独立选择正则；模型使用共享条件预测器，函数参数化和优化难度不同。其同源目标数值未进入预测特征：拟合协方差虽包含目标变量，但推理求解只提取可见源波段的子矩阵和源—目标协方差，这是回归拟合所需，不等于目标泄漏。Ridge在12种未见多波段遮盖上的验证评分为0.2138，高于单隐藏波段的0.1474，也说明单波段补全本身特别适合光谱回归。网络是否能产生更可迁移的表征，仍须由冻结任务头单独检验，不能从重建误差直接推出。

建议按依赖处理，先不增加模型规模、不叠新自监督损失：

1. **先让训练可诊断。**固定一小组合法训练观测、遮盖和目标；与固定验证同时报Huber、归一化MSE、物理RMSE、分波段偏差。补齐代表训练分布的固定多隐藏波段验证，以及单隐藏波段验证。只有训练任务也拟合不好，才主要排查优化/读出；训练拟合好而地域验证差，优先检查数据覆盖和过拟合。它们用于诊断，不用测试集选择方案。
2. **减少一个更新内的任务噪声。**在32个源观测内分层轮换目标，使每步覆盖多种波段；同一可见输入尽量复用编码结果，监督多个实际隐藏波段。空间块优先按每个观测独立或分层抽取，保留正确抽样权重；不通过重复样本冒充更大有效batch。固定训练遮盖分布和传感器/方向权重。消除噪声不意味着错误地消除任务难度。
3. **使目标尺度与预测接口对应。**优先检验输出z=(y−训练均值)/训练标准差、最终还原ŷ=均值+标准差·ẑ的方案。先用归一化MSE诊断能否拟合Ridge对应关系；其优化的是平均归一化平方误差，不等同当前平均归一化RMSE。若保留Huber，必须明确标准化空间δ及其与主要评价的差异。统计仅来自训练成员，不按隐藏目标局部统计反归一化。
4. **让优化在预算内完成。**采用warmup后按剩余有效更新数余弦下降至1e-6，明确保留低学习率末段；不再把5次plateau减半当必要前置。对偏置和LayerNorm免weight decay。较低峰值LR如1e-4—2e-4是待核验候选，不是从MAE参数直接推导的最优值；只做一次有限对照，不扫描大量组合。若引入EMA，单独冻结其更新规则和选模口径。
5. **只做一个结构核查。**保留共享编码器和目标条件接口，检查空间对齐的局部线性读出能否拟合简单关系；必要时评估“可见波段线性预测+编码特征残差”。若使用Ridge作旁路，零残差回到Ridge是构造事实，不能算预训练收益；必须分别报告旁路单独、完整预测和去掉旁路的冻结表征。此项属于方法改变，不能混进旧组继续冒充单因素比较。

停止判断建议围绕固定任务评分、低学习率阶段和明确预算共同进行：只有达到最低更新、完成低学习率收尾，且固定评分在预先指定窗口无有效改善，才能记为验证平台；达到预算统一记为预算停止。改善门槛应结合固定案例与独立采集覆盖解释，0.1%并非已测出的观测噪声精度。连续多次验证不是多份独立统计证据。学习率下降、曲线更平滑和任务收益分别报告；跨源只有5个训练地点、2组训练独立采集，任何调度都不能补出地域覆盖或证明广泛泛化。

上述审阅没有证明修改一定超过Ridge。下面将候选收敛为一个训练契约，取代前述多个可选改动同时试验的理解；当前尚未实施，也不自动重跑整套实验。

### 收敛后的候选：稳定任务组成、全部隐藏目标联合监督

需要纠正因果表述：随机目标训练可以是在估计一个固定总体目标的梯度，单步方向不同并不意味着数学目标每步改变，更不证明模型永远学不出来。当前问题是每传感器整批共享一个目标，使任务抽样的相关性较高；此前少量案例的负梯度余弦只说明局部冲突，不证明全部任务不可兼容。跨源查询使用完整源输入，因此多波段隐藏也不能独自解释跨源预测落后Ridge。

首轮保留现有编码器、目标查询和预测器，优先改变监督组织与优化契约；EMA、Ridge旁路、新目标嵌入、梯度投影及更大模型均不纳入首轮候选。用以下一次受控候选先回答“现有结构能否在稳定的联合目标下学好”。若多个工程因素同时改变，结果只能归属于整套修订训练方案，不能声称单因素因果。

| 项目 | 明确约定 |
|---|---|
| 可见输入与目标 | 先选择隐藏集合M；编码器只得到其补集的有效观测；同一份编码结果查询M中全部真实波段，目标之间不互相输入真值 |
| 每次更新的任务组成 | 同源仍16个S2和16个Landsat。预先生成平衡的合法遮盖日程，使每个有效batch覆盖全部目标波段；隐藏数分布在短周期内保持原1至floor(C/2)均匀意图，目标出现次数尽量相等。12种保留组合不进入训练日程；遮盖与地点索引独立打乱 |
| 损失归一化 | 每目标先按真实有效像元平均，再对本batch该目标的观测平均，再对传感器内波段等权平均，最后两传感器等权平均。使用训练集固定均值/标准差的归一化MSE，预测接口反归一化为物理反射率 |
| 空间抽样 | 同一观测的各目标使用同一组物理Tile；不同观测独立或分层抽样。继续保持目标原生网格与无偏抽样权重，不把同一位置重复查询计为新增源观测 |
| 梯度累积 | 一个有效batch开始清零；各微批和目标贡献按全batch分母累积；全部任务完成后统一裁剪和optimizer.step。不能在目标间分别step，也不能把每微批独立均值直接相加 |
| 真实跨源任务 | 保留8个独立S2、8个独立Landsat及8个配对槽的原组成；严格配对不足8个独立地点时仍如实记录重复。完整源输入每次编码一次，两个方向分别查询全部真实30m目标波段，方向与波段等权；同源损失和跨源损失各权重1 |
| 优化器与日程 | 候选峰值LR固定1e-4，AdamW、矩阵参数WD0.04，偏置和LayerNorm不衰减，clip3。warmup500步；随后余弦下降，在总有效更新预算80%处到1e-6，末20%保持该LR。此数值是待检验设计，不是已证实最优 |
| 验证与选模 | 固定训练诊断成员与固定验证成员都用固定遮盖。常规验证同时包含单隐藏及代表训练分布的合法多隐藏组合，主评分预先固定为两部分等权归一化MSE，传感器/波段继续等权；单隐藏nRMSE、物理RMSE和偏差并列。跨源每方向全部波段评价；原12种保留组合另列，不用于调度 |

对应同源损失为L_mask=(1/2)Σ_s[(1/C_s)Σ_b mean_{i:b∈M_i} mean_valid((ŷ_ib−y_ib)/σ_sb)^2]。必须保证每个batch的每条目标至少一次有效监督；样本遮盖日程只依赖合法掩码和元数据，不依赖目标数值或模型难度。极端QA造成目标无有效监督时按真实贡献归一化并记录，不能悄悄把该目标记为零误差。此式有意固定每条波段权重，不能替换成把所有隐藏像元摊在一起求平均，否则多隐藏样本、10m目标和有效面积大的观测会改变任务权重。

例如同一幅S2隐藏B02、B08、B11：编码只见其余合法波段；三个查询从同一编码结果分别预测三条目标，所有损失一起更新。联合梯度仍可能存在抵消，优势是每次更新更接近预先定义的平均任务；它不是消除梯度冲突的保证。与原方案相比，编码次数可以复用，但解码及目标曝光会增加；须报告真实解码量、像元曝光和耗时，不能只按相同optimizer步数称严格等成本。

只保留一项关键拟合诊断：在少量固定合法训练观测上关闭增强、固定遮盖和目标位置，以相同真实目标比较现有结构与线性参照。观察每个目标的训练误差是否同时下降，以及是否仍持续出现条件偏差。如果连该固定任务都明显学不好，应停止长训，定位目标条件响应和局部读出；如果训练拟合良好而固定地域验证差，则优先处理泛化与配对覆盖，不能继续把问题笼统归为学习率。小样本诊断不能用于宣称研究收益。

候选停止规则也随日程简化：达到阶段最低步数并进入固定低LR末段后，连续10次固定验证未超过预先设定的0.1%相对改善，可记验证平台并停止；最佳权重仍按绝对最低主评分保存。若预算不足以容纳最低步数、500步warmup和10次验证的收尾，必须先解决预算安排，不能宣称早停可达。0.1%是工程停止约定，不是统计显著性。达预算而未满足平台条件，仍记预算停止、未确认收敛；当前仍在使用旧训练契约的作业不套用这一新规则。

实施前须重新核对实际已花费与剩余预算，确定一个候选及相应参照的可执行上限；不自动追加完整实验矩阵。跨源任务继续是正式方案的重要部分，但本次修改不能扩大5个训练地点、2组独立训练采集所能支持的泛化结论。

## 产品接口与网格口径

```python
from observation_model.api import ConditionalObservationModel, ImageProduct

model = ConditionalObservationModel("observation_model/outputs/runs/masked_transformer/best_unlabeled.pt")
product = ImageProduct.read("已准入的原生1200m窗口.npz")
```

读取器从缓存侧文件自动取得波段、定标、实际日期、来源、有效性和网格，也可通过`ImageProduct.from_four_view(base, site, sensor, bbox)`直接读取已存在的原始产品窗口。首版明确处理1200 m窗口，不默默裁剪整景，也不接受缺少物理与地理信息的匿名数组。

## 统一评价

`python -m observation_model.evaluate --help`提供同源/跨源、验证/测试、单波段/12种未见遮盖组合评价。所有方法使用同一份真实目标QA，预测覆盖不足的像元仍计入误差并单列数量。逐波段报告MAE、RMSE、偏差，以及非平坦场景的Pearson和Spearman；调度评分仍是传感器等权的逐波段RMSE/训练集标准差。

`python -m observation_model.compare --help`比较相同成员和遮盖，以原始采集及同地点关系连接后的组进行配对Bootstrap。扩展门槛使用物理反射率单位的逐波段RMSE，并按传感器/方向等权汇总；用于调度的归一化评分另列。重复窗口不充当独立采集。测试集合只能在选择配置和预训练权重后显式运行；当前验证结果不能称为测试成绩。同源均值、邻近波段插值、Ridge和小型MLP使用同一入口评价。

跨源评价的`--pair-set strict`对应冻结的严格监督成员；`broad`保留时间差不超过两天、共同QA合格而不按NDVI筛选的诊断成员；`all_local`另包含长时差和配准不确定的本地组合。后两者不用于阶段扩展门槛，按时差、NDVI变化/差异、平坦目标与配准不确定性分列，不能和严格配对分数混排。

## 冻结表征与辅助任务

`frozen_features.py`在相同1200 m窗口提取特征，并在提取前后校验编码器参数和运行统计的哈希。新模型在注意力编码后按有效波段汇聚；历史CNN-DINO、官方完整DOFA及官方完整AnySat使用各自编码器。各方法特征统一读到40×40的30 m网格，以float16存储，轻量头用FP32计算。官方模型的全部编码器权重严格/按官方dense契约加载，不拼接缺权重的重建头。

`frozen_probe.py`仅训练线性分类头或1×1分割头，seed=1234、batch=32、最多2000次更新，每100次验证，独立调度，保存最佳与末态。特征通道数不同导致头参数数不同，实际数量另列；不称严格等容量比较。分类和分割的头均在训练成员拟合统计，编码器不参与优化或标签选模。

- WorldCover复用原60/20/20地域划分，取中心1200 m窗口；20 m缓存和地图标签只支持地图一致性补充。10 m输入通道由20 m缓存插值得到，不能作为原生10 m细节证据。
- 滑坡使用既定2223训练/669研发验证成员，取相同1200 m窗口。20 m波段由原10 m公共网格缓存面积聚合，属于辅助诊断。窗口小于历史1280 m报告，须重新评价所有参照，不直接混用旧分数。
- `outputs/phase5/reference_provenance.json`记录历史CNN-DINO可追溯的训练地域和广岛36幅无标签验证影像接触；它不等于未接触过广岛的参照。官方模型的历史地域覆盖无法确认，保留限制。

参照特征位于`outputs/frozen_features/`，轻量头与评价位于`outputs/probes/`。WorldCover参照提取/探针和滑坡参照队列独立于新模型预训练推进；新模型必须先由无标签验证确定预训练权重再进入这些任务。`outputs/releases/probe_v1/`绑定辅助评价代码；滑坡队列入口为`run_reference_slides.ps1`，实时状态见`outputs/reference_slides_queue_status.json`。

尚未交付：正式训练的最终比较、新模型冻结表征诊断、条件满足后的空间约束训练及完整结果图表。独立人工土地覆盖标签缺失时，语义结论保持未验证；滑坡标签不用于优化新编码器或选择预训练权重。
