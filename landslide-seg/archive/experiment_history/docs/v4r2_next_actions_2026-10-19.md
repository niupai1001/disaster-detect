# v4r2后的有限训练控制与遥感表征对照

状态：本文件的低编码器学习率对照与DOFA接入/正式训练已完成，结果见 `reports/v4r3_execution_report_2026-10-19.md`，复现见 `docs/v4r3_reproduction.md`。以下保留执行前的计划与边界，不改写为事后假设。

## 1. 决策依据

统一decoder重训后，早态encoder的DEV IoU/AP为0.2731/0.3694，末态encoder为0.2463/0.3450；末态encoder反而更拟合TRAIN。固定encoder时decoder单独训练仍会使DEV下降。两组共同漏检1023/1679个可评对象，含71/77个tiny。

这表明应控制预训练表征的更新，同时继续研究表征来源和空间细节。它没有证明某一种遗忘机制，也没有解释主模型best仅约0.31的全部原因。不能把下一阶段缩成长期调学习率；本轮probe到此结束，不继续初始冻结组、三seed或四档数据量矩阵。

## 2. 一个训练策略对照，所有主模型参数继续可训练

主用架构沿用全量SegFormer-B0 direct10 + 原网格细节残差，复用原正式配置及官方权重。与v4r1全量主模型比较，唯一策略因素为降低第一层输入卷积之外的预训练encoder学习率；已有 `optim.first_conv_lr` 能保持输入适配的学习率，不需要增加新训练框架。

| 项目 | 既有全量主模型 | 新受控组 |
|---|---:|---:|
| 首层十通道输入卷积LR | 6e-5 | 6e-5 |
| 其余预训练encoder LR | 6e-5 | 6e-6 |
| 原decoder、二值头、Stem/残差融合LR | 6e-4 | 6e-4 |
| 参数是否可训练 | 全部 | 全部 |
| TRAIN/DEV/seed | 2223/669/1234 | 相同 |
| 成功更新/batch/曝光 | 3600/64/230400 | 相同 |

保留同一BCE+Dice、增强、warmup/poly、权重衰减、每100步双DEV选模、0.5阈值及全部尺度指标。使用独立配置/目录，建议名称 `segformer_b0_direct10_detailres_pretrained_encoder_low_lr_n100_u3600_s1234`。从官方初始化重新训练，不从probe checkpoint续训，不带probe冻结字段。

这个对照把输入适配的学习速率保持不变，优先检验深层表征更新幅度，而不是把新增七波段一并放慢。来源probe同时包含输入与深层变化，因此该组只是针对一个解释的干预，不预设结论。标准无Stem的诊断结论能否迁移到主用细节架构，以同架构受控结果为准。

只跑这一档学习率，不随后扫描多个倍率。对比best与last的AP、两事件IoU、小对象绝对匹配数及原固定案例；只有平均值改善但某事件/小对象退化时如实报告权衡。单seed不声称统计显著；末端持续改善也不自动延长到300epoch。此组只能检验训练策略，不能被包装成新的结构贡献。

## 3. 同期推进DOFA官方分割接口可行性，进入表征来源问题

不把上面的学习率对照作为此项开始的前置条件。以已归档官方commit及匹配权重为起点，复用官方分割特征/decoder路径和已有数据评测框架，先做接口可行性，再明确一个完整系统对照。

必须先解决：

1. 现有十波段与波长列表、单位/归一化对应，实际权重加载报告及完整哈希；权重未获得时明确阻碍，不用随机初始化冒充预训练。
2. 128×128输入的patch16 token网格及位置编码。所阅默认分类路径使用224网格和全局池化，不能原样当分割encoder；优先使用官方分割接口，不将图像静默放大到224/1024来替代原网格信息。
3. 密集特征、输出128×128、有效区loss、梯度、checkpoint重载；显存与实际可行batch。保持单期/同十波段/同TRAIN与DEV，不增加DEM或目标域图像。
4. 若decoder、预处理或特征尺度与SegFormer不同，明确这是完整系统对照，不能声称唯一变化是encoder，也不能把结果纯归因遥感预训练。冻结probe和完整微调各自的可训练部分、模式和适配参数必须明确。

接口成功后先固定一份配置完成真实训练，不同时展开B2、Prithvi、TerraMind、AnySat等矩阵。不同系统的合理预处理可以保留，但来源与差异需显式记录；评测划分和口径保持一致。

## 4. 结构路线保留为有证据的后续，而非重复晚期融合

方法表已覆盖SegFormer、HRNet、TransLandSeg、DOFA及公开摘要中的LandslideSegFormer。若后续仍集中漏检同一批小对象，再研究更早的浅深信息交换或细粒度解码/监督。原项目已经有晚期SUM/AFF等试验，不将再次加入晚期注意力当新方向。

BCE按有效像素归一、Dice逐图计算，不等于实例等权；空间粒度、表征和监督目标是不同因素。如选择对象/尺度监督，应单独对照，不与encoder、decoder、采样同时修改。

继续单seed；开发阶段不推理Italy或New Zealand，不重划事件，不重写历史缓存/标签，不将未核实空标注图块当可靠负影像。后续报告必须含实际结果、未验证部分和阻碍。
