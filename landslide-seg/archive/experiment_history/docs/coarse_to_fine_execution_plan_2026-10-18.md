## 1. 已核对的工程起点

- 当前 A1：MiT-B0、官方 SegFormer 解码器、10 通道直接适配、32 通道 Spectral Stem、残差融合头。编码器、解码器及新增模块共同训练。
- 当前前向为 `final_logits = base_logits + delta_logits`；delta 读取解码特征和 Stem 特征，没有显式读取粗定位概率。损失只监督最终输出。因此当前 A1 是单阶段基线。
- `models/full_model.py`、`coarse.py`、`refiner.py` 保留了旧粗细阶段，但依赖旧特征金字塔，未接入 SegFormer 训练器；代码存在不等于该路径已完成有效训练。
- `dataset_and_modules.md` 描述早期 12 波段及基础模型流程，不能用其历史样本规模替代当前 10 波段实验配置。当前数据版本以 `configs/segformer/v3clean/base.yaml` 和实际运行快照为准。
- U-Net 的已有环境探测只证明 SMP 0.5.0 的随机初始化 ResNet18 U-Net 能前向、反传；预训练权重加载和正式训练尚未验证。

## 2. 固定范围与比较条件

1. 所有新实验仅使用 seed=1234。历史多种子结果保留，但不新增三种子任务，不据此宣称统计显著性。
2. 固定 `s2_10band_v3_p20` 的 manifest、划分、缓存、统计量、valid 规则和增强。Hiroshima 用于验证与选模型，Italy 用于最终报告；Italy 已用于历史诊断，不能再声称是从未查看的盲测集。
3. 输入顺序固定为 B02/B03/B04/B05/B06/B07/B08/B8A/B11/B12。新 SegFormer 实验沿用 A1 的 direct10 初始化，公共参数尽量保持完全相同的初始张量，并保存加载清单。
4. 主干保持 MiT-B0 和官方解码器；不扩大到 B2，不直接把 150 epoch 翻倍。TerraMind、AnySat、TiM、文本语义及旧全模型保留接口，但不加入本轮主训练。
5. 基础预算为有效 batch=64、FP32、3,600 次实际 optimizer 更新；沿用 AdamW、encoder LR=6e-5、decoder/new LR=6e-4、weight decay=0.01、5% warmup、poly 调度、梯度裁剪1.0。实现时核对调度器确实按该步数预算工作。
6. 每组从指定的预训练权重和新增模块初始化开始，不各自从不同历史 best 续训。历史 A1/1234 仅在配置与实际更新预算相符时直接复用，否则补一个明确标注的匹配基线。
7. 训练 OOM 时先检查显存占用；必要时统一采用微批量与梯度累积，并记录归一化层差异。不能默默改变某组的有效 batch、精度或训练预算。

## 3. 目标架构与接口

### 3.1 阶段一：复用 SegFormer 的粗定位输出

```text
10 波段影像 → 官方 MiT-B0 → 官方多尺度解码器 → 解码特征 D
                                                └→ 二分类头 → 粗 logits C
10 波段影像 → 现有 Spectral Stem → 全网格细节特征 S
上采样 D + S + sigmoid(上采样 C) → 轻量精分头 → 修正量 Δ
最终 logits F = 上采样 C + Δ
```

直接复用官方解码器的二分类输出作为定位输出，不另造一个重复的完整定位编码器。这里的“全局”指当前输入图块内的上下文，新增结构不会自动获得图块以外的地理信息。

粗 logits 双线性上采样到输入尺寸后监督。第一轮使用原始 mask 和 valid，不把二值小目标用普通下采样缩没，不引入膨胀标签、存在性分类或新的标注。

### 3.2 阶段二：全图软定位引导精分

- 保留现有 Stem 的 `1×1光谱融合 → 3×3局部卷积`，输出32通道、全程不下采样。
- 参考实现：`concat(up(D), S, P) → 1×1 Conv(通道和,64) → GELU → 3×3 Conv(64,64,pad=1) → GELU → 1×1 Conv(64,1)`，其中 `P=sigmoid(up(C))`。通道数从实际解码器读取，不硬编码为所有骨干通用。
- 最后一层零初始化，使初始精分输出等于粗输出；这是稳定初始化，不是精分已有效的证据。
- 粗概率作为连续条件输入，不做硬阈值裁剪，不用概率乘法把低置信区域直接置零；全图细节路径保留补救粗阶段漏检的机会。
- 训练和推理都使用预测的 P，禁止用 GT mask 替代定位输入。首轮不 detach P，联合反传；记录粗头与精分头的梯度和更新。
- 沿用旧模块 `coarse_logits`、`fine_logits` 的输出语义。旧 FineRefiner 是另一套金字塔解码器，不直接照搬它替换官方 SegFormer 解码器；在现有残差融合头上扩展更符合本轮范围。
- 统一返回 `logits`（最终输出，兼容旧评测）、`coarse_logits`、`fine_logits`；调试时可返回 coarse_prob、delta_logits。标准 A0/A1/B0/B1 路径及历史 checkpoint 加载行为保持兼容。

这是“软定位引导的全图两阶段”，不是硬 ROI 裁剪级联，也不是两个独立训练作业。它是否真正利用了定位输入，必须通过消融和运行证据判断。

## 4. 损失与训练策略

保持已有 valid-aware 二值损失口径：

`Lseg(Z) = 0.5 × masked BCEWithLogits(Z,Y) + 0.5 × masked Dice(Z,Y)`

定位监督组使用：`Ltotal = Lseg(F) + 0.5 × Lseg(up(C))`。

- λ_coarse=0.5 为首轮预先固定的值，不表示已经优化。分别记录 coarse BCE/Dice、fine BCE/Dice、总损失与各参数组 LR。
- 不跨不同目标函数用 total loss 大小评价优劣。增加辅助项也改变梯度规模，不能把收益全部归因于定位机制。
- 第一轮所有组继续全量微调，不同时叠加 Focal、冻结解冻、边界损失、新增强或采样策略，以便分辨新增任务与结构的贡献。
- 第二轮仅在结果支持时做一项针对性调整：粗定位仍漏检时研究粗损失/采样，定位覆盖够但边界差时研究边界细化，训练不稳定时研究分阶段优化。每项独立对照，不自动启动参数网格。

## 5. 实验矩阵与执行顺序

| 编号 | 结构与监督 | 回答的问题 |
|---|---|---|
| A1-base | 历史匹配 A1，只有最终监督 | 当前起点 |
| A1-AUX | 原 A1 结构不变，额外监督官方 base_logits | 增加定位辅助监督是否有用？ |
| CF1 | 新精分头 + 预测粗概率条件 + 粗/细双监督 | 定位引导精分整体是否改善？ |
| U0 | SMP ResNet18 U-Net，10通道，BCE+Dice | 成熟卷积模型对照 |
| CF0 | 与 CF1 完全相同的头和双监督，条件通道始终填0 | CF1 的收益是否来自显式定位条件？ |

顺序：A1-base匹配确认 → A1-AUX → CF1 → U0 → CF0。CF0 是正式机制消融，交付结论前必须完成；CF1 与 A1-AUX 的差别还包括精分头容量，不能单凭这两组声称定位引导有效。CF0 只关闭显式概率通道，仍保留相同的粗 logits 残差基础路径，报告时说明这一点。

CF0/CF1 使用相同结构、公共初始张量、样本顺序和预算；同一个 seed 并不足以自动保证这些一致，需显式控制模块初始化和 DataLoader 随机数生成器。

U0 使用 SMP 的标准 Unet + ImageNet 预训练 ResNet18 编码器；先加载3通道权重，再显式扩成10通道，将 RGB 映射到 B04/B03/B02，其余通道置零且可训练。无 Spectral Stem，无粗定位辅助损失。复用相同预处理、训练预算和指标；明确它与 SegFormer 的预训练任务、参数量不同，该比较不是严格的纯架构因果试验。权重不可用时记录阻碍，不以随机初始化结果冒充预训练对照。

### P2：正式训练前的实际运行门槛

1. 使用真实缓存样本验证 `[B,10,H,W] → [B,1,H,W]`，粗、细输出对齐；前向及所有有效损失有限。
2. 含正样本、空标注及无效像素的反传检查：无效区域不参与监督；全无效 batch 安全跳过且不计 optimizer 更新。验证粗监督确实进入损失。
3. 检查编码器、输入适配、解码器、Stem、精分头的梯度和 optimizer 更新。零初始化末层使上游精分梯度首步可能为零，需在若干更新后检查，不能误判为永久断路。
4. 固定特征、替换 P，验证训练若干步后 CF1 输出确实依赖条件通道；CF0 对被替换的 P 不敏感。这只是工程路径验证，不等同于定位条件对真实分割有效。
5. 固定8张训练图（包含小目标和背景），关闭随机增强，做最多500更新的小样本过拟合。记录完整曲线、前后预测与前景Dice，目标为训练前景Dice≥0.90；未达到时先分析优化/实现原因，不直接启动长训或宣称网络有效。不将该结果当泛化指标。
6. 保存/加载 checkpoint 后在 eval 模式比较输出，并验证短程断点恢复的步数、LR、优化器状态。确认旧 A1 路径不因公共代码变更发生意外漂移。

每个模型变体至少完成真实样本前向、反传、参数更新与重载；重点过拟合验证 CF1 和 U0。上述是训练正确性门槛，不是重复验证数据来源。

### P4：阶段分析、消融与最终报告

- 主指标：滑坡 IoU、Dice、Precision、Recall，沿用当前 metric v2 聚合与 valid 口径。
- 对象指标：继承当前小/中/大阈值（0.5ha、2ha）与匹配阈值，额外单列1–4像素对象；无该尺度对象时标为 N/A 并报告样本数，不记为0。
- 边界F1：沿用1像素容差；说明这是共同输入网格上的边界精度，不代表恢复了原生20m波段中不存在的10m细节。
- 粗细比较：同一个 checkpoint 分别评估粗输出和最终输出；展示粗阶段漏检→精分找回、粗误检→精分消除、精分新增误检和边界修正。
- 定位覆盖诊断：对每图有效像素按粗概率排序，在固定5%/10%/20%面积预算下报告滑坡像素覆盖率及对象命中率，平分时固定排序。对象“命中”只表示有有效GT像素进入候选区，不等于达到IoU匹配的对象召回；两者分开报告。
- 固定案例来自训练、Hiroshima、Italy，复用已有选择并补齐实际存在的失败类型；记录ID，展示RGB/假彩色、GT、粗概率、粗mask、精分mask、误差图。训练案例只作诊断，不计入泛化结论。
- 无滑坡误报率仅在已有可确认的负样本上报告；没有确认依据时注明未验证，不把空标签自动当作无滑坡事实，不新增大规模标签审计前置条件。
- 成本：总/可训练参数、同设备同精度的 batch1 延迟和吞吐、训练显存峰值。计时包含输入适配、Stem和精分，使用预热及CUDA同步；记录输入尺寸、batch和是否含数据读取。

## 7. 决策与完成标准

- CF1 优于 A1-AUX 但不优于 CF0：只能支持新增精分结构的价值，不能证明显式定位条件有贡献。
- 粗覆盖率低、精分也救不回：下一步优先定位任务、困难正样本学习及粗损失；不先切硬ROI。
- 粗覆盖足够但最终误检高：优先精分的背景判别；边界差则考虑局部/不确定性细化。第一轮不接入 PointRend 等额外模块，以免同时改变太多因素。
- U0 明显更好：如实报告卷积对照优势，分析小样本迁移与局部特征差异，不为了维护预设架构隐藏结果。
- 所有变化都未改善：保留失败结果，再依据训练/验证差距决定下一项实验；不自动扩数据、扩主干或翻倍epoch。

完成交付需具备：四个新组 A1-AUX/CF1/U0/CF0 的配置及实际训练评测结果、匹配 A1 基线、checkpoint、曲线、阶段可视化、参数/速度/显存报告，以及可执行的复现命令。各项明确标为已运行、未验证或受阻；单种子结果只支持本轮开发判断。

当前已完成的是代码路径核对与本执行计划。新模型实现、真实样本运行门槛、新组训练和机制结论均待执行；U0 预训练权重可用性与新增模型实测资源需求仍待确认。本文未启动训练，也未修改数据、生产模型或历史checkpoint。
