# A1 单种子改进计划

> 当前执行顺序已由 [SegFormer 定位引导精细分割执行计划](coarse_to_fine_execution_plan_2026-10-18.md) 替代。本文保留为历史方案；Focal、空间卷积及冻结策略不再作为首轮独立主线。

依据用户最新要求更新：当前重点是让模型学得更好。上一版计划过多偏向数据审阅和实验归因，对 A1 本身的训练、损失和结构调整不足。本版替代上一版后续安排。

## 固定约束

- 所有新增实验只使用 **seed=1234**；已有多种子结果作为历史记录，不再要求重复三种子。
- 使用当前 `s2_10band_v3_p20` 的同一数据清单、划分、波段顺序和训练统计量，不重新选图、不扩量、不改标签。
- A1 作为改进对象：MiT-B0 + 官方 SegFormer 解码器 + 10 波段直接适配 + Spectral Stem。保留成熟编码器和解码器。
- 复用现有 A1/1234 的 v3 基线；新增实验独立保存，不覆盖旧 checkpoint。每组从同一官方预训练及指定的新层初始化开始，不在不同历史 best 上分别续训造成额外混杂。
- 原则上保持 batch64、FP32、3,600 更新步、现有增强、验证频率和阈值0.5。先按这个预算筛选，不直接延长到300 epoch。
- 不启动数据×训练步数的大矩阵，不要求先完成对象级标签审计，不把大量数据验证作为模型训练的前置任务。
- 仅保留必要检查：输入/输出尺寸、波段顺序、valid处理、梯度更新、有限损失、预训练加载及checkpoint重载。这些用于避免错误训练，不是新的数据研究。

## 当前 A1 的实际起点

训练：编码器、官方解码器、二值头、Stem、融合头同时全量微调；编码器基础LR为6e-5，其余解码器/新层为6e-4，AdamW，5% warmup+poly。

损失：`0.5 masked BCEWithLogits + 0.5 masked Dice`。

结构：Stem有1×1光谱融合和3×3空间卷积；但上采样解码特征与Stem拼接后，融合头只有`1×1 Conv → GELU → 1×1 Conv`。因此**融合后的联合特征没有再经过邻域空间卷积**；不是整个模型缺少空间建模。

## 第一轮实验：三个 A1 改进方向 + U-Net

| 标识 | 相对原 A1 的变化 | 要回答的问题 |
|---|---|---|
| A1-base | 现有单种子基线，不变 | 比较起点 |
| A1-L | BCE项换成masked Focal，保留Dice | 减少容易背景的损失贡献，是否改善漏检和困难背景误检？ |
| A1-S | 融合头增加一个3×3空间卷积 | 融合后的光谱/语义邻域建模，是否改善细长目标、断裂和边界？ |
| A1-T | 编码器短暂冻结后逐步解冻 | 先建立适配和分割输出，再微调预训练特征，是否改善早期迁移稳定性？ |
| U0 | ResNet18编码器的标准U-Net，10波段输入 | 成熟卷积编码器及U-Net解码路径能达到什么水平？ |

这不是把三项改动一次性叠加。先分别对照A1-base，只组合单项有效的改动。A0/B0/B1保留已有结果用于背景比较，不因每个A1改动把四组全部重跑。

### A1-L：Focal + Dice

首个预设为 `0.5 masked Focal(gamma=2, alpha=None) + 0.5 masked Dice`。Focal的逐像素定义为`(1-p_t)^2 × BCE`，有效像素求和除以有效像素数；不把无效区域作为背景参与计算。保留现有Dice口径，不顺带改变聚合方式。

这里先不增加正类权重，因为当前既有漏检，也有亮地表大块误检。Focal用于改变容易/困难像素的贡献，不保证解决小对象，也可能强化疑似错误标签，所以必须看固定失败案例及P/R。

可复用成熟逐像素Focal实现并加valid归一化，不直接套一个忽略mask口径的默认loss。SMP提供Focal等损失接口，参数见[官方文档](https://smp.readthedocs.io/en/v0.5.0/losses.html)。记录Focal、Dice各自数值和梯度情况；不能跨损失函数用total loss大小判断谁更好。

### A1-S：加强已有融合头

保留现有Stem和官方解码器，只将融合头改为：

`concat(up(decoder), stem) → 1×1 Conv(288,64) → GELU → 3×3 Conv(64,64,pad=1) → GELU → 1×1 Conv(64,1)`。

输出仍为`L_base + ΔL`；末层继续零初始化。新增3×3卷积作用于128×128共同网格，不下采样、不超分辨率、不新增完整编码器。相对原头增加36,928个参数（3×3卷积含bias），运行时核验参数量、显存和延迟。

这可能帮助处理邻接像素的联合决策，也可能进一步平滑/合并小对象，必须同时检查边界F1、小对象召回和误检。不能预先承诺结构改动一定改善细节。

### A1-T：新层/分割路径先适应，编码器后解冻

前180次更新（总预算5%）冻结编码器；训练官方解码器、新二值头、Stem及融合头。冻结期间编码器使用eval模式以避免随机训练行为，其他模块正常train。

第181次更新起解冻编码器，在随后180次更新内把encoder LR从接近0升至对应全局调度目标，之后跟随原poly；头部沿用原全局调度。总预算仍是3,600次更新，冻结阶段计入预算。记录所有阶段的可训练参数、LR和真实更新次数。

此实验检验短暂冻结与解冻调度这个整体训练策略，不是回到长期冻结基础模型，也不等价于此前只改首层LR的T1。

### U0：保留一组标准U-Net对照

复用SMP 0.5.0的`Unet(encoder_name='resnet18', ...)`，加载ImageNet预训练编码器，再显式把首层扩成10通道：RGB权重映射到B04/B03/B02，其他七通道置零且可训练。标准U-Net解码器从初始化开始训练，不加Spectral Stem。

共用现有数据、BCE+Dice基线损失、预处理和训练预算。U0在比较中明确标为“ResNet18编码器的U-Net”，不是原版U-Net的逐层复现。参数量与预训练任务不同，因此比较实际方案效果和成本，不宣称纯架构因果。

当前环境结构探测已通过；正式预训练加载、参数更新和训练效果尚未验证。此前随机初始化的前向/反传只属于兼容性检查。

## 执行顺序

1. 实现并跑A1-L：先验证valid及梯度，再开始单种子正式训练。
2. 实现并跑A1-S：复用相同基线和预算，检查新增空间融合是否有效。
3. 跑U0主对照，获取独立架构参照，不等待数据扩量或全面标签审查。
4. 跑A1-T，检查训练策略能否改善迁移与验证曲线。
5. 根据验证集结果组合有效改动，最多先增加一组A1组合实验；无效项停止，不进行无边界的超参网格搜索。

若实际计算资源允许，可以并行跑互相独立的实验，但统一设备/精度测量口径。上述是计划，不表示已启动这些训练。

## 判断标准和最少验证

单个种子用于开发筛选，记录结果但不宣称跨种子稳定性。按固定验证集IoU选择checkpoint，同时报告P/R、Dice、小对象召回、边界F1和固定案例。IoU涨但误检明显增加，或小对象收益伴随边界恶化，都应明确呈现，不能只挑一个指标。

每组结束后用现有metric v2评测固定测试集合；Italy作为历史诊断集，不根据它循环调参。没有必要每次重复全数据审计或重算已有的尺度构成。训练曲线、实际学习率、checkpoint和预测图必须保存。

数据问题只有在出现明确训练异常或固定失败案例有具体矛盾时，才做局部核查；不自动扩大为整批核查。低精度并不证明数据一定正确，但目前已有大量审阅证据，应把主要算力和开发时间转回模型实验。

## SMP 是什么

SMP是 **Segmentation Models PyTorch** 的缩写，Python包名`segmentation_models_pytorch`。它是现成的图像分割模型库，不是一个单独的模型，也不是数据集。它提供U-Net等网络、可选的预训练编码器及损失函数。

本项目只需使用它提供的U-Net结构和预训练编码器接口。数据读取、10波段适配、训练流程、损失mask、指标和报告仍由现有工程管理；安装SMP不会自动获得训练好的滑坡模型。

本轮修改仅为执行计划；生产模型、配置、数据和checkpoint未改动。旧三种子/扩量矩阵计划的当前执行优先级已取消。
