# 辐射定标验证：Sen12 的 DN 与官方 L2A 反射率比对

> 2026-10-18 · 脚本 `scripts/verify_radiometry.py` · 结果 `outputs/logs/verify_radiometry.json`

## 1. 做法

1. 取 3 个认证样本（italy），每个都有 STAC item id、日期、CRS、bbox；
2. 在 **Microsoft Planetary Computer** 的 `sentinel-2-l2a` 集合检索**同一景**产品
   （按点位 + 日期 + MGRS 瓦片号对齐，独立于回补 B01/B09 时用的 AWS sentinel-cogs）；
3. 用产品元数据的 `scale/offset` 换算 BOA 反射率；
4. 最近邻重投影到样本网格，与 Sen12 的 `DN/10000` 逐像元相减。

> 说明：这不是"和 CDSE 端点比对"，而是"和另一家独立分发的同一 ESA 产品比对"。
> 真正对 CDSE 比对需要 OAuth 凭据，脚本已预留 `--cdse-token`。

## 2. 结果

3 个样本、12 个波段，**中位有符号差全部是 −0.1000 ± 0.001**：

| 样本 | PC 产品 | 中位 \|Δ\| | 中位有符号 Δ |
|---|---|---|---|
| italy_s2_2330 | `S2B_MSIL2A_20230617…T32TPQ` | 0.0999 | **−0.0992 ~ −0.1020** |
| italy_s2_2349 | `S2B_MSIL2A_20230528…T32TPQ` | 0.1011 | **−0.0989 ~ −0.1094** |
| italy_s2_2270 | `S2A_MSIL2A_20230523…T32TPQ` | 0.1000 | **−0.0998 ~ −0.1050** |

逐波段示例（italic_s2_2270）：

| 波段 | Sen12 中位反射率 | PC 中位反射率 | 有符号 Δ |
|---|---|---|---|
| B02 | 0.0247 | 0.1247 | −0.1000 |
| B04 | 0.0299 | 0.1299 | −0.1000 |
| B08 | 0.3804 | 0.4804 | −0.1000 |
| B12 | 0.0944 | 0.1939 | −0.0998 |

## 3. 结论

**Sen12 的 DN 系统性比官方当前 L2A 产品低 1000 DN（= 0.1 反射率），常数级、全波段一致。**

唯一能解释"恰好 1000 DN、跨波段跨样本不变"的是 Sentinel-2 **处理基线 04.00 的
`BOA_ADD_OFFSET = −1000`**：ESA 把偏移量写进产品元数据，读取方需要把它加回去；
Sen12 的 `data_harmonized` 只做了**时间序列内部的辐射一致性**，没有做这一步基线协调。

**相对结构（去除该常数后）是一致的**：残差中位 0.002–0.02（20–200 DN），
说明两边确实是同一产品的同一批像元，空间配准也正确。

## 4. 已做的处理

在读取缓存时施加可配置偏移（缓存仍保存原始 DN，不改数据）：

```yaml
data:
  boa_offset_dn: 1000.0   # 加回基线 04.00 的 -1000 DN
```

`load_sample(rec, boa_offset=...)`、`make_batches(..., boa_offset=...)` 已接通，
`train_full.py` / `accept_m1.py` 从配置读取。

## 5. 一个必须纠正的推断

我一度认为"这个 1000 DN 偏移能解释之前观察到的标准化偏差（均值 −0.5、std 0.04–0.44）"。
**实测否定了这个说法**：

| 偏移 | 标准化后逐通道均值（B01…B12） | 均值绝对偏差 |
|---|---|---|
| 0（原始） | −0.53, −0.52, −0.52, −0.66, −0.54, +0.06, +0.28, +0.29, +0.34, +0.24, −0.24, −0.58 | ≈0.40 |
| +1000 | −0.06, −0.06, −0.03, −0.19, −0.06, +0.59, +0.83, +0.82, +0.91, +0.79, +0.46, +0.17 | ≈0.40 |

加上偏移后**可见光变正常（−0.52 → −0.06），但近红外反而过冲（+0.29 → +0.82）**，
整体偏差量级没变。原因是这块影像本身是**深色可见光 + 高近红外的茂密植被**，
其光谱形状与预训练全局均值不同——这是场景性质，不是定标错误。

所以两件事要分开：

1. **定标口径**：确实少了 1000 DN，应当加回（否则所有波段系统性偏暗）；
2. **分布偏移**：加回之后仍然偏离预训练分布，属于场景差异，无法靠偏移解决。

## 6. 影响与后续

- 之前所有指标（val IoU 0.270 / test IoU 0.011）都是在 **offset=0** 下得到的，
  与新默认口径不可直接比较，需重跑；
- 建议把 `boa_offset_dn` 作为一个显式实验变量（0 vs 1000）各跑一次，
  用验证集判断哪个口径更匹配预训练统计；
- 若要与 CDSE 官方端点做最终确认，需提供 CDSE OAuth 凭据（`--cdse-token`）。
