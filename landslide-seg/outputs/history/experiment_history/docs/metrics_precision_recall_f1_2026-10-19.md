# 精确率 / 召回率 / F1：全部已跑实验的完整指标

由 `scripts/make_prf1_table.py` 从既有评测 JSON 生成，只提取与派生，未改动任何历史结果。

## 口径

- 全部为 **pooled** 像素级指标（跨图累计 TP/FP/FN 后计算），最终阈值固定 **0.5**。
- `P = TP/(TP+FP)`，`R = TP/(TP+FN)`，`F1 = 2TP/(2TP+FP+FN)`（二分类下即 Dice），`IoU = TP/(TP+FP+FN)`。
- 主架构四组（A0/A1/B0/B1）为 **3 seeds**，报 mean±std；变体组为 **单 seed（1234）**，因此不给 std。
- `C`（粗输出）= 官方解码器分类器的直接结果，未经细节残差修正；U-Net 无独立 `C`，其 coarse 列与 final 相同。
- val = hiroshima 448 张（单事件）；test = italy（v3 下为 2,795 张）。两者**不可直接比较**。
