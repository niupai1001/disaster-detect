## 4. 固定一种温和、可追溯的权重规则

复用8邻接GT连通域与现有截断判据。面积在完整缓存GT上计算，不能先乘valid把同一对象切碎；只有可评的完整GT对象参与面积重分配。截断对象仍保留原像素监督。

对面积为A的完整GT对象定义原始权重：

```text
q(A) = clip(sqrt(50 / A), 1, 4)
```

50px取自既有尺度分档，4是本次预先声明的上限；它们是实验设计选择，不声称是文献最优值，不在DEV上搜索。

从固定2223个TRAIN样本计算一个全局归一化常数：

```text
c = Σ完整对象[A × q(A)] / Σ完整对象[A]
```

像素权重：

```text
完整对象内正像素：w = q(A) / c
截断对象内正像素：w = 1
有效背景像素：    w = 1
无效像素：        不参与loss
```

这样完整对象的总正权重与原正像素总量相同，截断对象和背景的权重不变。它控制的是不同大小完整对象之间的权重分配，不是全局正类增权。逐batch的正权重会有自然波动；需要记录，不能声称每个batch都严格守恒。

**不要按每张图单独归一化正权重**：只有一个小对象的图块会因此把面积权重完全抵消。本阶段使用同一个TRAIN全局常数c；不得用DEV拟合c。

损失固定：

```text
weighted_BCE = sum(valid × w × BCEWithLogits(logits, target)) / sum(valid)
loss = 0.5 × weighted_BCE + 0.5 × original_Dice
```

分母仍为有效像素数，不改成 `sum(valid*w)`；Dice沿用原实现。保留精确退化开关：关闭面积重分配时w严格为1，输出应等于旧loss。

权重图作为新增派生缓存或按样本ID的独立文件保存，绑定原GT/valid/manifest哈希；不得重写原图像、GT或valid缓存。翻转、旋转时权重图与图像和GT使用同一几何变换。权重计算过程不引入模型预测。

## 6. 正式训练前的必要检查

1. w=1时，新旧loss数值和logit梯度一致；全无效样本按原规则处理，无除零、NaN。
2. 在TRAIN全集验证归一化恒等式，截断对象和背景权重为1；记录c、权重分布、各尺度加权前后总量及每batch波动。
3. 原GT不变；权重与GT经过同一次几何增强；无效像素loss和梯度为0。
4. 同一初始模型、同一固定TRAIN batch，比较两损失的尺度梯度份额，确认不是实现断路或变成普通全局正类加权。
5. 两组真实前向/反传、固定8个TRAIN样本过拟合、batch64与checkpoint重载通过。诊断样本不用DEV难例，测试结果不当作泛化性能。
6. 原BCE组先跑；如果与历史参照出现明显无法解释的偏移，先核对初始化、样本顺序、数值精度和loss退化等价，不把偏移算作新方法效果。

## 7. 评价与停止条件

仍按0.5阈值报告正式指标：事件均值/各事件IoU、合并Dice/Precision/Recall/AP、边界F1、六尺度对象匹配数与分母、背景像素FPR，以及best/last/固定500步结果。

新增权重可能改变概率工作点。因此对两个已选best同时使用同一个预先固定的0.10–0.90、步长0.05诊断网格，比较PR关系及接近召回下的精度。扫描只用于解释，不把同一DEV最大值当独立测试成绩，不单方面给新损失调阈值。

按同一GT身份报告新增命中、失去命中、每事件变化和既定8例。跨v4r3/v4r4稳定漏检的159个1–19px对象可以列作诊断子集，但不能用它们选择训练样本、权重、checkpoint或阈值。保留数据使用历史；本轮不访问Italy/New Zealand。

判断：

- 新损失只有Recall上升而Precision/AP、边界或中大目标明显退化：记录权衡，不能宣布改善。
- 在相近Recall下精度没有改善、AP也无改善，仅改变0.5工作点：优先采用固定模型的校准方案，停止继续叠加loss。
- 小对象覆盖、整体AP/IoU和两事件表现共同支持改进：保留候选，冻结结构与监督，再安排后续泛化验证；单seed仍不声称显著性。
- 没有净改善：停止该权重规则，不立即扫多个指数、上限或Focal/Tversky组合。先据实际结果判断未解决的是表征、监督还是事件迁移。

1–19px DEV对象主要来自Hiroshima，必须逐事件报告分母；Thrissur缺少tiny不能当作跨事件tiny提升的证据。暂不扩种子，也不以raw数据未下载作为本轮训练阻碍。
