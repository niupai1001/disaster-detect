# B2 四个 probe：标记受阻

日期：2026-10-20
依据：执行计划 §3 B 组——"较大 SegFormer 的上游身份若仍无法闭环，相关四个 probe 标记受阻，其余组继续，不用随机权重替代"。

## 1. 为什么判为"身份未闭环"

| 检查项 | 结果 |
|---|---|
| 文件内容架构 | **一致**：`decoder_hidden_size=768`、`depths=[3,4,6,3]`、`hidden_sizes=[64,128,320,512]`、`linear_c` 输出 768、首层 64×3×7×7、27,463,511 元素、110,000,905 B |
| 本地 sha256 | `187ca07b…`（已记录） |
| 与上游比对 | **无法完成**：HF 的 `/api/*` 与 `/resolve/*` 对本出口 IP 返回 401，`hf-mirror` 原样转发同一错误 |
| 命名一致性 | **不一致**：目录名与 `download_meta.json` 的 `repo` 均写 `nvidia/segformer-b2-finetuned-ade-512-512`，而内容是 B2-768 规格；官方 ADE 系列 B2 只有 768 一档 |

即：能证明"这是一个 B2-768 的 ADE 权重"，**不能证明它来自哪个上游快照**。按计划口径这属于未闭环。

## 3. 对计划的影响

- B 组由计划的 16 个 run 降为 **12 个**（4 折 × 3 种编码器：sf_b0_rgb / dofa_rgb / dofa_10）。
- 计划中"较大 SegFormer 预训练编码器（RGB）——同族规格的冻结特征比较"这一问**本轮无答案**，
  报告须明确列为未完成问题，而不是用 b0 的结果代替。
- 其余组继续：控制组、三个 probe、U-TAE 配对不受影响。

## 4. 解除受阻的条件

任一条满足即可恢复这四组：

1. 能访问 HF（或提供有效 token），取得 `splits` 之外的权重文件哈希并与本地比对一致；
2. 提供该权重的可信来源记录（下载页面的 commit/hash 截图或校验和清单）；
3. 改用身份完全可核的 B2 权重（例如本地已有明确 commit 的镜像）。

在满足之前，本项目任何"同族规格冻结特征"的结论都只能基于 B0。
