# USE v3 表征与高分辨率成本诊断报告

> 本报告仅整理本次诊断文档的结果、解释、限制与后续建议，不新增实验或证据。来源：[本次诊断文档](DATA_EVENT_PROTOCOL.md#use-v3表征与高分辨率成本诊断)。

本报告回答两个问题：为什么无标签恢复更好，却没有稳定提高滑坡分割；现有实现能否承担更大图像。诊断已完成，**当前证据不足以把USE作为更好的滑坡分割方案，也不足以确定唯一失败原因**。近期精度参照继续使用十波段直接输入的SegFormer B0＋原始网格细节分支；USE保留为研究分支。建议下一轮先验证“在同一冻结编码器下，当前Context投影与加和路径是否帮助分割”，再决定是否调整预训练目标。下文行动均为建议，未启动新训练。

## 阅读约定与实验设置

本节是用户授权完成审阅稿后的**只读诊断**。基准提交`93aa16c8c9f8e0979d4bf582db28cff4e7db0944`，沿用已有选定编码器和四个最佳分割网络，不重选权重、不训练编码器、不训练探针或新消费者；没有5k检查点探针。全部优化器更新为0，正式62000步预算未增加。用户明确指定无法确认的地物区域标为`uncertain`，不据此作类别因果结论。

Fine是保留原128×128网格的32通道表征，Context是1/4、1/8、1/16、1/32四个原生尺度的空间表征，main是内部投影融合得到的1/4尺度32通道表征。无标签监督使用影像本身的数值：例如遮住10波段影像中的16×16空间块，要求从可见影像恢复该块原来的标准化反射率；像素任务随机遮住25%位置，光谱任务遮住部分可识别波段。监督分割则用独立滑坡GT产生0/1目标，GT不进入编码器输入。

采用我们的数据划分（留事件验证）：九事件2223块训练；广岛448＋特里苏尔221块是研发反复使用的开发验证，非盲测。十波段使用559块TRAIN核心拟合的stats_core25。四模型全部669块重新推理，源数组/缓存/质量/GT/像素顺序配对检查通过，混淆计数逐项复现旧结果。诊断22块含原六例及事前固定的分层扩展；另九个训练事件各取一块。语义ROI共66个，全部uncertain。质量排除像素不计误报，RGB与SCL只能辅助定位，SCL不是地物真值。

## 展开结论

**恢复能力改善已经成立，滑坡迁移改善没有成立。** 统一无标签探针总分从原生金字塔的1.0484降低到双向空间交互的0.9210，表示三项既定恢复任务的平均误差下降，不是滑坡判别分数。完整U-Net最佳事件等权IoU从0.1263到0.1305，完整SegFormer从0.1285到0.1258；两者方向不一致，均低于当前十波段端到端参照0.3081。参照的训练方式、初始化与预算不同，因此差距说明USE尚未替代当前方案，不是单一模块造成损失的因果证据。

**默认阈值不能单独解释当前问题。** 双向方案在0.5阈值下，两消费者都增加了假阳性；但把召回率固定在约0.4后，U-Net的FPR略降，SegFormer仍上升，AP也没有一致改善。由此优先关注表征与消费者的匹配，而不是只调阈值。若后续为了业务选择阈值，必须另设校准与评价规则，不能借本次开发验证扫描重新包装原成绩。

**“连接太弱”不是现有证据支持的修复方向。** 注入和反馈的真实范数比中位为0.240和1.120，反馈已经与原Fine同量级；像素级有效秩也从10.65增至15.09。加大门控或加深网络没有明确依据。前四个Query读出相近，是值得核查的机制线索，但最终Fine还有逐像素残差与空间反馈；既不能把Query数当独立信息数，也不能据此直接删Query或重训。

**预训练目标与融合方式都值得研究，但现在不能排出唯一主因。** 固定小样本中，光谱与像素项的加权梯度明显大于空间、一致性项；空间池化边界又确实包含可见位置预测。这提示“完成恢复任务所需要的信息”和“区分滑坡所需要的信息”可能不一致，属于未验证机制。另一方面，当前消费者把四尺度各投影到32通道、平均后加Fine，会改变幅度与方向；类中心距离和秩的变化只说明几何发生变化，并没有证明关键语义被删除。下一轮宜先固定编码器、只检验消费者这条连接，减少同时改变目标、结构和训练策略带来的解释困难。

**高分辨率问题应拆成执行开销和尺度增长两件事。** 512输入时，双向裸编码器29.26ms，接完整SegFormer后65.47ms；冻结包装自身含两次同步哈希，不能把全部耗时叫作注意力成本。此尺寸单份全局bias只有16MiB，不是约796MiB裸编码器峰值的主要证据；到了2048，它的静态单份大小变成4GiB，增长机制明确，整网是否可运行尚未测。切片是可验证的工程候选，但会截断跨窗上下文，不能直接承诺大图精度或端到端时延。

未验证假设：云/云影/人工结构是否为主要误报源；Fine是否形成重建捷径；某个投影方向是否丢失关键语义；加强或删除反馈是否提高泛化。没有语义人工确认或重新训练的因果对照，本轮不把这些假设写成结论。P1质量比较仅固定32份/传感器/无标签角色及固定监督案例，见[质量与元数据](../outputs/use_v3_diagnostics/quality_shift.json)；已知模式仅保留缓存的known_mask，不等于所有波长、带宽、原生分辨率字段都已知，尤其监督带宽仍未知。SCL代理、10m目标网格与部分20m原生波段须分开解释，土地覆盖分布尚未人工测量。

## 限制与下一步

本次单seed、研发验证已复用、诊断案例含错误分层且正像素增补；类距离、梯度、路径干预不能证明因果。完整成本是本轮新测的只读矩阵，不追溯改写原训练前“用户跳过成本门禁”的事实，也不宣称原旧门槛已事前通过。2048整网、冷IO、真实高分辨率场景、优化器完整步、多GPU吞吐和跨机器稳定性均未测。

后续候选仅供讨论：人工确认困难负样本、用固定训练范围验证目标与判别关系、分开研究投影/融合、评估避免完整全局bias的实现与切片上下文。均未实现、未训练、未追加预算；当前参照和选模不变，下载暂停。
