本文件为已有诊断交付的实施说明，不替代stage_ledger.json。2026-10-24复核：128块TRAIN诊断及两组300步探针已完成；不重复。正式记录仍由固定台账负责人回写。用户要求确定待认领任务后执行，本轮已执行方案复核，尚未启动新的模型训练。

## 必须纠正的解释与实现

1. 当前bridge输出是固定10维隐特征，不是有已知波段身份的反射率。不能按输入band_valid索引屏蔽bridge输出；输入可变C与固定输出10也没有逐通道对应。保持现有缺波段处理与置换不变性。S2十波段岭回归只可作为限定输入的诊断，不作为通用模型主方案。
2. 输出与原始波段的对角相关低，不等于表示错误。低有效秩、低梯度份额均为诊断现象，不是已证实瓶颈；有效秩>4、梯度份额>0.005、元数据干预差>0.01不再作为性能晋级硬门槛。
3. 不能仅根据参数梯度份额较低断言必须增加辅助分割头；全零辅助头权重会使第一步传到上游的该项梯度为零。细节分割辅助头与重建损失暂不纳入首批，以免改变多个因素。
4. DEV-best教师并不等于读取DEV标签做蒸馏，但继承了开发选模历史；last也不能消除既有超参数选择历史。固定使用本批直入best作开发实验教师，只在TRAIN生成目标，明确非盲测，不额外训练教师。
5. 取消累加多个机制和20–30次探针扫描。首批保留桥接标定、标定加特征辅助两组。未见五波段不用于标定或蒸馏训练。
6. 现有诊断比较的是physical完整波段组（0.1955），后续主对照是physical_mixed（0.1895）；需先补同口径只读诊断，不能把前者的全部机制解释直接套到后者。

## 两组恢复实验的冻结设计

参照：本轮直入0.2985、physical_mixed 0.1895；均使用原TRAIN2223/DEV669、seed1234、stats_core25。新组使用与原批次相同的官方视觉初始化规则和随机USE初始化，记录逐张量哈希；不从已训练physical checkpoint偷偷续训。

教师固定为本轮直入best，记录哈希、冻结全部参数并eval；教师只读TRAIN full10。学生训练组合仍为full 1/2、RGB/四波段/六波段各1/6，unseen5仅评价。

第一组：用固定TRAIN校准成员和采样序列进行200步桥接标定，冻结USE与视觉参数，但保留从冻结视觉前向到bridge的反向传播；匹配教师MiT第一级特征，不直接将32维回归为不同维度的多尺度特征。不得将学生前向包在no_grad中。之后恢复原监督训练参数组，重建优化器，正式2000步。

第二组：复制第一组标定结束的全部状态；正式2000步时唯一新增特征辅助项。标签损失仍0.5BCE+0.5Dice，特征项系数固定0.05，MiT前两级等权。归一化统计仅从TRAIN教师特征拟合并冻结；有效区下采样按完整有效支持的位置参与，空有效区返回可微零值。两组使用相同监督样本、增强、波段采样和学习率序列。

共同正式预算：batch8、FP32、BN运行统计冻结而仿射参数可训练；停止2000、调度3600、预热180；每100步选模；保存500/1000/1500/2000及best/last。额外200步标定和教师前向单独计成本；相对既有无标定组的比较不是等总计算比较。

短程验收用既有TRAIN内96拟合/32检查，不读DEV选辅助系数。只做预登记的固定系数和单seed实现筛查，不扫损失权重，不以短程达到某IoU作为科学结论。

## 验收与停止

硬门槛是数据身份、无泄漏边界、数值有限、教师零梯度、参数冻结正确、联合置换、masked/absent一致、checkpoint恢复、样本与波段序列可复现。秩/相关/梯度份额仅作解释读数。

正式两组若完整十波段IoU低于约0.27，恢复不足；0.27至0.2885仅为恢复信号；达到0.2885后还须查看逐事件、1–4/5–25/26+对象召回、≥50对象内部与边界FN、Precision/AP以及3/4/6/未见5输入。门槛为工程筛选，不是显著性。小目标分母77来自广岛，特里苏尔为空时写N/A。

不自动停止其他任务；不自动取得活动路径的写权限。认领前重查登记，有冲突则缩小独立实现范围或按项目规则明确移交。日期标注一致性不查，外部九通道滑坡数据不纳入。
