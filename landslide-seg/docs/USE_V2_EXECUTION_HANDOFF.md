### 2.2 两组模型与输出

两组命名：无局部波段Self-Attention（V2-N），有局部波段Self-Attention（V2-A）。代码代号仅用于路径；正文写架构描述。

共同Tokenizer将每波段每2×2 Patch的4个有序值及4个有效标记拼为8维，经Linear(8→32)和LayerNorm生成一个波段Token。先清除无效值，不做2×2均值后再编码。

V2-A加入一层4头局部波段MHSA；V2-N跳过此MHSA。两组保留相同逐Token FFN（扩展比2）、Fine/Context Query、空间主干与任务目标。公共模块初始张量一致。无波段MHSA组仍含Query交叉注意力，不能称完全无注意力模型。

Fine：4个位置Query分别读取波段Token；另将每个具体位置的有效观测经共享低维投影（值与有效标记→8维）、有效波段汇聚、8→32映射形成位置残差。两路相加并重排回原网格。隐藏目标必须在所有路径先遮蔽。

Context：1个Query汇聚Patch特征，经学习型合并到1/4尺度；空间主干窗口大小4，通道32/64/128/256，深度[1,1,2,1]，第三尺度两个模块采用普通与移位窗口。显式屏蔽无效Key/Value及填充窗口，避免全掩膜NaN。

| 输出            | 输入128×128时形状           | 含义      |
| ------------- | ---------------------- | ------- |
| fine          | B×32×128×128           | 原网格位置特征 |
| context[0]    | B×32×32×32             | 1/4尺度   |
| context[1]    | B×64×16×16             | 1/8尺度   |
| context[2]    | B×128×8×8              | 1/16尺度  |
| context[3]    | B×256×4×4              | 1/32尺度  |
| valid         | 与Fine及四层Context对应的布尔掩膜 | 输出支持范围  |
| metadata_used | 实际字段掩膜                 | 审计      |

奇数宽高只在右/下填无效位置，各尺度向上取整；Fine恢复原尺寸。有效区和空间坐标同步变换。支持1–16反射型通道，不承诺无界C或高光谱。

复用FrozenUSE时检查嵌套输出、所有参数及包括非持久buffer在内的状态。eval、no_grad、优化器排除和完整哈希必须实际成立。不得将旧权重strict=False静默加载到新架构。

### 2.3 无标签任务、遮挡与目标身份

每批相同观测生成三个任务视图，额外视图曝光和成本单列：

1. 光谱：隐藏约50%实际波段，至少保留一个可见波段；只预测目标物理身份可识别的波段。目标完全未知时不做整波段预测。
2. Fine：随机隐藏25%空间位置，各波段同步遮挡。
3. Context：随机隐藏一个32×32连续区域，评价另测16、32、64像素块。不同传感器的像素块不代表相同地面面积。

元数据视图概率：保留已有字段50%、删除一半已知字段25%、全部未知25%；不能补造原本未知字段。

目标完全未知时，空间重建临时头可用该目标波段未遮挡部分的共享摘要来区分目标，摘要仅从遮挡后观测计算，不能使用目标像素或Band ID。各模型及简单参照获得相同目标条件。工程Agent须将摘要计算和读出头的准确配置写入release，验收Agent检查无泄漏。

重建损失作用于“原本有效且被遮挡”的目标，不能因输出支持掩膜将其删除。临时空间解码器从周边特征恢复目标，不能读取原图旁路。全图没有有效输入时拒绝样本。

三个任务MAE用训练集固定校准清单上的简单参照误差归一化后等权相加；校准成员、基线、系数正式启动前冻结。不能用验证集拟合归一化统计或损失系数。

### 2.5 冻结滑坡应用

六组：旧USE、V2-N、V2-A分别做Context与Context＋Fine。旧USE取上一轮共同multisensor权重，其四尺度输入用确定性池化构造，不称独立空间预训练。

统一轻量头：各层投影32维，上采样1/4后融合；Fine经32→32投影，在原网格相加并输出分割分数。无Fine组关闭该分支，不读取未经USE的原图旁路。编码器冻结，任务头从统一初始化规则开始。

每组5000更新；batch8、FP32、AdamW LR6e-4、weight decay0.01，250步预热后余弦衰减；损失沿用现有项目分割定义并在release展开。2223训练，广岛448＋特里苏尔221开发验证，seed1234，stats_core25，二事件等权IoU选任务头。保存best/last，不自动延长。

报告IoU、Dice、Precision、Recall、AP、边界F1、对象召回及逐事件；地理组配对Bootstrap，seed1234、2000次重采样。有限开发事件区间不代表跨地域总体显著性。历史SegFormer 0.2985及旧冻结适配0.1407/U-Net0.1397仅为系统参照，不称同预算因果对照。
