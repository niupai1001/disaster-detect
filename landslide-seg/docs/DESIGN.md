# 滑坡分割的研究方案与设计演变

## 目标与方案导览

研究 Sentinel-2 多光谱输入如何支持滑坡分割，重点是小目标、边界及跨事件迁移。保留三个模型系列：SegFormer、U-Net、UTAE。通用光谱编码器USE及其冻结特征消费者归跨卫星项目；本工程不因消费者同名而复制一套结果。

| 方案 | 做了什么 | 相比前面的改变 |
|---|---|---|
| 单期SegFormer参照 | 比较十波段直入、十转三投影和原网格细节路径 | 建立固定输入、结构与选模口径 |
| U-Net架构对照 | 以完整卷积网络检验分割能力和成本 | 改变空间编码解码方式，保留相同数据任务 |
| 数据覆盖与输入对照 | 检查事件覆盖、训练数量、额外光谱及地形信息 | 区分数据贡献与网络结构贡献 |
| 多日期SegFormer | 共享编码各日期并汇聚，保留参考影像的细节 | 在已有视觉参照上增加时间观测 |
| UTAE时间建模 | 以时间注意力处理多日期特征 | 比较专门时间结构与同架构时间消融 |

## 单期SegFormer：先建立清楚的视觉参照

### 目的与想法

成熟视觉编码器已经具备空间特征提取能力，最初的问题是如何读取十个光学波段，以及下采样后的小目标信息如何保留。十波段直入改变首层输入投影；十转三方案先学习波段映射，再接三通道入口。两者分别检验直接输入与兼容既有入口的做法。

原网格细节分支直接处理参考影像，主干提供多尺度语义，解码时融合两者。细节分支负责保留可见的局部信息，不被解释为恢复传感器没有采集到的细节。后续粗预测引导、融合位置和编码中交换细节，都围绕这一连接问题展开。

### 发现与保留

早期同集合三种子比较中，十波段直入增加细节后IoU由0.2575增至0.2938；数据条件改变后，输入适配排序也会改变。因此保留“十波段直入＋原网格细节”作为明确参照，不把某个输入投影宣称为普遍最优。当前留事件协议参照的两事件等权IoU为0.3081。

## U-Net：完整空间网络的架构对照

U-Net通过下采样编码、逐级恢复和跳接组织空间信息，目的在于判断已有收益是否依赖Transformer空间编码，而不是额外增加输入模态。架构对照要保持成员、输入、训练与选模条件一致，初始化和容量分别说明。

本工程记录直接从影像训练的U-Net；固定USE后接U-Net的实验属于跨卫星表示评价。二者不能因名称相同而混为一个方案，也不能把不同编码器起点的结果解释为纯架构差异。

## 数据与额外输入：先区分变化来自哪里

增加同一批训练事件的图块、扩大事件覆盖、改变观测日期规则、增加波段或地形，是不同实验因素。前两者改变训练覆盖，后两者改变可用信息；它们都不自动等同于输入层改进。

光谱对照先检验额外通道和波段身份，再考察关系建模及融合。地形对照比较高程、坡度的直接输入与独立学习表示；统计只来自训练成员。对照没有提供一致收益时，保留为结果记录，不把所有分支累加进参照模型。

## 多日期SegFormer：在同一视觉结构中判断时间信息

单期参照只读取按规则选择的参考影像。多日期方案共享空间编码器，对各日期特征做均值、内容或日期条件汇聚；原网格细节仍来自参考影像，避免把输入期数与细节分支同时改变。

必须区分回顾性全时相输入和不晚于参考日期的输入。前者可能包含灾后更多观测，后者检验预测截止时实际可用的信息；它们不能互称同一设置。固定期数、固定跨度和灾前灾后组成的对照，就是为拆开观测数量、时间位置和内容差异。

已有官方可用子集上，单期与多期SegFormer测试IoU分别为0.3302与0.4093。这个结果支持该条件下多期信息有帮助，不能跨到留事件集合直接比较，也不能单凭它认定日期编码是收益来源。

## UTAE：检验专门的时间结构

UTAE将多日期空间特征与时间注意力结合，目的在于比较专门的时间聚合结构，而不只给单期模型增加输入通道。真实日期接口、单期与15期、固定期数以及均值／内容开关分别回答不同问题。

既有官方可用子集的真实日期UTAE单期与15期测试IoU为0.3396和0.4832；多帧收益与旧日期接口的差值接近，说明不能把收益简单归于日期编码修正。后续保持共同成员，重点区分多次观测本身和时间聚合机制。
