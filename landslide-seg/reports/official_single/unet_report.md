# 同一批实验放到 U-Net 上：八组对照

日期：2026-10-20

## 0. 设置

两种架构各跑四组（baseline / +DEM / +坡度 / pos_weight=5），共用：
官方 S12LS-LD split、3,012 训练块 / 758 VAL / 945 TEST、同一份标签与 valid、
同一损失（0.5 BCE + 0.5 Dice）、3,600 更新 × batch 64、seed 1234、选模口径（VAL pooled IoU）。

| | SegFormer 组 | U-Net 组 |
|---|---|---|
| 结构 | MiT-B0 + 原网格 32 通道末端细节分支 | SMP ResNet18-UNet |
| 参数量 | 3,753,602 | 14,350,161（3.8×） |
| 预训练 | ADE（direct10，10 通道） | ImageNet（首层扩到 10/11 通道，新增通道零初始化） |
| 训练耗时 | 687–831 s | 544–602 s |
| 峰值显存 | 4,694–4,698 MiB | 1,852–1,856 MiB |
| 学习率 | encoder 6e-5 / 其余 6e-4 | **沿用同一套，未为 U-Net 调** |

> 学习率没为 U-Net 单独调，参数量也差 3.8 倍——**跨架构的绝对分数不能当"架构优劣"的判决**。
> 有意义的是**族内差值**：同一改动在本族内只动一个因素。

## 1. 绝对结果（TEST，best 检查点）

| 架构 | 组 | IoU | AP | Precision | Recall | 边界 F1 | 对象召回 |
|---|---|---:|---:|---:|---:|---:|---:|
| SegFormer | baseline | 0.3275 | 0.4830 | 0.5404 | 0.4541 | 0.5139 | 0.4602 |
| SegFormer | DEM | 0.3363 | 0.4902 | 0.5325 | 0.4772 | 0.5208 | 0.4790 |
| SegFormer | Slope | **0.3402** | **0.4923** | 0.5241 | 0.4924 | 0.5242 | 0.4577 |
| SegFormer | PW5 | 0.3314 | 0.4922 | 0.4652 | 0.5355 | 0.5126 | 0.4867 |
| U-Net | baseline | 0.3004 | 0.4339 | 0.4994 | 0.4299 | 0.4885 | 0.4270 |
| U-Net | DEM | 0.3020 | 0.4371 | 0.4988 | 0.4335 | 0.4888 | 0.4245 |
| U-Net | Slope | **0.3080** | **0.4428** | 0.4893 | 0.4539 | 0.4960 | 0.4504 |
| U-Net | PW5 | 0.3000 | 0.4340 | 0.4542 | 0.4693 | 0.4857 | 0.4411 |

U-Net 基线比 SegFormer 基线低 2.7 个 IoU 点（0.3004 vs 0.3275），但参数多 3.8 倍、显存只用 1/2.5、训练快约 20%。

## 3. 三组改动是否在两种架构上复现

| 组 | ΔIoU 符号 | ΔRecall 符号 | 判断 |
|---|---|---|---|
| DEM | 一致 | 一致 | 符号复现，但 U-Net 上幅度只有 +0.0015，实质为零 |
| Slope | 一致 | 一致 | **两侧都正，且是唯一在 U-Net 的 VAL 上也正的组** |
| PW5 | **相反** | 一致 | 召回效果复现，IoU 效果未复现 |

**（1）召回升、精确率降这个机制与架构无关。**
三组改动在两种架构上都表现为 Recall↑ / Precision↓，PW5 最明显（Seg +8.1/−7.5，U-Net +3.9/−4.5）。这说明"把判定推向正类"是可复现的机制，不依赖具体网络。

**（2）但 IoU 是否因此改善，与架构有关。**
PW5 在 SegFormer 上 +0.39，在 U-Net 上是 **−0.04**。结合 SegFormer 侧此前的阈值扫描（阈值从 0.5 降到 0.167 只换来 IoU 0.3214→0.3162），可以确认：**这类改动只是沿 PR 曲线滑动，滑不到更高的 IoU**。UNet 上连那点正号都没有，说明确属噪声。

**（3）坡度是三者中最可信的一个。**
它是唯一在两种架构、两个 split（U-Net VAL +0.0044、U-Net TEST +0.0075、Seg TEST +0.0127）上方向一致的改动。DEM 在两族里一大一小、其中 U-Net 的 VAL 还是负的，实质为零。

**（4）U-Net 的尺度偏好与 SegFormer 相反。**
U-Net 基线的 ≥200 px 召回 0.653（SegFormer 0.590），但 1–4 px 只有 0.191（SegFormer 0.210）；10–19 px 差得更多（0.441 vs 0.503）。较大的参数量没有换来小目标能力。

## 4. 结论

1. **在这套数据与预算下，SegFormer-B0 + 细节分支优于 ResNet18-UNet**，且便宜（显存 1/2.5、更快）。但 U-Net 的学习率是借来的，不能排除"调过之后反超"——这一点本轮无法回答。
2. **坡度（DEM 求导）是目前唯一在两个架构上方向一致的改动**，值得作为候选保留。DEM 原始高程两族都近似无效。
3. **pos_weight=5 只改变工作点，不改变排序质量**（AP 在 U-Net 上 +0.001、SegFormer 上 +0.009，都在噪声内）。若要小目标召回，它是便宜的杠杆；若要 IoU，它不是答案。
4. **跨架构比较的边界**：3.8× 参数量差 + 未调 LR + 单 seed，本表不支持"哪种架构更好"的普遍结论，只支持"在上述固定条件下哪一种分数更高"。
