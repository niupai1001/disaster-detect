# 研究备忘录：方向校正 — 重新定义灾害检测问题的正确框架

日期：2026-05-04

背景：与项目负责人就 `task-70f2a884ec28` 进行头脑风暴后审查。

## 跑偏诊断

**当前任务（切片1："火焰光谱基线与弱监督掩码构建"）偏离了项目目标。** 它在构建一条火灾专项的数据工程管线——计算 NBR、栅格化 WKT 多边形、解决 CRS 对齐——而不是解决实际问题。

**真正的目标：** 给定一张卫星遥感影像（如 Sentinel-2），分类识别出发生了什么灾害，以及灾害在图像中的位置。

差异对照：

| | 当前切片1方向 | 正确方向 |
|---|---|---|
| **做什么** | 计算火灾光谱指数；WKT多边形转栅格掩码 | 从影像中检测并分类灾害类型 |
| **覆盖范围** | 仅火灾 (C5) | 多灾种（C2泥石流、C3、C5火灾） |
| **本质** | 数据工程管线 | 分类 + 检测/分割问题 |
| **最终产物** | NBR/NDVI 的 GeoTIFF 文件 | 输出灾害类型 + 位置的系统 |

**根本原因：** 就绪审计发现火灾数据最丰富（837个多边形），团队沿着阻力最小的路径滑入了火灾专项的光谱指数管线，没有退一步确认这是否服务于多灾种目标。

## 数据清单

| 类别 | 多边形数 | 事件数 | 灾种 |
|---|---|---|---|
| C2 | 500 | 271 | 泥石流 |
| C3 | 50 | 28 | 待确认 |
| C5 | 837 | 294 | 火灾 |

- **总计：** 3 个灾种，1,387 个标注多边形
- **影像：** 15 个波段 (F01–F17)，Sentinel-2 类型，每波段约 4,300–11,200 个 .tif 文件
- **现有数据集：** `datasets/c5_fire_yolo/` — 仅火灾的 YOLO 格式数据集（单一类别：`0: fire`）

## 方法全景：从卫星影像中定位灾害的五条路径

### 1. 语义分割（Semantic Segmentation）

逐像素分类：每个像素 → 灾害类型或背景。

- **输出：** 像素级掩码（与多边形标注天然对齐）
- **代表模型：** U-Net, DeepLabV3+, SegFormer, Mask2Former
- **对本项目的适配度：高。** 多边形标注可直接栅格化为掩码。多类别输出直接对应多灾种目标。不规则灾害形状（蔓延的火烧迹地、长条形泥石流）天然适配。

### 2. 目标检测（Object Detection）

边界框回归：对每个灾害区域画矩形框。

- **输出：** 边界框 + 类别标签
- **代表模型：** YOLO, Faster R-CNN, DETR
- **对本项目的适配度：低。** 矩形框浪费了精确的多边形标注。灾害形状（细长泥石流、不规则火烧迹地）被矩形严重劣化。现有 `c5_fire_yolo` 数据集用的是这个格式，但那只是单类别实验，不应成为目标架构。

### 3. 实例分割（Instance Segmentation）

检测 + 分割的结合：为每个灾害实例输出精确轮廓和类别。

- **输出：** 每个实例的掩码 + 类别
- **代表模型：** Mask R-CNN, YOLOv8-seg, SAM
- **对本项目的适配度：中。** 如果需要区分同一张图里的多个独立灾害事件则有价值。需要实例级标注（WKT多边形可以提供）。

### 4. 变化检测（Change Detection）

比较灾前 vs 灾后影像：变化区域 = 灾害区域。

- **输出：** 变化图 / 差异掩码
- **代表模型：** Siamese U-Net, ChangeFormer, BIT
- **对本项目的适配度：潜力高但有门槛。** 现有 107 对灾前/灾后候选，但 0 对已验证。变化检测是灾害最原则性的定义（灾害本质上就是变化），但需要先验证时间配对的质量。

### 5. 光谱指数阈值法（Classical Remote Sensing）

从多光谱波段计算物理指数（NBR、NDVI 等），然后阈值分割。

- **输出：** 每个指数的二值掩码
- **代表方法：** NBR, dNBR, BAI, MIRBI, NDVI
- **对本项目的适配度：作为辅助特征，而非主要方法。** 指数编码了物理先验，深度学习模型应将其作为输入通道利用。但纯阈值法只能处理单一灾种、对阈值敏感、无法实现多类别目标。

## 核心结论

**本项目是多类别语义分割问题。** 多边形标注数据、精确灾害边界勾画的目标、真实灾害的不规则形状——三者都指向语义分割，而非目标检测。

光谱指数（NBR、NDVI 等）是分割模型的**输入特征**，不是最终输出。现有 `c5_fire_yolo` 数据集是前人针对单一火灾类别的实验，不应被视为目标架构或格式。

## 决策影响

1. 第一个实现切片应重新定义，目标为**多灾种语义分割**，而非火灾专项指数计算。
2. 目标检测（YOLO 格式）降级为备选方案，非主要路线。
3. 光谱指数计算的正确定位是**输入特征工程**，不是交付物。
4. 变化检测仍为高价值方向，但受限于灾前/灾后配对验证。
5. 下一个任务简报的起点应是「什么模型输入影像、输出灾害类型+掩码」，而非「怎么算 NBR」。
